## 🔥 核心模式

### ⭐ 组件命名规范

**文件命名**
```bash
# React组件
Button.tsx              # 大驼峰
button.module.css       # 小驼峰 + 模块化

# Vue组件
TheHeader.vue           # 大驼峰（视觉组件）
UserCard.vue            # 大驼峰（业务组件）

# Hooks
useCounter.ts           # use前缀
useAuth.ts              # use前缀

# 工具函数
formatDate.ts           # 动词开头
parseJSON.ts            # 动词开头
```

**组件命名**
```tsx
// React
// ✅ Good
UserProfile, NavigationMenu, ProductCard

// ❌ Bad
userProfile, nav, card

// Vue
// ✅ Good
<template>
  <TheHeader />         # 视觉组件带The前缀
  <UserProfile />       # 业务组件大驼峰
</template>
```

### ⭐ Git 提交规范

**Commit Message 格式**
```
<type>(<scope>): <subject>

# type: feat | fix | docs | style | refactor | test | chore
# scope: 影响的模块
# subject: 简短描述
```

**示例**
```bash
feat(auth): add login with wechat

fix(ui): fix button hover style in dark mode

docs(readme): update installation guide

style(css): format code with prettier

refactor(api): extract common fetch logic

test(hooks): add unit tests for useCounter

chore(deps): upgrade react to v18
```

**Angular提交规范**
```
feat: 新功能
fix: 修复bug
docs: 文档变更
style: 代码格式（不影响功能）
refactor: 重构
perf: 性能优化
test: 测试相关
build: 构建或依赖变更
ci: CI配置变更
chore: 其他变更
```

### ⭐ 目录结构

**React 项目**
```
src/
├── assets/              # 静态资源
├── components/          # 公共组件
│   ├── ui/             # UI组件
│   └── layout/         # 布局组件
├── features/            # 功能模块
│   ├── auth/
│   ├── dashboard/
│   └── settings/
├── hooks/               # 自定义Hooks
├── lib/                 # 工具库
├── pages/              # 页面
├── services/           # API服务
├── stores/             # 状态管理
├── styles/             # 全局样式
├── types/              # 类型定义
├── App.tsx
└── main.tsx
```

**Vue 项目**
```
src/
├── assets/             # 静态资源
├── components/          # 公共组件
│   ├── base/          # 基础组件
│   └── common/        # 通用组件
├── composables/        # 组合式函数
├── layouts/            # 布局组件
├── pages/             # 页面
├── router/            # 路由
├── stores/            # 状态管理
├── styles/            # 全局样式
├── types/             # 类型定义
├── utils/             # 工具函数
├── App.vue
└── main.ts
```

### ⭐ Code Review 清单

- [ ] 代码是否清晰易读

- [ ] 变更是否向后兼容
