> ⚠️ 本知识仅适用于 **uni-app 自定义组件 / uni-app 项目** 场景。
> H5 普通 Vue 项目使用 iconfont 不需要特殊处理，**不能**直接复用本方案。

# uni-app 自定义导航 icon 字体库

## 问题

uni-app 编译到小程序端时，`text`/`view` 标签内引用的 iconfont 在线字体往往因跨域或体积过大无法生效。
特别是 `pages.json` 中 `tabBar.iconfont` 与 `midButton` 的字体图标。

## 方案一：tabBar.iconfont

```json
{
  "tabBar": {
    "iconfontSrc": "static/iconfont/iconfont.ttf",
    "list": [
      {
        "pagePath": "pages/index/index",
        "text": "首页",
        "iconfont": { "text": "\ue001", "selectedText": "\ue002", "fontSize": "20px" }
      }
    ]
  }
}
```

> 仅 **App 端** 支持 iconfont 字体图标，**小程序 tabBar 必须用图片**。

## 方案二：midButton 悬浮按钮

```json
{
  "tabBar": {
    "midButton": {
      "iconWidth": "40px",
      "iconfont": { "text": "\ue000", "fontSize": "40px", "color": "#ff546e" },
      "backgroundColor": "#fff"
    }
  }
}
```

## 方案三：页面内 iconfont（兼容所有端）

1. 将 iconfont.css / .ttf 放入 `static/iconfont/`。
2. 在 `App.vue` 中引入：

```css
@font-face {
  font-family: 'iconfont';
  src: url('/static/iconfont/iconfont.woff2') format('woff2'),
       url('/static/iconfont/iconfont.ttf') format('truetype');
}
.iconfont {
  font-family: 'iconfont';
  font-size: 24rpx;
}
```

3. 模板使用：

```html
<text class="iconfont">&#xe001;</text>
```

> 注意使用 `<text>` 而不是 `<view>`，否则小程序可能渲染失败。

## 实践提示

1. 小程序不支持 iconfont 作为 tabBar 图标，必须导出 png。
2. midButton 仅在 App / H5 端有效，小程序被自动忽略。
3. iconfont 字体文件控制在 50KB 以内，避免拖慢首屏。
4. 多色图标建议使用 SVG sprite 替代 iconfont。
