# 微信小程序运行步骤（uni-app 工程）

## 背景

uni-app 工程运行到微信开发者工具时，常因「未配置 AppID」、「未开启服务端口」等原因失败。
新手经常遇到下图的报错提示。

## 操作步骤

### 步骤一：创建 / 打开 uni-app 项目

使用 HBuilderX 创建项目，或在 CLI 工程中执行 `vue create -p dcloudio/uni-preset-vue my-project`。

### 步骤二：获取微信小程序 AppID

1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. 进入「开发管理」→「开发设置」
3. 复制 **AppID（小程序ID）**

### 步骤三：在 manifest.json 中配置 AppID

打开项目根目录 `manifest.json` → 「微信小程序配置」：

```json
{
  "mp-weixin": {
    "appid": "wxYourAppIdHere",
    "setting": { "urlCheck": false },
    "usingComponents": true
  }
}
```

### 步骤四：开启微信开发者工具「服务端口」

1. 打开微信开发者工具
2. 菜单 → 设置 → 安全设置
3. 开启 **「服务端口」**（HBuilderX 需要通过端口调用 CLI）

### 步骤五：HBuilderX 运行到小程序模拟器

1. 顶部菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」
2. 首次运行会自动打开微信开发者工具并导入编译产物
3. 编译产物目录：`unpackage/dist/dev/mp-weixin`

### 步骤六：真机预览

1. 微信开发者工具右上角「预览」扫码
2. 手机微信扫码即可在真机查看效果

## CLI 工程方式

```bash
# 编译到微信小程序
npm run dev:mp-weixin

# 在微信开发者工具中导入 unpackage/dist/dev/mp-weixin 目录
```

## 常见报错

| 报错 | 解决方案 |
| --- | --- |
| AppID 不正确 | 检查 manifest.json 的 mp-weixin.appid |
| 服务端口未开启 | 微信开发者工具 → 设置 → 安全设置 |
| 无法识别小程序项目 | 确认导入的是 `dev/mp-weixin` 而非项目根 |
| 自定义组件报错 | manifest.json 加 `"usingComponents": true` |

## 实践提示

1. 个人测试可使用「微信开发者工具」自动分配的测试 AppID。
2. 真机调试需在「详情 → 本地设置」中关闭「ES6 转 ES5」。
3. 发布前需在「微信公众平台 → 服务器域名」配置 request 合法域名。
4. 体验版与正式版是两套独立二维码，调试时使用体验版。
