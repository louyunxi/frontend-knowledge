## 页面模式精确索引

页面模式知识须满足：

- 来自真实项目代码蒸馏，附 `source_scope` 与 `observed_platforms`；
- 通过模板元数据校验，`confidence` 基于观察样本判定，不随意标为 `low`；
- 文件路径、knowledge_id 与下表条目一一对应，不出现孤儿条目。

当前未登记任何页面模式。下一次新增须按 `/frontend:distill --type page-layout` 命令从真实页面代码生成，禁止再以参考目录方式占位创建。

## 使用说明

### 查询方式

```
当用户搜索时：
1. 先在 L1 索引中查找完全匹配的 title
2. 再查找 filename 完全匹配
3. 返回匹配结果
```

### 示例

```
搜索: "gsap页面过渡"
→ L1 匹配: ["GSAP 页面过渡动画"] ✅

搜索: "scroll-trigger"
→ L1 匹配: ["ScrollTrigger 滚动动画"] ✅
```

## 维护说明

### 添加新知识

```
添加新知识时，同步更新 L1 索引：

1. 提取精确关键词（从 title、filename、description）
2. 填写索引表格
3. 保持按域分组
```

### 定期更新

```
更新周期: 每次添加新知识时自动更新

维护检查:
□ 新知识的 L1 索引是否完整
□ 关键词是否准确
□ 复杂度是否正确
```

## 性能考虑

```
L1 索引特点:
├── 数据量: 小（仅精确关键词）
├── 查询速度: 最快
├── 召回率: 低（仅精确匹配）
└── 用途: 快速定位 + 兜底

使用建议:
├── 优先查询 L1
├── 命中则直接返回
└── 未命中则继续 L2-L4
```
