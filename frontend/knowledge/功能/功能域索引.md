## 🔥 核心模式

### GIS / 地图类（8 条）

**入口组合**：

- 首次接入地图：先看 `GIS地图初始化与天地图集成.md`，再按目标平台选 `Leaflet*` 或 `ArcGIS*` 系列。
- Leaflet 业务：初始化 → 地块绘制 → 区域轮廓四层高亮（厚度层 + 走线动画 + 背景层 + 呼吸发光），共 3 个 Leaflet 文件按需串联使用。
- ArcGIS 业务：事件 → 几何 → 渲染 → 数据查询 4 个文件按职责组合。
- 文字标注性能：参考 `地图标注渲染引擎.md`，使用 Proxy 响应式 + 视口剔除。
- 区域聚焦：参考 `地图区域蒙层-反向环Polygon镂空.md`，使用反向环 Polygon 实现区域外蒙层 / 区域内穿透。

### 可视化类（5 条：1 + 4 子集）

- **ECharts 自动循环聚焦 tooltip（基线）**：饼图 / 柱状图 / 折线图均可使用 `dispatchAction({ type: 'showTip' })` 配合 `setInterval` 实现定时聚焦某个 item 显示 tooltip；hover 鼠标时设置 `isHovering = true` 阻止本次自动聚焦，并 `hideTip` 当前 item。`ECharts-图表自动循环聚焦tooltip.md` 内含三种图表的差异对比表和统一框架代码（适用于 echarts ≥5）。
- **ECharts 4.9 多系列渐变柱状图**：`ECharts-4.9-多系列渐变色柱状图+长度自适应.md`，按 `maxLength` 三档（≤6 / 6~12 / >12）自适应切换 `grid.bottom` / `axisLabel.rotate` / `dataZoom.zoomLock`；4 组颜色硬编码（每组 `[top, bottom]`）。
- **ECharts 4.9 多色折线渐变面积图**：`ECharts-4.9-多色折线渐变面积图.md`，每条线 `colorList = { lineColor, lineInitiateColor(rgba 0.4), lineStopColor(rgba 0) }`，`areaStyle.colorStops` 方向 = 上→下，缺失数据降级为 `--`。
- **ECharts 4.9 3D 饼图卡片**：`ECharts-4.9-3D饼图卡片.md`，依赖项目内置 `Pie3D01` 子组件，data 拆为「主指标 + 详情子项」，`v-if="hasData && optionData.length"` 防空渲染，chart 绝对定位 `top: 33px` 让出主指标头部。
- **ECharts 4.9 2D 饼图 + 图例列表**：`ECharts-4.9-2D饼图+图例数据列表.md`，依赖 `echartsPie` + `pieText` 子组件，使用 `echartData` 对象契约 + `slot="title"`/`slot="num"` 注入；图例按 `:nth-child(2n-1)` 60% / `:nth-child(2n)` 24% 实现错位双列。

### 大屏卡片布局类（5 条 · 2026-09-16 新增）

> 来自 `D:\sn-project\frp_gov_web\src\components\GovScreen\GSTemp\src` 真实蒸馏，共性：**外层都包 `GSPlate`（项目内部 card 壳，自带标题栏 / 角标 / loading）**。

- **顶部 Hero + 横向分页图标指标卡**：`卡片布局-顶部Hero块+横向分页图标指标卡.md`，核心是 `arrTrans(n, list)` 切片工具 + `el-carousel indicator-position="none"` + 翻页箭头。
- **顶部主指标 + 居中轮播卡 + 自定义分页**：`卡片布局-顶部主指标+居中轮播卡+自定义分页.md`，使用 `vue-awesome-swiper 4.1.1` 配 `centeredSlides + loop + autoplay`，分页点带 `Aniupdown` 浮动动画。
- **顶部数字递增 + 4 列图标数据网格**：`卡片布局-顶部数字递增+4列图标数据网格.md`，使用 `vue-count-to 1.0.13`（`startVal/endVal/decimals/useEasing`），4 列等宽 flex + BEM 命名（`.col-info__pic` / `.col-info__value`）。
- **占比点对可视化 + 双指标底栏**：`卡片布局-占比点对可视化+双指标底栏.md`，外层容器按 `flex: 1` 切两半，每半各放一组「图标 + 大数值 + 单位 + 标签」，底部用 `box-content` 比例换算 + 单位换算双说明。
- **顶部 Tab 切换 + 四角数据格 + 中心图标**：`卡片布局-顶部Tab切换+四角数据格+中心图标.md`，tab 容器 `.nav-wrap` 内 `.nav-item` 切组，底部 `.line-active` 用 `transform: translateX(distance)` + `transition: linear 0.3s` 实现滑动指示线；4 角数据 + 中心图标用绝对定位叠。

### uni-app 移动端组件类（11 条 · 2026-09-17 跨域迁移）

> 来自 `frontend-patterns` 知识库跨域迁移，共性：**面向 uni-app 移动端场景**，涵盖基础交互组件、布局组件、系统能力调用等。

- **Drawer 抽屉组件**：`Drawer抽屉组件.md`，使用 `transform: translateX(-100%)` 配合 `transition` 实现侧边抽屉滑入/滑出，配合遮罩层 `v-show` 控制显示。
- **验证码与密码输入框**：`验证码与密码输入框.md`，通过 Flex 网格布局 N 个独立 `<input>`，配合 `v-model` + `focus` 自动跳转下一格，支持 4 位验证码 / 6 位密码两种模式。
- **自定义数字键盘**：`自定义数字键盘.md`，`digitKeyboard` 组件实现 0-9 数字 + 小数点 + 删除键布局，使用 `number-precision`（NP）库处理浮点数精度问题。
- **瀑布流布局纵向**：`瀑布流布局纵向.md`，Flex 4 列等宽布局，每列高度独立累加，新元素 push 到当前最矮列，实现纵向瀑布流。
- **瀑布流布局横向**：`瀑布流布局横向.md`，`column-count` + `column-gap` 实现横向瀑布流，自动换列，断点自适应。
- **Flex 实现 Table 布局**：`Flex实现Table布局.md`，使用 Flex `display: flex/flex-wrap` 替代原生 `<table>` 标签，实现更灵活的响应式表格，支持固定列、合并单元格。
- **输入框模糊搜索**：`输入框模糊搜索.md`，监听 `input` 事件，遍历列表用 `indexOf` 过滤匹配项，实时更新搜索结果。
- **自由拖动按钮**：`自由拖动按钮.md`，`touchstart`/`touchmove`/`touchend` 计算偏移量，通过 `uni.setStorageSync` 持久化 position，下次进入恢复位置。
- **二维码与条形码扫码**：`二维码与条形码扫码.md`，调用 uni-app HTML5+ API `plus.barcode.create()` 创建扫码控件，支持二维码 / 条形码识别。
- **长按保存图片组件**：`长按保存图片组件.md`，`@longtap` 触发 `uni.saveImageToPhotosAlbum` 保存到相册，配合权限申请 `uni.authorize`。
- **车牌号键盘选择组件**：`车牌号键盘选择组件.md`，8 位车牌输入，第 1 位省份选择键盘（汉字），其余 7 位字母数字键盘，支持新能源车牌。
