# 输入框模糊搜索 (inputSearch)

> ⚠️ 本知识仅适用于 **uni-app 自定义组件**。原生 `<input>` + `@input` 事件 + 数组 `indexOf` 模糊匹配，是移动端轻量搜索框最直白的实现。

## 实现原理

1. 父组件传入 `dataSource`（形如 `[{id, name}, ...]`）
2. 监听 `@input` 事件，对 `dataSource[i].name` 做 `indexOf(val) !== -1` 过滤
3. 把匹配项写入 `list` 渲染在 `<view class="ul">` 中
4. 点击项触发 `@tap="select(item)"`，向上 emit `select` 事件
5. `@blur` 时通过 `setTimeout(0)` 把 input 内容回填为"已选名称"——绕开 `tap` 与 `blur` 触发顺序问题

## Props

| Prop | 类型 | 默认 | 说明 |
| ---- | ---- | ---- | ---- |
| `placeholder` | String | — | 输入框占位 |
| `searchKey` | String | — | 数据源中要匹配的字段名（源码中**未真正使用**，需自行扩展） |
| `dataSource` | Array | `[]` | 数据源 |

## Events

| 事件 | 参数 | 说明 |
| ---- | ---- | ---- |
| `@select` | 选中的数据项 | 用户点击匹配项 |

## 关键代码

```html
<template>
  <view class="input-group">
    <input :placeholder="placeholder" @input="search" @blur="hideList" v-model="name" />
    <view class="ul">
      <view
        class="li"
        v-for="(item, index) in list"
        :key="index"
        @tap="select(item)">
        {{ item.name }}
      </view>
    </view>
  </view>
</template>
```

```js
methods: {
  search(e) {
    const val = e.detail.value;
    const { dataSource } = this;
    const arr = dataSource.filter(item => item.name.indexOf(val) !== -1);
    this.list = val ? arr : [];
  },
  select(item) {
    this.backName = item.name;
    this.list = [];
    this.$emit('select', item);
  },
  hideList() {
    this.list = [];
    this.t = setTimeout(() => { this.name = this.backName; }, 0);
  }
}
```

## 设计要点

| 要点 | 说明 |
| ---- | ---- |
| `setTimeout(0)` 回填 | `@tap` 在 `@blur` 之前触发，先清空 list 再设回 `backName` |
| `dataSource` 父级传入 | 业务可换任意字段 / 多字段搜索 |
| `.ul` 绝对定位 `top: 100%` | 紧贴输入框下方 |
| `indexOf` 模糊匹配 | 数据量小时 OK；超过 1000 条建议上 `fuse.js` / 后端接口 |

## 适用场景

- 收货地址联想
- 商品搜索
- 用户名 / 群组搜索

## 进阶

- 替换 `searchKey` 为**实际字段名**（如 `searchKey='label'`）
- 大数据量改用 `lodash._.debounce` 防抖
- 加键盘"搜索"按钮：`@confirm` 触发回车提交
- 加高亮匹配文字：用正则 split + `<text style="color:red">`
