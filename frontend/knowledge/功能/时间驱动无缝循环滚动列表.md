# 时间驱动无缝循环滚动列表（hover 暂停 + 滚动条渐显）

## 概述

**时间驱动无缝循环滚动列表**是 ThreeAssetsSupervision 项目里"各市监管指数排行"模块的核心组件。它用 `requestAnimationFrame` 配合**时间增量**（`elapsed * speed / 1000`）做平滑滚动，到达底部自动重置回顶部形成无缝循环。鼠标进入时**立即暂停**，离开时无缝续滚。同时配套了**滚动条 hover 渐显**的细节交互。

**适用场景**：
- 大屏里实时排行/列表/通知的自动滚动展示
- 数据条数超过容器高度、需要"翻页"感但又不想真分页
- 任何需要"展示 N 条数据但容器只放得下 M 条"的场景

**关键特征**（与同类区分）：
- ✅ **时间驱动（delta-time）**：用 `elapsed * speed / 1000`，**与帧率无关**（60fps 和 30fps 速度一致）
- ✅ **无缝循环**：滚到底部自动重置回顶部（**不闪烁**，因为内容连续）
- ✅ **hover 暂停/续滚**：精确暂停在当前帧，鼠标离开时无缝接续
- ✅ **滚动条 hover 渐显**：默认透明，hover 时蓝色渐变 + drop-shadow 发光
- ✅ **数据自适应**：数据条数 ≤ 可视条数时**自动停止**动画
- ✅ **零依赖**：纯 Vue 3 + 原生 JS
- ❌ 不是 CSS `@keyframes` 动画（CSS 动画无法与 hover 暂停/续滚无缝衔接）
- ❌ 不是 `vue-seamless-scroll` 等第三方库

### 3. 完整脚本（核心逻辑）

```ts
<script setup>
import { computed, inject, ref, onMounted, onUnmounted, watch } from 'vue';

const props = defineProps({
  speed: { type: Number, default: 25 },
});

const regionAdcode = inject('regionAdcode');  // 注入父级 adcode（用于切换数据源）

const containerRef = ref(null);
const isPaused = ref(false);

let animationId = null;
let startTime = null;
let lastScrollTop = 0;
let maxScroll = 0;

// 核心：rAF 时间增量循环
function startAnimation() {
  const tick = (timestamp) => {
    if (!startTime) startTime = timestamp;
    const elapsed = timestamp - startTime;
    const delta = (elapsed * props.speed) / 1000;  // 时间增量（与帧率无关）

    lastScrollTop += delta;

    // 关键：到底部后重置回顶部（无缝循环）
    if (maxScroll > 0 && lastScrollTop >= maxScroll) {
      lastScrollTop = 0;
    }

    if (containerRef.value) {
      containerRef.value.scrollTop = lastScrollTop;
    }

    startTime = timestamp;
    animationId = requestAnimationFrame(tick);
  };
  animationId = requestAnimationFrame(tick);
}

function stopAnimation() {
  if (animationId !== null) {
    cancelAnimationFrame(animationId);
    animationId = null;
  }
}

// hover 暂停
function handleMouseEnter() {
  isPaused.value = true;
  stopAnimation();
}

// hover 离开 → 无缝续滚（关键：lastScrollTop 同步当前滚动位置）
function handleMouseLeave() {
  isPaused.value = false;
  if (containerRef.value) {
    lastScrollTop = containerRef.value.scrollTop;  // 关键：同步当前位置
  }
  startTime = null;          // 重置时间起点
  startAnimation();
}

// 计算最大可滚动距离（数据自适应）
function updateMaxScroll() {
  requestAnimationFrame(() => {
    const container = containerRef.value;
    if (container) {
      const scrollableHeight = container.scrollHeight - container.clientHeight;
      if (scrollableHeight <= 0) {
        // 数据不足一屏 → 不滚动
        lastScrollTop = 0;
        maxScroll = 0;
        stopAnimation();
        return;
      }
      maxScroll = scrollableHeight;
      if (lastScrollTop > maxScroll) {
        lastScrollTop = 0;
        container.scrollTop = 0;
      }
    }
  });
}

onMounted(() => {
  updateMaxScroll();
  startAnimation();
  window.addEventListener('resize', updateMaxScroll);
});

onUnmounted(() => {
  stopAnimation();
  window.removeEventListener('resize', updateMaxScroll);
});

// 数据变化时重计算 maxScroll
watch(rankings, () => {
  updateMaxScroll();
});

const rankings = computed(() => getRankings());
</script>
```

## 关键参数说明

| 参数/状态 | 类型 | 默认 | 说明 |
|----------|------|------|------|
| `speed` | Number | `25` | 滚动速度（**像素/秒**），越大越快 |
| `isPaused` | Boolean | `false` | 当前是否暂停（同时控制 `is-paused` CSS class） |
| `lastScrollTop` | Number | `0` | 累积滚动位置（rAF 内部状态） |
| `maxScroll` | Number | `0` | 最大可滚动距离（`scrollHeight - clientHeight`） |
| `startTime` | Number | `null` | 上一帧时间戳（用于计算 `elapsed`） |
| `animationId` | Number | `null` | 当前 rAF ID（用于 cancel） |

### 时间增量核心公式

```js
const elapsed = timestamp - startTime;       // 距上一帧的毫秒数
const delta = (elapsed * props.speed) / 1000;  // 转换为"像素"
```

> **为什么用时间增量而不是固定像素？** 固定像素（如每次 +1）在 60fps 屏幕是 60px/s，在 30fps 屏幕只有 30px/s。**时间增量与帧率无关**，所有设备速度一致。

### 无缝循环关键

```js
if (maxScroll > 0 && lastScrollTop >= maxScroll) {
  lastScrollTop = 0;          // 直接重置为 0
}
container.scrollTop = lastScrollTop;
```

> **为什么不"复制第一段内容"做无缝？** 该项目数据量可控（≤16 条），重置回 0 视觉上不会突兀。如果数据条数很多，建议复制首条到末尾做"内容接龙"。

### Hover 暂停/续滚关键

```js
function handleMouseLeave() {
  isPaused.value = false;
  if (containerRef.value) {
    lastScrollTop = containerRef.value.scrollTop;  // ← 关键：同步
  }
  startTime = null;          // ← 关键：重置时间
  startAnimation();
}
```

> **为什么必须 `startTime = null`？** 不重置的话，`elapsed` 会从停止时算到恢复时，**瞬间跳一大段**。重置后下一帧 `elapsed` 从 0 开始计算。

## 注意事项

> ⚠️ **颜色只是默认值**：滚动条 `#00d4ff`、进度条 `#0284c7→#38bdf8` 是该项目 dark theme 配色，实际根据业务调整。

1. **必须 `lastScrollTop = scrollTop` 同步**：离开时若不读取 DOM 当前位置，会出现"瞬移"。
2. **必须 `startTime = null` 重置**：不重置会出现"加速跳跃"。
3. **数据不足时停止**：`scrollHeight - clientHeight <= 0` 时调用 `stopAnimation()`，避免空转。
4. **进度条双层 linear-gradient**：第一层透明叠加是 IE 兼容 hack（项目里没用到，但保留以防需要）。
5. **滚动条 hover 渐显**：默认 `opacity: 0`，hover 时 `opacity: 1` + 蓝色渐变 + drop-shadow 发光，避免一直占视觉。
6. **`is-paused` class 控制 overflow**：暂停时仍可手动查看，配合 `overflow-y: auto`。
7. **resize 必须重新计算 maxScroll**：容器大小变化后 `scrollableHeight` 会变，否则滚动到底部判断失效。

## 变体提示

- **如果数据条数特别多（>50）**：复制首条到末尾做"内容接龙"，避免重置 0 时视觉跳变。
  ```js
  const loopedRankings = computed(() => [...rankings.value, rankings.value[0]]);
  ```
- **如果想要"滚动到底后停留几秒再重置"**：在 `lastScrollTop >= maxScroll` 时加 `setTimeout(reset, 2000)`。
- **如果是水平滚动（轮播图）**：把 `scrollTop` 改为 `scrollLeft`，`direction: column` 改为 `row`，其余逻辑不变。
- **如果是分页式滚动（每页 N 条）**：用 `Math.floor(lastScrollTop / itemHeight) * itemHeight` 锁定到整条目对齐位置。
- **如果数据源切换频繁**：把 `rankings` 改为 `watch` 监听的数据源 prop，每次变化都触发 `updateMaxScroll`。
- **如果想要自动反向滚到底再回到顶**：把 `delta` 加负号即可反向滚动，但需要单独处理 hover 续滚时的 `lastScrollTop` 边界。
