# 瀑布流布局 · 纵向（多列固定）

## 适用场景

固定列数的瀑布流，每列独立纵向排列。
适合：商品列表、笔记流、相册等多列等宽卡片。

## 核心思路

1. 外层 `.g-container`：`display: flex; flex-direction: row; justify-content: space-between`
2. 内层 `.g-queue`：`display: flex; flex-direction: column; flex-basis: 24%`
3. 每个 `.g-item` 自定义高度，纵向逐项堆叠

## 源码片段

```scss
.g-container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  overflow: hidden;
}

.g-queue {
  display: flex;
  flex-direction: column;
  flex-basis: 24%;
}

.g-item {
  position: relative;
  width: 100%;
  margin: 2.5% 0;
}
```

## 使用 SCSS 循环生成示例数据

```scss
$lineCount: 4;
$count: 8;

@function randomNum($max, $min: 0, $u: 1) {
  @return ($min + random($max)) * $u;
}

@function randomColor() {
  @return rgb(randomNum(255), randomNum(255), randomNum(255));
}

@for $i from 1 to $lineCount+1 {
  .g-queue:nth-child(#{$i}) {
    @for $j from 1 to $count+1 {
      .g-item:nth-child(#{$j}) {
        height: #{randomNum(300, 50)}px;
        background: randomColor();
      }
    }
  }
}
```

## 模板

```html
<view class="g-container">
  <view class="g-queue">
    <view class="g-item"></view>
    ... 8 个 item
  </view>
  ... 4 个 g-queue
</view>
```

## 实践提示

1. 列数固定时（如 2/3/4 列），用 `flex-basis: 24%` 等数值更可控。
2. 数据从接口获取时，建议在 `mounted` 中按列数切片赋值，避免回流。
3. 真·瀑布流（高度未知）需用 JS 计算最短列，可参考横向方案。
4. 图片懒加载可用 `<image lazy-load>`，减少首屏渲染压力。
