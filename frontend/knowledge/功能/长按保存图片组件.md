> H5 端**无相册 API**，本组件**不能**直接复用，需改为 `<a download>` 方案。

# 长按保存图片组件

## 背景

二维码、推广海报、用户头像等场景需要「长按图片保存到相册」。
uni-app 提供 `uni.saveImageToPhotosAlbum`，但**仅 App 端 + 部分小程序端**可用。

## 平台兼容

| 端 | 是否可用 | 说明 |
| --- | :-: | --- |
| H5 | ❌ | 无相册 API |
| 微信小程序 | ✅ | `uni.saveImageToPhotosAlbum`，需 download 域名白名单 |
| Android App | ✅ | 直接使用 |
| iOS App | ✅ | 需先申请 `NSPhotoLibraryAddUsageDescription` 权限 |

## API

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| url | String | '' | 待保存图片地址 |

| 事件 | 说明 |
| --- | --- |
| @hide | 点击背景关闭预览 |

## 模板结构

```html
<view class="preview-photo-box flex-box">
  <view class="preview-photo-bg" @tap="hide"></view>  <!-- 半透明遮罩 -->
  <view class="item tc">
    <image :src="url" mode="widthFix" @tap="hide" @longtap="toSave" />
  </view>
  <view class="download-img" @tap="save">
    <image src="/static/icon/download.png" />
  </view>
</view>
```

## 核心保存逻辑

```js
save() {
  uni.getImageInfo({
    src: this.url,
    success: (image) => {
      // 必须先用 getImageInfo 拿到本地路径
      uni.saveImageToPhotosAlbum({
        filePath: image.path,
        success: () => {
          uni.showToast({ title: '图片保存成功', icon: 'none', duration: 2200 })
        },
        fail: (err) => {
          // 用户拒绝相册权限
          if (err.errMsg.includes('auth')) {
            uni.showModal({
              title: '提示',
              content: '需要您授权保存到相册',
              success: (m) => {
                if (m.confirm) uni.openSetting()
              }
            })
          }
        }
      })
    }
  })
}

toSave() {
  uni.showModal({
    title: '图片保存',
    content: '确定要保存图片吗',
    success: (e) => { if (e.confirm) this.save() }
  })
}
```

## 必要权限配置（manifest.json）

```json
{
  "app-plus": {
    "distribute": {
      "ios": {
        "privacyDescription": {
          "NSPhotoLibraryAddUsageDescription": "保存图片到相册"
        }
      }
    }
  }
}
```

## H5 替代方案

```html
<a :href="url" download="poster.png">下载图片</a>
```

## 实践提示

1. `uni.saveImageToPhotosAlbum` 必须是**本地路径**，先用 `getImageInfo` 转换。
2. 网络图片需要服务端配置 CORS，否则 `getImageInfo` 失败。
3. iOS 必须配置 `NSPhotoLibraryAddUsageDescription`，否则闪退。
4. 用户拒绝授权时引导打开设置页：`uni.openSetting()`。
5. H5 没有相册 API，建议降级为「点击下载」+ `<a download>`。
