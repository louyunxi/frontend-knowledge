> ⚠️ 本知识仅适用于 **uni-app 自定义组件** 场景。
> 该组件使用 `<input type="number">` + `value` 双向同步，跨端时需注意 number 类型在 iOS 的兼容性，**不能**直接套到普通 Vue。

# 自定义验证码 / 密码输入框

## 背景

App 中常见的「6 位验证码」「6 位密码」UI 效果：
- 隐藏原生 input
- 把每格单独渲染为方块
- 根据 isPwd 决定显示数字还是圆点

## API

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| maxlength | Number | 4 | 4 或 6 |
| isPwd | Boolean | false | true 时显示圆点 |

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| finish | value: string | 输入达到 maxlength 触发 |

ref 方法：
- `$refs.code.clear()` 清空输入

## 模板结构

```html
<view class="code-area">
  <view class="flex-box">
    <!-- 隐藏的真 input -->
    <input :value="val" type="number" focus="true" :maxlength="maxlength"
           class="hide-input" @input="getVal" />
    <!-- 视觉位 -->
    <view :class="['item', { active: codeIndex == 1 }]">...</view>
    ...
  </view>
</view>
```

## 关键实现：拆分输入值

```js
getVal(e) {
  const { value } = e.detail
  this.val = value
  const arr = value.split('')
  this.codeIndex = arr.length + 1
  this.codeArr = arr
  if (this.codeIndex > Number(this.maxlength)) {
    this.$emit('finish', this.codeArr.join(''))
  }
}
```

## 完整用法

```html
<template>
  <view class="content">
    <view>验证码：</view>
    <validCode ref="code" :maxlength="4" :isPwd="false" @finish="getCode" />
    <view>密码：</view>
    <validCode ref="pwd" :maxlength="6" :isPwd="true" @finish="getPwd" />
    <button @tap="clearCode">清空验证码</button>
  </view>
</template>

<script>
export default {
  methods: {
    getCode(v) { console.log(v) },
    clearCode() { this.$refs.code.clear() }
  }
}
</script>
```

## 实践提示

1. `hide-input` 必须绝对定位覆盖整个视觉区域，否则点击视觉位不会弹出键盘。
2. `focus="true"` 让组件挂载后自动获得焦点；如需手动聚焦可改为 `:focus="isFocus"`。
3. `type="number"` 在 iOS 键盘上为纯数字键盘，**不显示字母**，密码场景慎用。
4. 密码模式可改用 `type="text" password` + 自行渲染圆点视觉。
5. 输入完成回调建议加 `vibrate` 反馈，提升输入体验。
