# 自由拖动按钮 (uni-drag-button)

> ⚠️ 本知识仅适用于 **uni-app 自定义组件**。核心使用 `touchstart / touchmove / touchend` + `changedTouches`，并通过 `uni.setStorageSync` 持久化位置。原生 H5 也可移植（保留 touch 事件，改 `position` 单位）。

## 实现原理

1. 根节点 `position: fixed` + `:style` 绑定 `bottom / right`
2. `touchstart` 记录起点 `pageX / pageY`
3. `touchmove` 计算位移增量，更新 `right -= dx` / `bottom -= dy`，并立即 `uni.setStorageSync`
4. `touchend` 释放
5. data 初始化时读取 `uni.getStorageSync('xy')`，恢复上次位置

## 关键代码

```html
<template>
  <view
    class="scan-fixed"
    :style="{ bottom: bottom + 'px', right: right + 'px' }"
    @touchstart="start"
    @touchmove="move"
    @touchend="end">
    <text class="icon">拖动</text>
  </view>
</template>

<script>
export default {
  data() {
    const xy = uni.getStorageSync('xy');
    return {
      bottom: xy ? xy.bottom : 100,
      right:  xy ? xy.right  : 15,
      pageX: 0,
      pageY: 0
    };
  },
  methods: {
    start(e) {
      const p = e.changedTouches[0];
      this.pageX = p.pageX;
      this.pageY = p.pageY;
    },
    move(e) {
      const p = e.changedTouches[0];
      const dx = p.pageX - this.pageX;
      const dy = p.pageY - this.pageY;
      this.pageX = p.pageX;
      this.pageY = p.pageY;
      this.right  -= dx;
      this.bottom -= dy;
      uni.setStorageSync('xy', { right: this.right, bottom: this.bottom });
    },
    end(e) { /* noop */ }
  }
};
</script>
```

```css
.scan-fixed {
  position: fixed;
  z-index: 9999;
  background: #ffffff;
  width: 50px;
  height: 50px;
  border-radius: 50%;
  display: flex;
  justify-content: center;
  align-items: center;
  box-shadow: 0 0 8px rgba(0, 0, 0, 0.5);
}
.icon {
  color: rgba(212, 48, 48, 1);
  font-size: 40upx;
  font-weight: bold;
}
```

## 设计要点

| 要点 | 说明 |
| ---- | ---- |
| `e.changedTouches[0]` | 多指触摸时只取第一根 |
| `right -= dx / bottom -= dy` | 注意屏幕坐标系方向 |
| `setStorageSync` 实时落盘 | 拖动结束不必再保存一次，但保险 |
| 阴影 + 圆形 + 50px | 经典 FAB 视觉 |
| z-index: 9999 | 压住所有业务 UI |

## 适用场景

- 客服 / 反馈悬浮按钮
- 返回顶部
- 一键截图 / 语音
- 拖拽式收藏入口

## 平台兼容性

- H5：✅
- 小程序：✅ 但需把 `@touchmove` 改为 `@touchmove.stop="move"` 阻止冒泡
- App：✅ 性能最佳

## 进阶

- 增加**边界检测**避免超出屏幕：`Math.max(0, Math.min(this.right, screenWidth - 50))`
- 增加**自动贴边**：松手时吸附到左/右边缘
- 适配 iPhone 安全区：`bottom: env(safe-area-inset-bottom)`
