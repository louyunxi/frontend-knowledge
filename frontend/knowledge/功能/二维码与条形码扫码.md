> ⚠️ 本知识仅适用于 **uni-app 自定义组件** 场景。
> 该组件使用了 **App-Plus 专用 API**（`plus.barcode`），H5 / 小程序**完全无法复用**。

# 二维码 / 条形码扫码组件

## 背景

`<scan>` 组件基于 `plus.barcode.create()` 创建原生扫码视图，**仅在 App 端**生效。
不依赖第三方扫码库，扫码速度与识别率均优于 Web 端方案。

## 平台兼容

| 端 | 是否可用 | 说明 |
| --- | :-: | --- |
| H5 | ❌ | 没有原生扫码 API |
| 微信小程序 | ❌ | 需使用 wx.scanCode，无法自定义扫码 UI |
| Android App | ✅ | 直接使用 `plus.barcode` |
| iOS App | ✅ | 直接使用 `plus.barcode` |

## 使用方法

```html
<template>
  <view>
    <scan @getCode="onScan" />
  </view>
</template>

<script>
export default {
  methods: {
    onScan(val) {
      uni.showToast({ title: '扫码结果：' + val, icon: 'none' })
    }
  }
}
</script>
```

## 关键 API

### plus.barcode.create(id, filters, styles)

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | String | 扫码视图 ID |
| filters | Array | 识别码类型数组 |
| styles | Object | top/left/width/height/position |

支持的码类型：

```js
[
  plus.barcode.QR,        // 二维码
  plus.barcode.EAN13,     // EAN13 条形码
  plus.barcode.EAN8,      // EAN8 条形码
  plus.barcode.UPCA,      // UPC-A
  plus.barcode.UPCE,      // UPC-E
  plus.barcode.CODABAR,   // 库德巴码
  plus.barcode.CODE39,    // Code 39
  plus.barcode.CODE93,    // Code 93
  plus.barcode.CODE128,   // Code 128
  plus.barcode.ITF        // ITF 码
]
```

### 生命周期挂载

```js
created() {
  const page = getCurrentPages()[getCurrentPages().length - 1]
  const webview = page.$getAppWebview()
  this.barcode = plus.barcode.create('barcode', filters, {
    top: '0', left: '0px', width: '100%', height: '120px', position: 'static'
  })
  this.barcode.onmarked = this.onmarked
  webview.append(this.barcode)
}
```

## 核心：scan.vue 源码要点

```js
// 仅 Android 需要手动 start，iOS 自动开启
if (uni.getSystemInfoSync().platform === 'android') {
  this.barcode.start()
}

// 识别回调
onmarked(type, result) {
  this.$emit('getCode', result)
  setTimeout(() => this.barcode.start(), 1000) // 防抖，连续扫码
}
```

## 必要配置（manifest.json）

```json
{
  "app-plus": {
    "distribute": {
      "android": {
        "permissions": [
          "<uses-permission android:name=\"android.permission.CAMERA\"/>",
          "<uses-permission android:name=\"android.permission.VIBRATE\"/>"
        ]
      }
    }
  }
}
```

> ⚠️ 忘记声明 CAMERA 权限将导致 Android 黑屏或闪退！

## 实践提示

1. 在 `manifest.json` 必加相机权限，否则部分 Android 机型无相机权限。
2. `position: 'static'` 让扫码框跟随页面滚动，避免遮挡。
3. 连续扫码场景必须 `setTimeout` 延迟重启，避免重复回调。
4. 自定义扫码框需要叠加 `image` + 透明遮罩在 `barcode` 上层。
5. 小程序替代方案：`uni.scanCode({ success: r => r.result })`。
