# 自定义数字键盘 (digitKeyboard)

> ⚠️ 本知识仅适用于 **uni-app 自定义组件**。遮罩层 + `flex` 网格键盘面板 + `numberPrecision.js` 处理浮点精度，是 uniapp 社区最常见的"金额输入键盘"实现。

## 实现原理

- 根节点 `position: fixed; z-index: 999` 全屏遮罩
- 半透明 `.digit-keyboard_bg` 点击触发 `@tap="hide"`（关闭键盘）
- 底部 `.digit-keyboard_area` 通过 `position: absolute; bottom: 0` 固定
- 键盘项 `flex: 0 0 22%` 每行排 4 个
- 通过 `modifyNum(sign)` 处理 0-9、`.`、`-`、`del`、`add`、`minus`、`clear` 七类指令
- 使用 `numberPrecision.js` 避免 `0.1 + 0.2` 的坑

## Props

| Prop | 类型 | 默认 | 说明 |
| ---- | ---- | ---- | ---- |
| `inputVal` | String | `''` | 输入框 placeholder / 提示值 |
| `label` | String | `'现金'` | 输入框前说明文字 |

## Events

| 事件 | 回调参数 | 说明 |
| ---- | -------- | ---- |
| `@cancel` | — | 点击遮罩或取消时触发 |
| `@confirm` | 最终值（已去掉尾随 `.`） | 点击"确定"时触发 |

## 关键代码

```js
import NP from '@/util/numberPrecision/numberPrecision.js';

modifyNum(sign) {
  let { val } = this;
  if (sign === 'del') {
    val = val.length ? val.slice(0, -1) : '';
  } else if (sign === 'add') {
    val = NP.plus(Number(val), 1) + '';
  } else if (sign === 'minus') {
    val = NP.minus(Number(val), 1) + '';
  } else if (sign === 'clear') {
    val = '';
  } else if (sign === '-') {
    if (val.indexOf('-') === -1) val = '-' + val;
  } else if (sign === '.') {
    if (val.indexOf('.') === -1 && val.length > 0) val = val + '.';
  } else {
    // 防止连续多个 0 或前导 0
    if ((val === '0' || val === '-0') && sign === '0') return;
    if ((val === '0' || val === '-0') && sign !== '.') return;
    val = val + sign;
  }
  // 小数点后最多 3 位
  const arr = val.split('.');
  if (arr.length === 2 && arr[1].length > 3) return;
  this.val = val;
}

confirm() {
  let val = this.val;
  if (val.slice(-1) === '.') val = val.slice(0, -1);
  this.$emit('confirm', val);
}
```

## 设计要点

| 要点 | 说明 |
| ---- | ---- |
| 键盘项 `flex: 0 0 22%` | 留出 4% 间距，四列均分 |
| `label` 单独占位 | 方便业务方自定义如 "现金支付" |
| `numberPrecision` | 解决浮点 `0.1+0.2=0.30000000000000004` |
| 小数位 3 位封顶 | 适配金额场景 |
| `confirm` 中去除末尾 `.` | 防止用户输入 "12." 时直接提交 |

## 适用场景

- 收银台金额输入
- 提现金额输入
- 表单中需要数字输入且要避开系统键盘

## 平台兼容性

- H5：✅
- 小程序：✅ 但 `<icon type="cancel">` 在 mp-weixin 中显示差异大，建议替换为 `<text>×</text>` 或自定义图片
- App：✅
