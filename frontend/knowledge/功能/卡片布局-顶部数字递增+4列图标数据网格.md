# 卡片布局 - 顶部数字递增 (count-to) + 4 列图标数据网格

## 概述

**数字递增 + 4 列图标数据网格**是政务大屏最常见的"一个总览数字 + 几个子项"的展示模板：

- **顶部主指标**：`<count-to>` 组件从 0 数字递增动画到 `endVal`（支持小数），左侧 label + 中间大数字 + 右侧单位
- **主副信息行**（`txt`）：主指标下面的次要说明，例如 `产值：1234 元`
- **下方主体**：4 列等宽 grid，每列 = `图标 + 名称 + 数值/单位`
- **`slice(0, 4)`**：最多展示 4 条；少于 4 条时按 flex 等分剩余宽度
- **依赖 `vue-count-to@1.0.13`**：项目内 `@/components/common/countTo` 二次封装

**适用场景**：

- 关键 KPI 面板（总产值、企业数、人口数 等）
- 单卡片有 1 个主指标 + 多个子指标
- 数字变化需要"从 0 跑起来"的视觉冲击
- 单卡片 1-4 条数据

**关键特征**：

- ✅ `<count-to>` 替代 `{{ value }}`（数字递增）
- ✅ `decimals: getDecimalTotal`——小数位数由数据自动适配
- ✅ `useEasing: false`——线性递增，更直观
- ✅ `:i-size="30"`——大字号
- ✅ `:multi-len="0"`——不显示千分位
- ✅ BEM 命名 `.production` / `.production-img` / `.production-output`

### script

```js
import CountTo from "@/components/common/countTo";
import { REG_DECIMAL } from "@/utils/config";

export default {
  name: "CardCountTo4Grid",
  components: { CountTo },
  props: {
    plateVO: { type: Object, default: () => ({}) }
  },
  data() {
    return {
      list: {
        title: null,
        total: null,
        unit: null,
        listVo: { name: null, total: null, unit: null }
      },
      dataList: []
    };
  },
  computed: {
    // 自动判断保留几位小数
    getDecimalTotal() {
      const decimalMatch = String(this.list.total).match(REG_DECIMAL);
      return decimalMatch ? decimalMatch[1].length : 0;
    }
  },
  methods: {
    initModule() {
      const { plateMetricGroupList } = this.plateVO;
      this.list.title = plateMetricGroupList[0]?.metricGroupName;
      this.list.total = plateMetricGroupList[0]?.metricGroupValue;
      this.list.unit = plateMetricGroupList[0]?.metricGroupUnit;
      this.dataList = plateMetricGroupList[0]?.plateMetricList || [];
    }
  },
  watch: {
    "$attrs.loading": {
      immediate: true,
      handler(v) {
        if (!v) this.$nextTick(() => this.initModule());
      }
    }
  }
};
```

## `<count-to>` Props 说明

| Prop           | 类型                | 默认      | 说明                                       |
| -------------- | ----------------- | ------- | ---------------------------------------- |
| `startVal`     | Number            | 0       | 起始值，建议固定为 `0`                           |
| `endVal`       | Number            | 必须      | 目标值，从业务数据取                                |
| `decimals`     | Number            | 0       | 保留几位小数                                    |
| `duration`     | Number            | 2.0     | 动画时长（秒）                                   |
| `useEasing`    | Boolean           | true    | 是否使用缓动曲线；**大屏场景建议 `false`**（更直观）       |
| `useGrouping`  | Boolean           | true    | 是否千分位分隔                                   |
| `separator`    | String            | ','     | 千分位分隔符                                    |
| `decimal`      | String            | '.'     | 小数点                                        |
| `i-size`       | Number / String   | 'auto'  | 数字字号                                       |
| `no-bg-style`  | Boolean           | false   | 是否去掉默认背景（本卡片必备，否则会与卡片背景冲突）              |
| `multi-len`    | Number            | 0       | 千分位生效最小长度（数字位数 >= 此值才显示分隔）               |

## `getDecimalTotal` 计算属性

```js
// utils/config.js
export const REG_DECIMAL = /\.(\d+)/;   // 捕获小数部分

// computed
getDecimalTotal() {
  const decimalMatch = String(this.list.total).match(REG_DECIMAL);
  return decimalMatch ? decimalMatch[1].length : 0;
}
```

- `"123"   -> 0`（小数 0 位）
- `"123.4" -> 1`（小数 1 位）
- `"123.45"-> 2`（小数 2 位）

让 count-to 自动适配数据精度。

## 关键设计要点

### 1. `no-bg-style` 必须

`<count-to>` 默认会渲染带背景的 DOM，与 GSPlate 卡片背景冲突，必须加 `no-bg-style`。

### 2. `useEasing: false` 推荐

Easing 曲线（默认 ease-out）会让数字从快到慢结束，对"实时数据"看起来"卡住了"；线性递增更直观。

### 3. `slice(0, 4)` 兜底

```vue
v-for="(item, index) in dataList.slice(0, 4)"
```

即使数据大于 4 条，也只渲染前 4 条，避免卡片高度溢出。

### 4. `flex: 1` 自动等分

```scss
.production { width: calc(100% / 4); }
.production-wrap { flex: 1; display: flex; }
```

`flex: 1` 让 `.production-wrap` 占满剩下空间，每条按 25% 排列；数据少于 4 时 flex 自动均分。

### 5. 数字置 0 后再显示

```vue
<count-to v-if="list.total" :endVal="Number(list.total)" ...></count-to>
```

**必须等数据回来再渲染**，否则 `:endVal="undefined"` 会出错。

### 6. 主副信息行

```vue
<span class="txt">
  {{ list.listVo.total ? list.listVo.name + "：" : list.listVo.name }}
  <i>{{ list.listVo.total }}{{ list.listVo.unit }}</i>
</span>
```

- 仅展示 `名称`：`total` 为空时
- 展示 `名称: 数值`：有 `total` 时
