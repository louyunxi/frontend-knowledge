# 卡片布局 - 顶部主指标 + Vue Awesome Swiper 居中轮播 + 自定义分页

## 概述

**主指标 + Swiper 居中卡片**是政务大屏中"宽卡片展示大量子项目"的常见布局：

- **顶部主指标**：大字号 label + value + unit（左中右水平排列）
- **主体**：vue-awesome-swiper 横向轮播，使用 `centeredSlides: true` 实现"中间一张最大，两侧 peek 出左右边缘"的效果
- **`loop: true + autoplay: 5s`**：循环无限滚动 + 自动播放
- **自定义 pagination bullet**：默认 bullet 太丑，用 `::v-deep div[class^="swiper-pagination-..."]` 选择器覆盖颜色（active 用主色 cyan，inactive 用半透明色）
- **卡片内部 Aniupdown 浮动动画**：左侧图标用 `@keyframes Aniupdown` 上下浮动，模拟"展示中"的感觉

**适用场景**：

- 河段/地块/水库 等"卡片较长、展示约 6-12 条" 的列表
- 需要居中聚焦 + 左右 peek 邻近项的轮播
- 强调视觉卡牌 + 浮动动画
- 需要分页指示器但不想用 Element 默认 dot

**关键特征**：

- ✅ `slidesPerView: 'auto' + spaceBetween: 10`——slide 宽度按内容计算
- ✅ `centeredSlides: true`——当前位置永远居中
- ✅ `loop: dataList.length > 1 ? true : false`——分页不足 2 个时不开启 loop
- ✅ `autoplay: { delay: 5000, disableOnInteraction: false }`——用户操作后依然自动播放
- ✅ `pagination.el` 用组件 `id` 动态生成独立分页节点
- ✅ `::v-deep` 选择自定义分页
- ✅ `@keyframes Aniupdown { 0/100% { transform: translateY(0); } 50% { translateY(-20%); } }`
- ✅ `@media (max-width: 1680px)` 缩小字号与卡片尺寸

## 完整代码

### template

```vue
<GSPlate v-bind="$attrs">
  <div class="box-content full-box">
    <!-- 顶部主指标 -->
    <div class="content-des" v-if="!loading">
      <p class="content-des__label">{{ title }}</p>
      <p class="content-des__value">{{ totalCount }}</p>
      <p class="content-des__unit">{{ unit }}</p>
    </div>

    <!-- 主体 Swiper 居中轮播 -->
    <div class="swiper-box" v-if="dataList.length">
      <div class="bs-swiper-container">
        <swiper class="full-box" :options="swiperOption">
          <swiper-slide v-for="(item, index) in dataList" :key="index">
            <div class="slide-item">
              <div class="production-img">
                <img :src="item.plateIconUrl" alt="" />
              </div>
              <div class="production-facility">
                <span class="name">{{ item.metricGroupName }}</span>
                <span class="total">
                  {{ item.metricGroupValue }}
                  <span class="unit">{{ item.metricGroupUnit }}</span>
                </span>
                <div
                  class="ite-box"
                  v-for="(ite, ind) in item.plateMetricList.slice(0, 2)"
                  :key="ind"
                >
                  <span>{{ ite.metricName }}：{{ ite.metricValue }}{{ ite.metricUnit }}</span>
                </div>
              </div>
            </div>
          </swiper-slide>
        </swiper>

        <div
          v-if="dataList.length > 1"
          :class="pgClassName"
          slot="pagination"
        ></div>
      </div>
    </div>
  </div>
</GSPlate>
```

### script

```js
import { arrTrans } from "@/utils/utils";

export default {
  name: "CardHeroSwiper",
  props: {
    plateVO: { type: Object, default: () => ({}) }
  },
  data() {
    return {
      swiperOption: {
        slidesPerView: "auto",
        spaceBetween: 10,
        initialSlide: 0,
        centeredSlides: true,
        loop: true,
        autoplay: {
          delay: 5000,
          stopOnLastSlide: false,
          disableOnInteraction: false
        },
        pagination: {
          el: ""
        }
      },
      totalCount: null,
      unit: null,
      title: "",
      loading: true,
      dataList: [],
      pgClassName: ""
    };
  },
  methods: {
    async initModule() {
      await this.$nextTick();
      this.loading = true;
      const { plateMetricGroupList } = this.plateVO;
      const arrLen = 2;
      this.dataList = arrTrans(arrLen, plateMetricGroupList.slice(1));
      this.swiperOption.loop = this.dataList.length > 1 ? true : false;

      // 用组件 id 拼接一个独立分页节点，避免多个卡片 swiper 分页冲突
      this.pgClassName =
        "swiper-pagination-" +
        this.plateVO.plateTemplateIdentifier +
        "-" +
        plateMetricGroupList[0].id;
      this.swiperOption.pagination.el =
        "." +
        "swiper-pagination-" +
        this.plateVO.plateTemplateIdentifier +
        "-" +
        plateMetricGroupList[0].id;

      this.totalCount =
        plateMetricGroupList[0]?.plateMetricList[0]?.metricValue || "";
      this.title =
        plateMetricGroupList[0]?.plateMetricList[0]?.metricName || "";
      this.unit =
        plateMetricGroupList[0]?.plateMetricList[0]?.metricUnit || "";
      this.loading = false;
    }
  },
  watch: {
    "$attrs.loading": {
      immediate: true,
      handler(v) {
        if (!v) this.$nextTick(() => this.initModule());
      }
    }
  }
};
```

## 关键设计要点

### 1. `pagination.el` 用组件 id 动态生成

```js
pgClassName = "swiper-pagination-" + uniqueId;
swiperOption.pagination.el = "." + pgClassName;
```

> 原因：页面里可能同时存在多个卡片 swiper，固定 class 会冲突；用业务 id 拼接独立 className 保证每个 swiper 分页独立 DOM。

### 2. `::v-deep` 选择器穿透

```scss
::v-deep div[class^="swiper-pagination-BKMB"] { ... }
```

> swiper 的 bullet DOM 是 Swiper 子组件渲染的，scoped 选择器匹配不到，必须用 `::v-deep`（vue 2 写法）或 `:deep()`（vue 3 写法）穿透。

### 3. `loop: dataList.length > 1`

```js
this.swiperOption.loop = this.dataList.length > 1 ? true : false;
```

> vue-awesome-swiper 在分页只有 1 个时开启 loop 会报错或行为异常，必须关闭。

### 4. `disableOnInteraction: false`

```js
autoplay: { delay: 5000, disableOnInteraction: false }
```

> 用户点击 bullet 后依然自动播放（避免误操作后停止）。

### 5. Aniupdown 动画循环方向

```scss
@keyframes Aniupdown {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(-20%); }   // 上
  100% { transform: translateY(0); }
}
```

> ease-in-out 更自然；2.6s 周期符合大屏动效的"克制风格"。

### 6. 1680px 适配

卡片宽度 `100%` 会按屏幕缩放，但字号/间距要响应式微调——大屏常用 `@media (max-width: 1680px)` 是 1080p 与 2K 的分界。

## 变体

| 变体     | 差异                                       |
| ------ | ---------------------------------------- |
| 卡片内容只有文字 | 删 `.production-img`，纯 文字版                    |
| 卡片可点击   | `<swiper-slide>` 包 `<a>` 或 @click         |
| 非循环    | `loop: false` + 左右箭头                       |
| 缩略图纵向   | `direction: 'vertical'` + vertical 分页        |
| 自动播放间隔  | `delay: 3000~8000`，根据内容阅读时长              |
