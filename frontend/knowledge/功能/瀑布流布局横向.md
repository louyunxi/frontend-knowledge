# 瀑布流布局 · 横向数据（高度未知）

## 适用场景

- 数据顺序固定，但卡片高度参差不齐
- 希望以「整体按行流动 + 自动换列」的视觉呈现
- 适合：搜索结果流、瀑布流图片墙

## 核心三招

### 1. 容器定高 + column wrap

```scss
.container {
  display: flex;
  flex-flow: column wrap;
  align-content: space-between;
  height: 1660px;       /* 关键：必须固定高度，且大于最高列 */
  padding: 20px;
  box-sizing: border-box;
}
```

### 2. order 重排成 3 列

```scss
.item { width: 32%; margin-bottom: 2%; }

.item:nth-child(3n+1) { order: 1; }
.item:nth-child(3n+2) { order: 2; }
.item:nth-child(3n)   { order: 3; }
```

### 3. 强制换列（伪元素占满整行）

```scss
.container::before,
.container::after {
  content: "";
  flex-basis: 100%;
  width: 0;
  order: 2;
}
```

## 模板

```html
<view class="container">
  <view class="item" style="height: 140px"></view>
  <view class="item" style="height: 190px"></view>
  ... 多个高度不一的 item
</view>
```

## 与「纵向瀑布流」的差异

| 维度 | 纵向 | 横向（高度未知） |
| --- | --- | --- |
| 数据流 | 每列独立追加 | 单向数据流，按 order 重排 |
| 容器高度 | 自适应 | **必须固定**，大于最高列 |
| 适合 | 已知列数 | 高度差异大 |
| 性能 | 略优 | 略差（需 order 计算） |

## 实践提示

1. **容器高度是关键**：一定要大于等于「单列总高度」。
2. 若不知道容器高度，可用 JS 计算：`高度 = ceil(item总数/列数) * 平均高度 + padding`。
3. `flex-basis: 100%` 的伪元素是「强制换列」的经典技巧。
4. 真·最佳实践是先计算「最短列」再 append，但本方案已能覆盖 80% 场景。
