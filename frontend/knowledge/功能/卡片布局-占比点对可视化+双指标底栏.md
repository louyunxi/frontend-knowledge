# 卡片布局 - 占比点对可视化（双层配对图标 + 比例底部说明）

## 概述

**占比点对可视化**是政务大屏"比例说明"的趣味展示模板：

- **顶部主指标**：标题 + 大数值 + 单位
- **中部双层 N 个小图标**：
  - 底层显示一组 icon（占满 N 个）作为"背景"
  - 顶层叠放另一组 icon（占满 N 个）作为"前景"
  - 根据比例计算，让其中一类的部分 icon 透明度=0（CSS class `townPeoOp0 { opacity: 0; }`）
  - 形成"双层配对"的对比视觉，类似饼图但更感性
- **男/女 icon 标题行**：每类配一图标 + 类别名 + 数值 + 单位（左右各一组）
- **底部双列文字指标**：2 列等宽图标 + 名称 + 数值 单位，常用于补充统计数据

**适用场景**：

- 比例/占比趣味展示（男女人口、城乡比、年龄结构等）
- 单纯百分比饼图显得过于严肃，需要"感性"
- 单卡片需要展示 1 个总量 + 1 个比例 + 2-3 个补充数据

**关键特征**：

- ✅ 双层 `<div class="selfsex">` 互相 absolute 叠放
- ✅ 每个点用 `v-for="(item, idx) in 24"` 生成 N 个等宽
- ✅ `townPeoOp0 { opacity: 0 }` 控制底层/顶层点
- ✅ `isNanMore.munMan = round(percent / 100 * 24)` 自动换算点数
- ✅ `isShow: !!genderList.length > 1` 比例缺失时整段隐藏

### script

```js
export default {
  name: "CardProportionPair",
  props: {
    plateVO: { type: Object, default: () => ({}) }
  },
  data() {
    return {
      list: {
        title: null,
        totalAcre: null,
        unit: null,
        genderList: [
          { metricValue: null },
          { metricValue: null }
        ]
      },
      populationList: [],
      // 三类 icon 来自项目 assets（实际项目用 require("@/assets/...")）
      bgIcon: "/icon/women.png",
      fgIcon: "/icon/man.png",
      manIcon: "/icon/man.png",
      womanIcon: "/icon/woman.png"
    };
  },
  computed: {
    // 比例点数换算
    isNanMore() {
      const opts = { isShow: false, munMan: 0, munWom: 0 };
      if (this.list.genderList.length > 1) {
        const a =
          Number(this.list.genderList[0].metricValue) +
          Number(this.list.genderList[1].metricValue);
        const b = this.list.genderList[0].metricValue;          // 男占比
        const percentMan = ((b / a) * 100).toFixed(2) + "%";
        const munMan = Number(((parseFloat(percentMan) / 100) * 24).toFixed(0));
        const munWom = 24 - munMan;
        opts.munMan = munMan;
        opts.munWom = munWom;
        opts.isShow = true;
      } else {
        opts.isShow = false;
      }
      return opts;
    }
  },
  methods: {
    initModule() {
      const { plateMetricGroupList } = this.plateVO;
      this.list.title = plateMetricGroupList[0].metricGroupName;
      this.list.totalAcre = plateMetricGroupList[0].metricGroupValue;
      this.list.unit = plateMetricGroupList[0].metricGroupUnit;
      this.list.genderList = plateMetricGroupList[0].plateMetricList;
      this.populationList = plateMetricGroupList[1]?.plateMetricList ?? [];
    }
  },
  watch: {
    "$attrs.loading": {
      immediate: true,
      handler(v) {
        if (!v) this.$nextTick(() => this.initModule());
      }
    }
  }
};
```

## 关键设计要点

### 1. N 个点的双层叠放

```vue
<!-- 底层：占满 N 个 -->
<div class="selfsex selfsexBg">
  <span v-for="(item, idx) in 24" :key="item"
        :class="{ townPeoOp0: idx < isNanMore.munMan }">
    <img :src="bgIcon" />
  </span>
</div>
<!-- 顶层：absolute 完全覆盖底层 -->
<div class="selfsex selfsexFg">
  <span v-for="(item, index) in 24" :key="item"
        :class="{ townPeoOp0: index >= isNanMore.munMan }">
    <img :src="fgIcon" />
  </span>
</div>
```

- `idx < munMan`：底层的前 `munMan` 个点隐藏 → 让给前景显示
- `index >= munMan`：顶层的后 `24 - munMan` 个点隐藏 → 让底层显示
- 两者重叠展示"前景 + 背景"，数字驱动的对比

### 2. 比例 → 点数换算

```js
const a = genderList[0].metricValue + genderList[1].metricValue;
const b = genderList[0].metricValue;           // 男占比分子
const percentMan = (b / a) * 100;
const munMan = round((percentMan / 100) * 24);
```

- 24 是经验值（人眼可辨认的密度极限）
- 数据是百分数 → 比例换算
- 实际业务可换成 50/100 等更大点数

### 3. 缺失数据降级

```js
isNanMore() {
  return {
    isShow: this.list.genderList.length > 1
  };
}
```

- `genderList.length <= 1`：整段比例图 + 男/女 icon 行隐藏
- `populationList.length === 0`：底部双列隐藏
- 避免空数据页面布局错乱

### 4. `space-around` 等距分布

```scss
.selfsex { display: flex; justify-content: space-around; }
```

- 24 个点等距分布在卡片宽度内
- 每个点宽度 `15px`，间距自动计算
- 不要用 `space-between`：会让首尾靠边

### 5. `opacity: 0` 而非 `display: none`

```scss
.townPeoOp0 { opacity: 0; }
```

- `opacity: 0` 保留 DOM（不抖动），仅"透明"
- `display: none` 会让其他点 reflow
- 适合"上层叠遮"的对比效果

## 变体

| 变体       | 差异                                       |
| -------- | ---------------------------------------- |
| 三层多比例   | 三层 `<div class="selfsex">` 分别表示 A/B/C 比例   |
| 大点数    | `v-for="(item, idx) in 50"` 50 点更精细        |
| 圆点替代图标 | `.townPeo` 用 `<div class="dot"></div>` + 圆形   |
| 渐变色背景   | `.townPeo` 加 `background: linear-gradient(...)` |
| 数值变文本说明 | `isNanMore.munMan > 12 ? "男性偏多" : "女性偏多"`     |

## 适用 vs 不适用

**适用**

- 数据有清晰二元对比（男/女、城/乡、用户/管理员）
- 单卡片内容 ≤ 5 个区块
- 希望"感性化"比例展示

**不适用**

- 类别 ≥ 3 种（用饼图更清晰）
- 极小屏幕（点会重叠看不清）
- 数据精度要求高（饼图数值标签更精准）
