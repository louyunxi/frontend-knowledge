# 模拟电池充电动效

> ⚠️ 本知识仅适用于 **uni-app 自定义组件**。核心是 `setInterval` 循环更新一个计数器，再用 `flex-direction: column; justify-content: flex-end` 让方块"从下往上"堆叠成电池条。原生 Vue 中可同样使用（去掉 `upx` 单位即可）。

## 实现原理

1. data 中声明 `plannum: 5` 作为当前充入的"格数"
2. `created` 中 `setInterval` 每 1000ms 让 `plannum` 在 `1~5` 之间循环
3. 模板中 `v-for` 渲染 `plannum` 个 `<view class="line">`
4. `destroyed` 中必须 `clearInterval` 释放定时器，避免内存泄漏

## 关键代码

```html
<template>
  <view class="battery-area">
    <view class="line" v-for="i in plannum" :key="i"></view>
  </view>
</template>
```

```js
export default {
  data() { return { plannum: 5 }; },
  created() {
    this.refreshTime = setInterval(() => {
      let numNew = this.plannum + 1;
      this.plannum = numNew % 6;
      if (!this.plannum) this.plannum = 1;
    }, 1000);
  },
  destroyed() {
    clearInterval(this.refreshTime);
  }
}
```

```css
.battery-area {
  width: 14upx;
  height: 72upx;
  background: #FFFFFF;
  border-radius: 6upx;
  border: 2upx solid #ff4300;
  padding: 8upx 2upx;
  box-sizing: border-box;
  display: flex;
  flex-direction: column;
  justify-content: flex-end; /* 关键：从底部堆叠 */
}

.battery-area .line {
  width: 100%;
  height: 8upx;
  background: #ff4300;
  margin-top: 3upx;
}

.battery-area .line:first-child { margin-top: 0; }
```

## 设计要点

| 要点 | 取值 | 说明 |
| ---- | ---- | ---- |
| 电池外壳尺寸 | 14upx × 72upx | 配合 5 段 + padding |
| 内部 padding | `8upx 2upx` | 留出边框与内容间距 |
| flex-direction | `column` | 竖直堆叠 |
| justify-content | `flex-end` | 让格线从底部向上生长 |
| 间隔 | `3upx` | 每格之间的呼吸感 |
| 周期 | `1s` 循环 1→5→1 | 平滑不刺眼 |

## 适用场景

- 低电量/充电中动画状态
- 排行榜"进度条"风格
- 加载等待装饰

## 平台兼容性

- H5 / 小程序：✅
- App：✅（nvue 中 flex 方向同样支持）
