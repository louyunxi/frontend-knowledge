# 动效缓动与设计哲学

## 1. Disney 12 动效原则

| 原则 | 说明 | UI 应用 |
|------|------|---------|
| **Squash & Stretch** | 压缩拉伸赋予重量感 | 按钮按压、弹性反馈 |
| **Anticipation** | 预备动作引导预期 | Hover 前先轻微放大 |
| **Staging** | 控制视觉焦点 | 入场时其他元素静止 |
| **Straight Ahead vs Pose** | 逐帧 vs 关键帧 | 简单动画直进，复杂动画关键帧 |
| **Follow Through** | 惯性超调再回落 | 关闭面板时惯性滑出 |
| **Slow In & Slow Out** | 自然加减速 | 所有 UI 过渡 |
| **Arcs** | 弧线运动更自然 | 元素不直线移动 |
| **Secondary Action** | 次级动作强化主动作 | 卡片飞入时影子追随 |
| **Timing** | 时长传递重量 | 大元素慢，小元素快 |
| **Exaggeration** | 夸张强化表达 | 成功动画明显放大 |
| **Solid Drawing** | 立体感 | 3D 透视、阴影层次 |
| **Appeal** | 吸引力和亲和力 | 圆润边角、友好色彩 |

| 名称 | cubic-bezier | 用途 |

| `ease` | `[0.4, 0, 0.2, 1]` | 标准 UI |

### 时长参考

| 动画类型 | 推荐时长 | 缓动 |
|----------|----------|------|
| 微交互 | 100-200ms | `ease-out` |
| 按钮 Hover | 150-250ms | `ease` |
| Modal 打开 | 200-300ms | `ease-out` |
| Modal 关闭 | 150-200ms | `ease-in` |
| 页面过渡 | 300-500ms | `ease-in-out` |
| 加载循环 | 1000-2000ms | `linear` / `ease-in-out` |
| 强调动画 | 500-1000ms | `elastic` |

## 3. 设计哲学

### Digital Brutalism 粗野主义

**核心理念**：原始、诚实、无修饰。暴露结构，功能即美学。刻意的不适感。

#### 动效模式

- **硬切**：无缓动，`ease: 'none'` 或 `duration: 0`，状态瞬间切换
- **突兀过渡**：`steps()` 缓动，突然位移，刻意的卡顿
- **禁用平滑滚动**：原生滚动。粗野区域禁用 Lenis
- **激进 stagger**：大延迟（0.3-0.5s），非均匀时序
- **超大动效**：元素移动 200-400% 视口，无微妙感

#### 字体

- 等宽字体：`monospace`、`JetBrains Mono`、`Space Mono`
- 超大尺寸：Hero 文字 15-30vw
- 紧凑行高：`line-height: 0.8-0.9`
- 重叠：负 margin，元素相互渗透

#### 布局

- 破损栅格：不对称、重叠、超出屏幕
- 可见边框：`border: 2px solid`
- 纯色背景：纯黑、纯白或单一强调色
- 无圆角：锐利边角

#### 代码示例

```tsx
gsap.to(el, { x: 500, duration: 0, ease: 'none' })
gsap.to(el, { rotation: 90, duration: 0.1, ease: 'steps(3)' })
gsap.to(el, { scale: 3, duration: 0.05 })
```

#### 配色

| 颜色 | Hex | 用途 |
|------|-----|------|
| 纯黑 | `#000000` | 背景、文字 |
| 纯白 | `#FFFFFF` | 背景、文字 |
| 酸绿 | `#BAFF39` | 强调 |
| 电蓝 | `#0000FF` | 替代强调 |
| 警示红 | `#FF0000` | 替代强调 |

### Minimalism 极简主义

**核心理念**：少即是多。每个元素都有目的。动效传递信息，从不装饰。

#### 动效模式

- **缓出**：`power2.out` 或 `[0.16, 1, 0.3, 1]`，永不平滑，永不弹跳
- **微妙缩放**：最大 1.02-1.05 变化，几乎不可感知
- **仅透明度**：许多过渡只需 `opacity: 0 → 1`
- **长时长**：主动画 800-1500ms，次要动画 300-500ms
- **单一属性**：一次只动画一个属性，从不同时动画 x + y + scale + opacity

#### 字体

- 无衬线：`Inter`、`Helvetica Neue`
- 轻字重：Body 200-400，emphasis 500-600（绝不用 900）
- 大间距：`letter-spacing: 0.1-0.3em` 用于标题
- 大行高：`line-height: 1.6-1.8`

#### 布局

- 大量留白：40-60% 视口应为空
- 严格栅格：12 列或 8 列，始终对齐
- 无装饰元素：不传递信息就删除
- 单色或最多两色

#### 代码示例

```tsx
<motion.div
  initial={{ opacity: 0 }}
  animate={{ opacity: 1 }}
  transition={{ duration: 1.2, ease: [0.16, 1, 0.3, 1] }}
/>

<motion.a whileHover={{ opacity: 0.6 }} transition={{ duration: 0.3 }} />
```

#### 配色

| 颜色 | Hex | 用途 |
|------|-----|------|
| 米白 | `#FAFAF9` | 背景 |
| 暖灰 | `#A8A29E` | 次要文字 |
| 炭灰 | `#1C1917` | 主要文字 |
| 石灰 | `#E7E5E4` | 边框、分隔线 |
| 淡灰 | `#D4D4D8` | Hover 状态 |

### Abstract / Generative 抽象 / 生成艺术

**核心理念**：非具象之美。数学即美学。算法生成有机感。

#### 动效模式

- **噪声驱动**：Perlin/Simplex 噪声控制位置、缩放、旋转。不可预测
- **参数化运动**：正弦/余弦组合创造有机循环
- **无限循环**：`repeat: -1`，永不静止的艺术
- **涌现行为**：简单规则 → 复杂视觉（蜂群、细胞自动机）
- **缓慢演化**：变化发生在 10-60 秒后，耐心得到回报

#### 视觉语言

- 形状：圆形、流动曲线、粒子系统，避免矩形
- 色彩：渐变、色相旋转、噪声映射调色板
- 纹理：颗粒、噪声叠加、位移贴图
- 尺度：揭示宏观结构的微观图案

#### 代码示例

```tsx
const animate = () => {
  time += 0.005
  elements.forEach((el, i) => {
    const nx = noise3D(i * 0.1, 0, time) * amplitude
    const ny = noise3D(0, i * 0.1, time) * amplitude
    gsap.set(el, { x: nx, y: ny, rotation: nx * 0.5 })
  })
  requestAnimationFrame(animate)
}
```

#### 配色

| 颜色 | Hex | 用途 |
|------|-----|------|
| 深空 | `#0A0A0F` | 背景 |
| 星云紫 | `#7C3AED` | 主色 |
| 等离子青 | `#06B6D4` | 次色 |
| 太阳金 | `#F59E0B` | 强调 |
| 虚空灰 | `#1E1E2E` | 表面 |

### Neo-Brutalism 新粗野主义

**核心理念**：粗野 + 极简。当前流行风格。保留粗野的粗犷，配以极简的克制。

| 保留自粗野 | 保留自极简 |
|------------|------------|
| 粗体字体 | 有目的的留白 |
| 可见边框 | 平滑缓动（`power1.out`） |
| 等宽字体 | 动效克制 |
| 高对比度 | 单次动画属性 |

#### 视觉特征

- 大号等宽标题
- 干净栅格 + 粗边框
- 黑 + 白 + 一个亮色强调
- 粗元素上的微妙动画

#### 代码示例

```tsx
<motion.div
  className="border-2 border-black bg-[#BAFF39] p-6 font-mono"
  whileHover={{ y: -4 }}
  transition={{ duration: 0.2, ease: 'easeOut' }}
>
  <h3 className="text-2xl font-black uppercase">Title</h3>
</motion.div>
```

#### 配色

| 颜色 | Hex | 用途 |
|------|-----|------|
| 黑 | `#000000` | 边框、文字 |
| 奶油 | `#FEF3C7` | 背景 |
| 青柠 | `#BAFF39` | 主强调 |
| 桃 | `#FECACA` | 次强调 |
| 薰衣草 | `#DDD6FE` | 第三强调 |

## 4. 风格混搭

### Controlled Chaos 控制的混乱

粗野 + 抽象：算法艺术配原始呈现。

- 保留粗野：硬边、高对比、激进尺度、等宽标签
- 保留抽象：生成几何、噪声、数学图案
- 视觉：全屏分形叠加等宽文字，生成背景配故障效果，数据可视化配粗野字体
- 动效配方：混合瞬时和缓慢——背景缓慢演化，UI 瞬时切换

### Generative Minimal 生成式极简

抽象 + 极简：微妙算法美配极简纪律。

- 保留抽象：噪声驱动运动、粒子系统、参数化形状
- 保留极简：克制、单色、负空间、缓慢过渡
- 视觉：单色生成背景、微妙噪声位移、若有若无的粒子
- 动效配方：极慢（15-60s 周期）、低幅度、opacity < 0.3
