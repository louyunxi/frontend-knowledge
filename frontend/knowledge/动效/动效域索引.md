## 🔥 核心模式

### ⭐ GSAP 页面过渡

适用：SPA路由切换、Tab切换

```tsx
import { gsap } from 'gsap';

const PageTransition = ({ children }) => {
  const ref = useRef(null);

  useEffect(() => {
    gsap.fromTo(ref.current,
      { opacity: 0, y: 30 },
      { opacity: 1, y: 0, duration: 0.5 }
    );
  }, []);

  return <div ref={ref}>{children}</div>;
};
```

### ⭐ GSAP 数字递增计数

适用：dashboard 大屏数字滚动展示（资产总额、订单数、PV/UV 等）。

```ts
import gsap from 'gsap';

const obj = { value: 0 };
gsap.to(obj, {
  value: targetNum,
  duration: 1.5,
  ease: 'power2.out',
  onUpdate: () => {
    dom.textContent = formatNumber(Math.floor(obj.value));
  }
});

// 周期性更新
setInterval(() => {
  animate(targetNum);
}, 6000);
```

> 必须使用**可变对象 `{ value: 0 }`** —— 不能直接 `gsap.to(ref.value, ...)`，Vue 的 ref 解包后是常量。详见 `GSAP数字递增动画.md`。

### ⭐ Canvas 2D 星空粒子背景

适用：dashboard / 营销页背景，无任何外部库依赖，纯 `requestAnimationFrame`。

```ts
interface Particle {
  x: number; y: number;
  size: number;
  vx: number; vy: number;
  alpha: number;
}

const particles: Particle[] = Array(density).fill(0).map(() => spawn());
ctx.scale(devicePixelRatio, devicePixelRatio); // 高 DPR 适配

function loop(now: number) {
  ctx.clearRect(0, 0, w, h);
  particles.forEach(p => {
    p.x += p.vx; p.y += p.vy;
    // 边界回环、闪烁等
    ctx.beginPath();
    ctx.fillStyle = `rgba(${color}, ${p.alpha})`;
    ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2);
    ctx.fill();
  });
  rafId = requestAnimationFrame(loop);
}
```

> 重点：`canvas.width = w * devicePixelRatio; ctx.scale(dpr, dpr);` 处理高 DPR 屏幕模糊问题。详见 `Canvas星空粒子背景效果.md`。

### ⭐ 滚动触发动画

适用：滚动时元素进入视口触发动画

```tsx
import { useInView } from 'framer-motion';

const AnimatedSection = ({ children }) => {
  const ref = useRef(null);
  const isInView = useInView(ref, { once: true });

  return (
    <motion.div
      ref={ref}
      initial={{ opacity: 0, y: 50 }}
      animate={isInView ? { opacity: 1, y: 0 } : {}}
      transition={{ duration: 0.6 }}
    >
      {children}
    </motion.div>
  );
};
```

### ⭐ 8 点轨道脉冲 Loading

适用：按钮内/卡片/全屏等通用加载等待场景；纯 CSS、零运行时依赖；视觉风格克制自洽。

```html
<div class="dot-spinner" role="status" aria-label="加载中">
  <!-- 8 个 dot，每 45° 一个 -->
  <div class="dot-spinner__dot"></div>
  ... 共 8 个 ...
</div>
<style>
  .dot-spinner { --uib-size: 2.8rem; --uib-speed: .9s; --uib-color: #183153;
    position: relative; height: var(--uib-size); width: var(--uib-size); display: flex; }
  .dot-spinner__dot { position: absolute; inset: 0; display: flex; }
  .dot-spinner__dot::before {
    content: ''; height: 20%; width: 20%; border-radius: 50%;
    background-color: var(--uib-color); opacity: .5; transform: scale(0);
    animation: dot-spinner-pulse calc(var(--uib-speed) * 1.111) ease-in-out infinite;
    box-shadow: 0 0 20px rgba(18, 31, 53, .3);
  }
  .dot-spinner__dot:nth-child(1)::before { animation-delay: 0s; }
  .dot-spinner__dot:nth-child(2)         { transform: rotate( 45deg); }
  .dot-spinner__dot:nth-child(2)::before  { animation-delay: calc(var(--uib-speed) * -0.875); }
  /* 同理 3~8，每 45° 增量 + 1/8 周期错开 */
  @keyframes dot-spinner-pulse {
    0%, 100% { transform: scale(0); opacity: .5; }
    50%      { transform: scale(1); opacity: 1; }
  }
</style>
```

> 关键技巧：**用 `::before` 伪元素承载视觉点，外层 dot 只负责旋转定位**；**8 个 dot 各延迟 1/8 周期**形成追逐波；详见 `加载动画/动效-loading-8点轨道脉冲.md`。

### ⭐ SVG 描边弧扫 Loading（Material 经典转圈）

适用：通用兜底 loading；后台、运营、报表、表单提交等待的最常见选；与 8 点轨道脉冲互为"经典克制" / "活泼脉冲"互补。

```html
<svg class="spinner" viewBox="25 25 50 50" aria-label="加载中" role="status">
  <circle r="20" cy="50" cx="50" />
</svg>
<style>
  .spinner { width: 3.25em; transform-origin: center;
    animation: spinner-rotate 2s linear infinite; }
  .spinner circle {
    fill: none; stroke: currentColor; stroke-width: 2; stroke-linecap: round;
    stroke-dasharray: 1, 200; stroke-dashoffset: 0;
    animation: spinner-dash 1.5s ease-in-out infinite;
  }
  @keyframes spinner-rotate { 100% { transform: rotate(360deg); } }
  @keyframes spinner-dash {
    0%   { stroke-dasharray: 1, 200;   stroke-dashoffset: 0;     }
    50%  { stroke-dasharray: 90, 200;  stroke-dashoffset: -35px; }
    100% { stroke-dashoffset: -125px; }
  }
</style>
```

> 关键技巧：**`stroke-dasharray: 1, 200`** 把圆周拆成"1 段实线 + 200 段空白"（200 ≥ 圆周长 ≈125.66）；**`stroke-dashoffset` 偏移起点**，让那段实线沿圆周扫过；**SVG 整层 2s 匀速旋转 + circle 1.5s 缓动 dash 动画** 时长错开、不严格同步，避开机械重复；详见 `加载动画/动效-loading-SVG描边弧扫.md`。

### ⭐ 12 条径向淡变 Loading（iOS / Apple 经典）

适用：iOS / Apple 视觉风格、工具型产品高端感、按钮内提交等待；与 8点轨道脉冲 = "活泼脉冲" 和 SVG描边弧扫 = "Material 经典" 形成互补，本条 = "克制细腻"。

```html
<div class="bar-loader" role="status" aria-label="加载中">
  <div class="bar"></div> ... 共 12 个 ...
</div>
<style>
  .bar-loader {
    --uib-size: 54px;
    position: relative; width: var(--uib-size); height: var(--uib-size);
  }
  .bar-loader .bar {
    width: 8%; height: 24%;
    background: currentColor; color: rgb(128, 128, 128);
    position: absolute; left: 50%; top: 30%; opacity: 0;
    border-radius: 50px; box-shadow: 0 0 3px rgba(0,0,0,.2);
    transform: rotate(0deg) translate(0, -130%);
    animation: bar-loader-fade 1s linear infinite;
  }
  /* 12 根条：30° 增量 + 0.1s 错相位 */
  .bar-loader .bar:nth-child(1)  { transform: rotate(  0deg) translate(0, -130%); animation-delay: 0s; }
  .bar-loader .bar:nth-child(2)  { transform: rotate( 30deg) translate(0, -130%); animation-delay: -1.1s; }
  .bar-loader .bar:nth-child(3)  { transform: rotate( 60deg) translate(0, -130%); animation-delay: -1s; }
  .bar-loader .bar:nth-child(4)  { transform: rotate( 90deg) translate(0, -130%); animation-delay: -0.9s; }
  .bar-loader .bar:nth-child(5)  { transform: rotate(120deg) translate(0, -130%); animation-delay: -0.8s; }
  .bar-loader .bar:nth-child(6)  { transform: rotate(150deg) translate(0, -130%); animation-delay: -0.7s; }
  .bar-loader .bar:nth-child(7)  { transform: rotate(180deg) translate(0, -130%); animation-delay: -0.6s; }
  .bar-loader .bar:nth-child(8)  { transform: rotate(210deg) translate(0, -130%); animation-delay: -0.5s; }
  .bar-loader .bar:nth-child(9)  { transform: rotate(240deg) translate(0, -130%); animation-delay: -0.4s; }
  .bar-loader .bar:nth-child(10) { transform: rotate(270deg) translate(0, -130%); animation-delay: -0.3s; }
  .bar-loader .bar:nth-child(11) { transform: rotate(300deg) translate(0, -130%); animation-delay: -0.2s; }
  .bar-loader .bar:nth-child(12) { transform: rotate(330deg) translate(0, -130%); animation-delay: -0.1s; }
  @keyframes bar-loader-fade { from { opacity: 1; } to { opacity: 0.25; } }
</style>
```

> 关键技巧：**12 根条共用一个 keyframe，**只动 `opacity` 不动 `transform`，**走 GPU 合成层最稳定**；**`transform: rotate(...) translate(0, -130%)` 顺序** —— rotate 在前 translate 在后，translate 的 `-130%` 是 bar 自身高度的相对值（不是容器），决定 12 根条对齐到圆周外缘；详见 `加载动画/动效-loading-12条径向淡变.md`。

### ⭐ 三球弹跳带影 Loading（拟物 / macOS 风）

适用：营销页 / Splash / 高端 SaaS / 按钮内提交等待；与 8点轨道脉冲 = "活泼脉冲"、SVG描边弧扫 = "Material 经典"、12条径向淡变 = "克制细腻" 形成互补，本条 = "拟物弹跳"。

```html
<div class="bounce-loader" role="status" aria-label="加载中">
  <span class="bounce-loader__pair">
    <span class="bounce-loader__ball"></span>
    <span class="bounce-loader__shadow"></span>
  </span>
  <span class="bounce-loader__pair">
    <span class="bounce-loader__ball"></span>
    <span class="bounce-loader__shadow"></span>
  </span>
  <span class="bounce-loader__pair">
    <span class="bounce-loader__ball"></span>
    <span class="bounce-loader__shadow"></span>
  </span>
</div>
<style>
.bounce-loader {
  --bounce-size: 18px; --bounce-color: currentColor;
  display: inline-flex; align-items: flex-end; gap: 36px;
  height: calc(var(--bounce-size) * 4);
}
.bounce-loader__pair { position: relative; width: var(--bounce-size); height: var(--bounce-size); }
.bounce-loader__ball, .bounce-loader__shadow {
  position: absolute; left: 0; border-radius: 50%;
}
.bounce-loader__ball {
  width: 100%; height: 100%; background: var(--bounce-color); top: 0;
  animation: bounce-ball .5s ease-in-out infinite alternate;
}
.bounce-loader__shadow {
  width: 100%; height: calc(var(--bounce-size) * 0.2);
  background: var(--bounce-color); opacity: .45;
  filter: blur(1px); bottom: 0; z-index: -1;
  animation: bounce-shadow .5s ease-in-out infinite alternate;
}
.bounce-loader__pair:nth-child(2) .bounce-loader__ball,
.bounce-loader__pair:nth-child(2) .bounce-loader__shadow { animation-delay: .2s; }
.bounce-loader__pair:nth-child(3) .bounce-loader__ball,
.bounce-loader__pair:nth-child(3) .bounce-loader__shadow { animation-delay: .3s; }
@keyframes bounce-ball {
  0%   { top: 100%; height: 25%; border-radius: 50% 50% 25% 25%; transform: scaleX(1.7); }
  40%  { height: 100%; border-radius: 50%; transform: scaleX(1); }
  100% { top: 0; }
}
@keyframes bounce-shadow {
  0%   { transform: scaleX(1.5); opacity: .7; }
  40%  { transform: scaleX(1);   opacity: .55; }
  100% { transform: scaleX(.2);  opacity: .3; }
}
</style>
```

> 关键技巧：**Squash & Stretch** —— 落地瞬间同时 `height: 25%` + `border-radius: 50% 50% 25% 25%` + `scaleX(1.7)`，三者联动制造"压扁弹性"，是迪士尼 12 原则之首；**阴影反向同步** —— 球越高阴影越小越淡 (`scaleX(.2)`、opacity `.3`)，这是拟物感的灵魂；**非均匀错峰** `.2s / .3s`（不是 1/3）刻意打破节拍器感；详见 `加载动画/动效-loading-三球弹跳带影.md`。

### ⭐ 首屏白屏 loading 同源占位

适用：SPA `index.html` 即出现的 loading 节点，避免白屏；CSS 内联不依赖外部资源；与页面背景同色无闪一下。

```html
<!-- index.html head 内部内联 -->
<style>
  #app-loading {
    position: fixed; inset: 0; z-index: 9999;
    display: flex; align-items: center; justify-content: center;
    background: #0b1220; /* 与 #app 真实背景完全一致 */
    transition: opacity 0.3s ease;
  }
  #app-loading.hide { opacity: 0; pointer-events: none; }
</style>

<!-- body 顶部 -->
<div id="app-loading" role="status"><div class="spinner"></div></div>
<div id="app"></div>

<script>
  window.__hideAppLoading = function () {
    var el = document.getElementById('app-loading');
    if (!el) return;
    el.classList.add('hide');
    setTimeout(function () { el.remove(); }, 350);
  };
</script>
```

```ts
// main.ts —— 框架挂载后调用
createApp(App).mount('#app');
window.__hideAppLoading?.();
```
