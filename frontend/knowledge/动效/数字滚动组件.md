# 数字滚动组件 (countUp)

> ⚠️ 本知识仅适用于 **uni-app 自定义组件**。核心实现借助 `<swiper vertical circular>` 模拟"翻牌器"，原生 Vue 可改用 CSS transition / GSAP 实现相同效果。

## 实现原理

每个字符（0-9 与小数点 `.`）作为一个独立的 `<swiper>` 组件，通过修改 `:current` 控制当前显示的"页"。`circular` 让滚动衔接时无缝。利用 `watch` 监听外部 `num` prop 变化，逐字符更新 current。

## Props

| Prop | 类型 | 默认 | 说明 |
| ---- | ---- | ---- | ---- |
| `num` | String / Number | — | 要显示的数字（支持小数） |
| `color` | String | `#000000` | 字色 |
| `width` | String | `15` | 单字符宽度（px） |
| `height` | String | `15` | 单字符高度（px） |
| `fontSize` | String | `15` | 字号（px） |

## 关键代码

```html
<block v-for="(myIndex, index) in indexArr" :key="index">
  <swiper
    class="swiper"
    vertical="true"
    :current="myIndex"
    circular="true"
    :style="{
      color: color,
      width: myIndex == 10 ? '7px' : width + 'px',
      height: height + 'px',
      lineHeight: fontSize + 'px',
      fontSize: fontSize + 'px'
    }">
    <swiper-item v-for="n in 11" :key="n">
      <view class="swiper-item">
        {{ n === 11 ? '.' : n - 1 }}
      </view>
    </swiper-item>
  </swiper>
</block>
```

```js
watch: {
  num(val, oldVal) {
    const arr = Array.prototype.slice.apply(this.indexArr);
    const newLen = val.toString().length;
    const oldLen = oldVal.toString().length;
    if (newLen > oldLen) for (let i = 0; i < newLen - oldLen; i++) arr.push(0);
    if (newLen < oldLen) for (let i = 0; i < oldLen - newLen; i++) arr.pop();
    this.indexArr = arr;
    this.numChange(val);
  }
}
```

## 设计要点

1. `.` 在 swiper 中的索引是 **10**（0-9 是数字），所以 `width: 7px` 让小数点窄一些
2. 用 `mounted` 中 `setTimeout(50ms)` 触发一次 `numChange` 以保证 swiper 已就绪
3. 长度变化时 push / pop 数组维持字符位

## 适用场景

- 数据大屏的"金额/数量"动效
- 商品详情页销量、评分
- 抽奖结果展示

## 平台兼容性

- H5 / 小程序：✅
- App：✅ 但 swiper 在 nvue 下表现与 webview 不同，可改用 vue 动画实现

## 替代方案

如需支持非数字字符（如中文滚动）、更复杂的翻牌效果，可改用 `vue-count-to` / `GSAP` 配合 ref。
