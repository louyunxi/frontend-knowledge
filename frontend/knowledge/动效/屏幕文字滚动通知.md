# 屏幕文字滚动通知 (screenTextScroll)

> ⚠️ 本知识仅适用于 **uni-app 自定义组件**。利用 `<swiper>` 的 `autoplay` + `display-multiple-items` 实现横/纵向通知滚动，原生 Vue 可直接用此组件（因为 swiper 标签在小程序是内置的）。

## 实现原理

`<swiper>` 配合 `autoplay circular` 让消息列表无限循环；`display-multiple-items="2"` 一次展示两条；`@change` 事件对外抛出当前下标，可用于联动指示器或停止播放。

## Props

| Prop | 类型 | 默认 | 说明 |
| ---- | ---- | ---- | ---- |
| `list` | Array | `[]` | 通知文案数组 |
| `interval` | Number (内部 data) | `3000` | 自动切换间隔 ms |
| `duration` | Number (内部 data) | `12000` | 滑动动画时长 ms |

> 注：`interval` 与 `duration` 在源码中写死为 data，不对外开放。如需自定义需自行扩展。

## 关键代码

```html
<template>
  <view class="_notice">
    <swiper
      class="_swiper tc"
      indicator-dots="false"
      autoplay="true"
      :interval="interval"
      :duration="duration"
      circular="true"
      display-multiple-items="2"
      @change="slideChange">
      <swiper-item v-for="(item, index) in list" :key="index">
        <view class="swiper-item uni-bg-red">{{ item }}</view>
      </swiper-item>
    </swiper>
  </view>
</template>
```

```js
methods: {
  slideChange(e) {
    this.$emit('getCurrentIndex', e.detail.current);
  }
}
```

```css
._notice {
  position: fixed;
  left: 0;
  top: 0;
  /* H5 端避开自定义导航条 */
  /* #ifdef H5 */
  top: 88upx;
  /* #endif */
  z-index: 9;
  width: 100%;
  background: rgba(72, 1, 1, 0.3);
  font-size: 20upx;
  height: 44upx;
  color: #ffffff;
  border-radius: 6upx;
  overflow: hidden;
}
```

## 设计要点

- 顶部固定 + 渐变背景做出"弹幕/公告"风格
- 使用 `/* #ifdef H5 */` 条件编译兼容 webview 顶部 88upx 安全区
- `display-multiple-items` 一屏两条节省屏占
- 自定义指示器需监听 `getCurrentIndex` 自行渲染

## 适用场景

- 首页"实时播报"（订单、签到）
- 直播间"入场提醒"
- 活动页"中奖名单"
