## 决策矩阵总表

| 任务类型 | 推荐库 | 原因 |
|---------|-------|------|
| 滚动驱动动画 | **GSAP + ScrollTrigger + useGSAP** | 行业标准，最精细的控制能力 |
| 平滑滚动 | **Lenis + ReactLenis** | 性能最优，与 ScrollTrigger 天然兼容 |
| React 原生动画 | **Motion** (Framer Motion) | 原生 React hook：`useScroll`/`useTransform` |
| 轻量/简单效果 | **Anime.js 4.0** | 体积小 (~9kb)，API 简洁 |
| 复杂时间轴编排 | **GSAP** | 无人能敌的时间轴控制 |
| SVG 形状变形 | **GSAP MorphSVG** 或 **Anime.js** | 两者都优秀 |
| 3D + 动画联动 | **Three.js + GSAP** | GSAP 控制 Three.js 对象 |
| 页面过渡 | **AnimatePresence** (Motion) 或 **GSAP** | Motion 用于 React，GSAP 用于复杂场景 |
| 矢量几何图形 | **SVG + GSAP/Motion** | 原生支持，可精确动画 |
| Canvas 程序绘图 | **Canvas 2D API** | 程序化，性能高 |
| 伪 3D 扁平图形 | **Zdog** | ~2kb，扁平设计风格 |
| 创意编程/生成艺术 | **p5.js** | 生态丰富 |
| 音频响应 | **Tone.js** | Web Audio API，合成器 + 效果链 |
| 2D 物理 | **Matter.js** | 重力、碰撞、约束 |
| 分形/递归图形 | **Canvas 2D** | 递归渲染 |
| 几何分割/拼图 | **SVG + GSAP** | 精确的路径动画 |
| 高级文字动效 | **GSAP SplitText + Canvas** | 逐字符控制 |
| Glitch 效果 | **CSS + GSAP** | 分层 RGB 分离 + clip-path |
| 粗野主义动画 | **CSS 原生 + Motion** | 硬切、无缓动 |
| 极简主义动画 | **Motion spring** | 克制、目的性 |

## 核心原则

### 1. 选库前先问自己

```
□ 这是什么类型的动画？  (滚动 / 交互 / 页面过渡 / 创意艺术)
□ 主要运行在什么环境？  (React / Vue / 原生)
□ 性能瓶颈在哪里？      (大量元素 / 复杂时间轴 / 移动端)
□ 需要哪些插件能力？    (ScrollTrigger / MorphSVG / SplitText)
□ 用户设备能力如何？    (桌面 / 移动 / 低端机)
```

### 2. React 项目首选路径

```
轻量简单        → Anime.js 或纯 CSS/Tailwind
React 优先      → Motion (原生 hook)
高级滚动/3D    → GSAP + useGSAP + ScrollTrigger
平滑滚动        → Lenis + GSAP ScrollTrigger (必须集成!)
两者结合        → Motion 做 UI 交互 + GSAP 做高级滚动
```

### 3. 避免过度工程

```
❌ 简单淡入淡出 → 上 GSAP
✅ 简单淡入淡出 → CSS transition 或 Tailwind transition

❌ 基础 hover → 上 Motion
✅ 基础 hover → Tailwind hover:scale-105

❌ 单次 scale 动画 → 上 GSAP timeline
✅ 单次 scale 动画 → CSS animation
```

## React 环境下的库选择

### GSAP + useGSAP（推荐用于高级动画）

```tsx
// lib/gsap.ts
import gsap from 'gsap'
import { ScrollTrigger } from 'gsap/ScrollTrigger'
import { useGSAP } from '@gsap/react'

gsap.registerPlugin(ScrollTrigger, useGSAP)
export { gsap, ScrollTrigger, useGSAP }
```

**适合**：复杂时间轴、精确控制、ScrollTrigger 驱动的滚动动画、高性能要求

### Motion（React 原生）

```tsx
import { motion, useScroll, useTransform, AnimatePresence } from 'motion/react'
```

**适合**：UI 交互、page transition、shared layout、声明式动画

### Anime.js（轻量场景）

```tsx
import anime from 'animejs'

anime({
  targets: '.el',
  translateX: 250,
  duration: 800,
  easing: 'easeInOutQuad',
})
```

**适合**：简单一次性动画、轻量依赖项目、非 React 环境

### Lenis（平滑滚动）

```tsx
import { ReactLenis, useLenis } from 'lenis/react'

export function SmoothScroll({ children }) {
  return (
    <ReactLenis root options={{ lerp: 0.1, duration: 1.2 }}>
      {children}
    </ReactLenis>
  )
}
```

**适合**：任何需要超越原生滚动体验的场景，与 GSAP ScrollTrigger 集成后效果最佳

## 移动端选型

| 场景 | 推荐 | 说明 |
|-----|------|------|
| 高端移动端展示站 | GSAP + Lenis | 最佳视觉效果 |
| 移动端 UI 交互 | Motion | 触控友好，API 简洁 |
| 低端/性能敏感 | CSS / Tailwind | 无库依赖，60fps 有保障 |
| 混合应用 | Anime.js | 轻量不拖累 bundle |

---

## 库组合推荐

### 组合 1: Awwwards 级别展示站

```
GSAP (核心动画) + Lenis (滚动) + Motion (UI 交互) + Anime.js (轻量辅助)
```

### 组合 2: 常规 React 应用

```
Motion (主要) + CSS/Tailwind (简单交互动画)
```

### 组合 3: 轻量/性能优先

```
Anime.js 或 纯 CSS animation
```

---

## 避坑指南

```
❌ 不要为简单动画引入重型库
❌ 不要同时混用 GSAP 和 Motion 做同一件事
❌ 不要忘记 Lenis 需要与 ScrollTrigger 集成才能正常工作
❌ 不要在 React 中直接用 gsap.to() 而不用 useGSAP
✅ 先用 CSS/Tailwind，复杂度超出后再上库
✅ React 环境优先用库的 React 版本 (useGSAP, ReactLenis)
✅ 移动端先测试再上线
```
