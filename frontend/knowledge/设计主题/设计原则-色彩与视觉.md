# 设计原则：色彩与视觉

## 概述

色彩是设计中最具情感冲击力的元素。一个精心设计的色彩系统可以建立品牌认知、引导用户注意力、传达产品个性。

本知识提供色彩设计的基本原则，帮助你做出有意的色彩选择。

---

## 色彩系统构建

### 1. 核心调色板

```
一个完整的色彩系统应该包含：

基础色 (Base Colors)
━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 主色 (Primary)
  品牌核心色，用于主要元素
  示例：#2563EB (蓝色)

- 次要色 (Secondary)
  支持主色，用于次要元素
  示例：#7C3AED (紫色)

- 中性色 (Neutral)
  文字、背景、边框
  示例：#111827, #F3F4F6

强调色 (Accent)
━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 成功色 (Success)
  正向反馈
  示例：#10B981 (绿色)

- 警告色 (Warning)
  中性警告
  示例：#F59E0B (黄色)

- 错误色 (Error)
  负向反馈
  示例：#EF4444 (红色)

- 信息色 (Info)
  信息提示
  示例：#3B82F6 (蓝色)
```

### 2. 语义色彩

```
语义色彩用于传达含义：

❌ 不要：
- 成功信息用红色
- 错误信息用绿色
（与用户预期相反）

✅ 应该：
- 绿色 = 成功/正面
- 红色 = 错误/负面
- 黄色 = 警告/注意
- 蓝色 = 信息/链接
```

### 3. 暗色模式考虑

```
暗色模式的色彩调整：

1. 不要只是反转
   ❌ 深色背景 + 浅色文字 ≠ 暗色模式

2. 考虑饱和度
   - 亮色模式：高饱和度
   - 暗色模式：降低饱和度（避免刺眼）

3. 使用正确的灰色
   ❌ 纯灰 (#808080) 
   ✅ 蓝灰 (#6B7280) 或暖灰 (#9CA3AF)

4. 保持对比度
   确保文字可读性 WCAG AA 标准
```

## 强调色使用

### 1. 强调色的作用

```
强调色用于：
━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 引导注意力
   - CTA 按钮
   - 重要信息
   - 关键数据

✅ 建立层次
   - 区分信息重要性
   - 创建视觉焦点

✅ 品牌识别
   - 建立品牌色
   - 增加记忆点

❌ 不要滥用：
- 不要每个元素都用强调色
- 不要多种强调色同时使用
- 不要随意更换强调色
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 2. 强调色选择原则

```
❌ 避免的常见组合：
━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 暖奶油色背景 + 陶土强调色
   (#F4F1EA + #D97757)
   → 过于常见

2. 近黑背景 + 酸绿/朱红强调
   (#0B0B0B + #00FF00)
   → 过于极端

3. 所有卡片使用相同强调色
   → 缺乏层次

✅ 更好的选择：
- 考虑产品调性
- 考虑目标受众
- 考虑使用场景
- 创建色彩梯度
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 视觉层次

### 1. 建立层次的方法

```
视觉层次 = 重要性顺序

建立层次的方式：
━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 尺寸
   更大的 = 更重要

2. 色彩
   更突出的 = 更重要
   强调色 > 主色 > 次要色 > 中性色

3. 位置
   左上 = 更重要（阅读起点）
   中心 = 更重要（视觉焦点）

4. 对比度
   更高对比度 = 更重要

5. 间距
   周围空间越多 = 越突出
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 2. 克制使用原则

```
💡 香奈儿原则：
"出门前照照镜子，拿掉一样配饰。"

设计原则：
━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 一个焦点
   让一个元素成为记忆点

✅ 其他保持克制
   围绕焦点的元素保持安静

✅ 移除不服务的装饰
   每个装饰都应该有目的

❌ 不要：
- 每个元素都想突出
- 过度使用强调色
- 滥用视觉层次技巧
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 避免模板化

### 常见模板化模式

```
❌ 1. 渐变洗色作为装饰
━━━━━━━━━━━━━━━━━━━━━━━━━━━
错误示例：
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%)

问题：
- 没有功能性
- 显得装饰过度

✅ 更好的方式：
- 使用纯色背景
- 或者渐变有功能性（数据可视化）
━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 2. 所有卡片相同阴影
━━━━━━━━━━━━━━━━━━━━━━━━━━━
错误示例：
box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
（所有卡片使用相同阴影）

问题：
- 缺乏层次
- 视觉单调

✅ 更好的方式：
- 悬停卡片加深阴影
- 重要卡片更深阴影
- 调整阴影强度表示重要性
━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 3. 过度使用圆角
━━━━━━━━━━━━━━━━━━━━━━━━━━━
错误示例：
border-radius: 12px;
（所有元素相同圆角）

问题：
- 缺乏层次
- 显得廉价

✅ 更好的方式：
- 主按钮：较大圆角
- 辅助元素：较小圆角
- 数据标签：无圆角或微圆角
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 色彩检查清单

```
设计前：
□ 产品/品牌的主色调是什么？
□ 目标受众的色彩偏好？
□ 产品调性（活泼/专业/简约）？
□ 是否有品牌色彩约束？

设计中：
□ 是否保持了色彩克制？
□ 强调色是否用于关键元素？
□ 是否考虑了暗色模式？
□ 语义色彩是否正确？
□ 是否避免了模板化配色？

完成后：
□ 色彩是否有个性？
□ 是否符合产品调性？
□ 是否有清晰的视觉层次？
□ 是否考虑了无障碍？
```
