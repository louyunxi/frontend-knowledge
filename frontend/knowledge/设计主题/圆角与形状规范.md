# 圆角与形状规范

## 概述

项目采用 Apple 风格的「**软圆角 + 渐变层次**」视觉语言，从 18px（小图标缩略图）到 36px（大型 hero 卡片）形成 4 个核心圆角档位，所有圆角通过 CSS 变量集中管理。

## 设计令牌

### CSS 变量

```scss
:root {
  --wb-radius-card: 32px;    // 主卡片
  --wb-radius-soft: 24px;    // 软圆角（次级卡片）
  --wb-radius-pill: 999px;   // 药丸（按钮、徽章、Tag）
}
```

## 圆角分级

### 4 个核心圆角档位

| 档位 | 值 | 用途 | 示例 |
|------|------|------|------|
| **XL** | 32-36px | 主卡片、Hero 区 | 购物车金额卡、订单卡、首页产品卡 |
| **L** | 28-30px | 次级卡片 | 新品上架卡、搜索结果卡 |
| **M** | 22-26px | 缩略图 / 子元素 | 商品缩略图、操作按钮 |
| **S** | 18-20px | 小图标 / 内嵌元素 | 类目缩略图、菜单图标 |
| **Pill** | 999px | 药丸形 | 按钮、徽章、Tag、搜索框 |

## 应用示例

### 卡片基础类

```scss
.card {
  border-radius: var(--wb-radius-card);    // 32px
  background: var(--wb-surface-glass);
  box-shadow: var(--wb-shadow-card);
}

.card-soft {
  border-radius: var(--wb-radius-soft);    // 24px
}

.pill {
  border-radius: var(--wb-radius-pill);    // 999px
}
```

### 缩略图

```scss
.thumb {
  width: 132px;
  height: 132px;
  border-radius: 22px;        // 介于 M 与 L 之间
  object-fit: cover;
}
```

### 按钮

```scss
.btn-primary {
  border-radius: 999px;       // Pill 风格
  background: var(--wb-blue);
  color: #fff;
}

.btn-icon {
  width: 42px;
  height: 42px;
  border-radius: 21px;        // 50% 形成正圆
}
```

## 响应式策略

圆角无需随断点变化（小屏下卡片宽度更小，圆角相对更明显）。

## 最佳实践

### ✅ 推荐

- 圆角与卡片大小成正比：卡片越大圆角越大
- 主卡（`--wb-radius-card = 32px`）+ 子缩略图（22px）形成层次
- 行动按钮统一使用 999px pill 风格
- 头像、评分图标使用 50% 正圆

### ❌ 避免

- 不同页面使用不同圆角（破坏视觉一致性）
- 圆角过大（>40px）导致内容区塌陷
- 圆角过小（<8px）显得过于硬朗

## 性能考虑

- `border-radius` 是合成层开销较小，但避免过多元素同时使用动画化圆角
- 用 `transform: scale()` 实现圆角缩放比直接修改 `border-radius` 性能好

## 无障碍

- 圆角为视觉性，对辅助技术无影响
- 但与背景对比度应足够，避免低视力用户看不清边界
