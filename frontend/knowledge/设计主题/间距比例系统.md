# 间距比例系统

## 概述

项目全站采用「**8 的倍数 + 个别 14 / 18 微调**」的间距系统，核心 8 档：8 / 12 / 14 / 16 / 18 / 20 / 24 / 32px。所有内边距、外边距、flex/grid gap 都从这 8 个值中选取，确保视觉节奏统一。

## 设计令牌

### 间距阶梯表

| 档位 | 值 | 主要用途 | 使用频率 |
|------|------|---------|---------|
| **XS** | 8px | Tag 间距、tab 间小空隙、icon 与文字间距 | ⭐⭐ |
| **S1** | 12px | 卡片内元素间距、Tab 间距 | ⭐⭐⭐ |
| **S2** | 14px | 紧凑型双列栅格间距 | ⭐⭐ |
| **M1** | 16px | 卡片内 padding、列表 gap、区段内 padding | ⭐⭐⭐⭐⭐ |
| **M2** | 18px | 水平卡片间距、缩略图与文字间距 | ⭐⭐⭐ |
| **M3** | 20px | 信息栅格 gap、按钮 gap | ⭐⭐ |
| **L1** | 24px | 区段间距、面板 padding | ⭐⭐⭐⭐ |
| **L2** | 28px | 面板 header padding 顶部 | ⭐⭐ |
| **XL** | 32px | 末段底部留白、面板 padding | ⭐⭐⭐ |

## 间距使用公式

```
区段间距  = padding-top: 24px      (L1)
卡片内边距 = 16px 16px 18px        (M1 + M1 + M2)
栅格间距   = gap: 16px              (M1)
列表间距   = gap: 16-18px           (M1 + M2)
底部留白   = padding-bottom: 32px   (XL)
```

## 响应式策略

```css
/* 默认通过 rem + flexible.js 自动适配 */
/* 小屏下窄间距微调 */
@media (max-width: 480px) {
  .home__body { padding: 0 12px; }   /* 16 → 12 */
  .home__section { padding-top: 20px; }  /* 24 → 20 */
}
```

## 最佳实践

### ✅ 推荐

- 永远从 8 档间距中选取，避免使用 10/13/15 等「野值」
- 横向 padding 优先使用 16px，纵向区段间距优先使用 24px
- gap 与 padding 混用：内容间用 gap，容器内边距用 padding
- 末段必须有额外 padding-bottom 给 TabBar 留位

### ❌ 避免

- 使用 5px / 7px / 11px 等小数值间距
- 在同一组件内同时使用 gap 与 margin 制造间距（叠加导致双倍）
- 使用 `margin: 0 auto` 配合非父级 display（应 flex/grid 居中）

## 性能考虑

- `padding` 触发容器自身 box 重排，性能良好
- `gap` 由浏览器原生处理，无额外开销
- 避免 margin collapse 引起的二次重排（用 padding 替代）

## 无障碍

- 间距为视觉性，不影响辅助技术
- 但合理的间距提升扫读效率，间接改善可访问性
