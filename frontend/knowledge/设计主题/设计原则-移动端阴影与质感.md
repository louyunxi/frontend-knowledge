# 移动端阴影与质感

## 概述

移动端阴影的核心是"柔和、有色、不生硬"。阴影必须与背景色调一致，并通过分层与透明度构建质感层次。

## 核心原则

### 三原则

```text
1. 始终使用柔阴影 — 从不生硬/锐利
2. 阴影颜色与背景匹配 — 用染色阴影，不要用纯灰/纯黑
3. 微弱白色内阴影为按钮增加立体感
```

## 推荐阴影 token

### 浅色背景

```css
:root {
  --shadow-sm: 0 1px 2px rgba(15, 23, 42, 0.06);
  --shadow-md: 0 4px 12px rgba(15, 23, 42, 0.08);
  --shadow-lg: 0 12px 32px rgba(15, 23, 42, 0.12);
  --shadow-xl: 0 24px 48px rgba(15, 23, 42, 0.16);
}
```

### 深色背景

```css
:root {
  --shadow-sm-dark: 0 1px 2px rgba(0, 0, 0, 0.4);
  --shadow-md-dark: 0 4px 12px rgba(0, 0, 0, 0.5);
  --shadow-lg-dark: 0 12px 32px rgba(0, 0, 0, 0.6);
}
```

### 暖色背景（如米色、橙色基底）

```css
:root {
  --shadow-warm-sm: 0 1px 2px rgba(120, 80, 50, 0.08);
  --shadow-warm-md: 0 4px 12px rgba(120, 80, 50, 0.12);
}
```

## 按钮内阴影

```text
核心：在主按钮上加微弱白色内阴影增加立体感
作用：让按钮看起来"被按下"，有物理触感
```

```css
.btn-primary {
  background: linear-gradient(180deg, #FF8F65 0%, #FF7A45 100%);
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.2),     /* 顶部白色内阴影 */
    inset 0 -1px 0 rgba(0, 0, 0, 0.08),         /* 底部深色内阴影 */
    0 4px 12px rgba(255, 122, 69, 0.3);          /* 外部强调色阴影 */
}
```

## 装饰性阴影

```text
用途：在关键元素（CTA、激活态）后添加发光效果
组合：blur + opacity
```

```css
.glow-accent {
  position: relative;
}
.glow-accent::before {
  content: '';
  position: absolute;
  inset: -8px;
  background: radial-gradient(circle, rgba(255,122,69,0.2) 0%, transparent 70%);
  filter: blur(12px);
  z-index: -1;
}
```

## 次级元素边框

```text
核心：5% 透明度的主色边框用于次级元素
作用：在不喧宾夺主的前提下强化品牌关联
```

```css
.btn-secondary {
  background: white;
  border: 1px solid rgba(255, 122, 69, 0.5);   /* 5% 边框 */
  color: #FF7A45;
}
```

## 卡片悬浮层级

```css
/* 静态 */
.card { box-shadow: var(--shadow-sm); }

/* Hover */
.card:hover { box-shadow: var(--shadow-md); }

/* 选中态 */
.card.selected {
  box-shadow: var(--shadow-lg);
  border-color: rgba(255, 122, 69, 0.5);
}
```

## 移动端 Tap Target

```text
所有可点击元素：至少 44×44pt（iOS HIG 标准）

实施：
- min-height: 44px;
- min-width: 44px;
- padding: 12px 16px; (内部)
- 元素间间距：≥ 8px
```

## 实施示例

### Tailwind 自定义阴影

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      boxShadow: {
        'soft-sm': '0 1px 2px rgba(15, 23, 42, 0.06)',
        'soft-md': '0 4px 12px rgba(15, 23, 42, 0.08)',
        'soft-lg': '0 12px 32px rgba(15, 23, 42, 0.12)',
        'accent-glow': '0 8px 24px rgba(255, 122, 69, 0.25)',
        'inset-top-light': 'inset 0 1px 0 rgba(255, 255, 255, 0.2)',
      }
    }
  }
}
```

### Vue 按钮组件

```vue
<template>
  <button class="btn-primary">
    主要操作
  </button>
</template>

<style scoped>
.btn-primary {
  background: linear-gradient(180deg, #FF8F65 0%, #FF7A45 100%);
  border: none;
  border-radius: 12px;
  padding: 14px 24px;
  color: white;
  font-size: 15px;
  font-weight: 600;
  min-height: 44px;
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.2),
    inset 0 -1px 0 rgba(0, 0, 0, 0.08),
    0 4px 12px rgba(255, 122, 69, 0.3);
  transition: all 0.2s ease;
}
.btn-primary:active {
  transform: translateY(1px);
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.1),
    0 2px 4px rgba(255, 122, 69, 0.2);
}
</style>
```

## 反模式

- ❌ 使用纯黑色阴影：`box-shadow: 0 4px 8px #000`
- ❌ 使用太锐利的阴影：`box-shadow: 0 0 0 2px #333`
- ❌ 在彩色背景上用灰色阴影
- ❌ 阴影扩散过远：`box-shadow: 0 50px 100px`
- ❌ 缺少状态的过渡（hover/active 都是同一样式）
- ❌ 可点击元素 < 44pt（移动端）
