# 设计原则：排版规范

## 概述

排版是页面个性的载体。字体选择和处理方式直接影响页面的整体感觉。

本知识提供排版设计的最佳实践，帮助你做出有意图的选择，而不是默认选择。

---

## 字体选择原则

### 1. 字体数量控制

```
❌ 常见错误：
- 标题用一种字体
- 正文用另一种字体
- 数据标签又一种字体
- 结果：5-6 种字体混杂

✅ 最佳实践：
- 1-2 种字体家族足够
- 如果用两种，确保明显不同
- 保持一致性

示例：
✅ 好：
   标题: Playfair Display
   正文: Inter

❌ 差：
   标题: Playfair Display
   副标题: Roboto
   正文: Inter
   标签: Fira Code
   数据: SF Mono
```

### 2. 选择有意图的字体

```
❌ 避免的默认选择：
- Roboto (Android 默认)
- Open Sans (Google Fonts 最流行)
- Inter (最近过度使用)
- Arial / Helvetica (系统默认)

✅ 选择原则：
- 根据产品调性选择
- 考虑行业特性
- 考虑目标受众
- 不要因为"流行"而选择

特殊场景例外：
- 技术文档：等宽字体可能合适
- 儿童产品：圆润字体可能更好
- 奢侈品：衬线体可能更合适
```

### 3. 字体角色定义

```
定义每种字体的明确用途：

示例 1：
┌─────────────────────────────┐
│ Display: Playfair Display    │
│ 用途: 品牌标题、Hero 区域   │
│ 特点: 衬线、优雅、有个性    │
├─────────────────────────────┤
│ Body: Inter                 │
│ 用途: 正文、按钮、标签       │
│ 特点: 无衬线、易读、现代    │
└─────────────────────────────┘

示例 2：
┌─────────────────────────────┐
│ Primary: Space Grotesk      │
│ 用途: 所有文本              │
│ 特点: 几何、有趣、现代      │
└─────────────────────────────┘
```

## 字阶系统

### 1. 遵循经典比例

```
使用 The Elements of Typographic Style 的经典比例：

常用比例：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Major Third (1.250)
  12 → 15 → 19 → 24 → 30 → 38 → 48

Perfect Fourth (1.333)
  12 → 16 → 21 → 28 → 38 → 50 → 67

Golden Ratio (1.618)
  12 → 19 → 31 → 51 → 82 → 133

选择一种比例后保持一致
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 2. 字号设置

```
❌ 常见错误：
- 标题：60px
- 副标题：48px
- 正文：16px
- 小字：14px
- 标签：12px
（没有规律，随意设置）

✅ 最佳实践：
基于基础字号，按比例计算

示例（Major Third 比例）：
基础: 16px
小标签: 13px (16/1.25)
正文: 16px
副标题: 20px (16 × 1.25)
标题: 25px (16 × 1.25²)
大标题: 31px (16 × 1.25³)
Hero: 39px (16 × 1.25⁴)
```

### 3. 字重和间距

```
字重使用：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Light (300)   ← 谨慎使用
Regular (400)  ← 正文常用
Medium (500)  ← 按钮、标签
Semi-bold (600) ← 副标题
Bold (700)     ← 标题

⚠️ 不要：
- 混用太多字重
- 正文使用过粗字重
- 标题使用过细则不突出
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

字间距：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
标题：通常默认或略微收紧 (-0.02em)
正文：默认
标签：略微放宽 (+0.05em)
全大写：明显放宽 (+0.1em)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 行高和行长

### 1. 行高设置

```
❌ 常见错误：
- 行高太紧（1.2 以下）
- 不区分正文字体类型
- 所有文本相同行高

✅ 最佳实践：

衬线体正文：
  行高: 1.6 - 1.8
  （衬线体需要更多空间阅读）

无衬线体正文：
  行高: 1.4 - 1.6
  （无衬线体更紧凑）

标题：
  行高: 1.1 - 1.3
  （标题行高应该更紧）
```

### 2. 行长控制

```
❌ 常见错误：
- 不限制行宽
- 行太长（超过 100 字符）
- 移动端也不调整

✅ 最佳实践：

理想行长：
  45-75 字符（英文）
  20-35 汉字

衬线体正文：
  可以稍长：60-80 字符

移动端：
  保持 35-50 字符
```

### 3. 段落间距

```
段落间距 = 行高的 0.5-1 倍

示例：
行高: 24px
段落间距: 12-24px

不要：
- 段落间距 = 行高 × 2（太大）
- 段落间距 = 行高 × 0.25（太小）
```

## 避免模板化排版

### 需要避免的处理

```
❌ 1. 标题中单个词强调
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
错误示例：
  "我们<span style="color: red">领先</span>的解决方案"

为什么不好：
- 过于常见
- 显得刻意
- 破坏一致性

✅ 更好的方式：
- 使用不同的排版处理（字号、字重）
- 或者不强调
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 2. 全大写标签
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
错误示例：
  <label>IMPORTANT NOTE</label>

为什么不好：
- 视觉上刺眼
- 阅读困难
- 显得廉价

✅ 更好的方式：
- 使用 Small Caps
- 或者使用 Sentence case
- 配合字重变化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 3. 不必要的标签
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
错误示例：
  LABEL: Content text here
  Category: Description

为什么不好：
- 信息冗余
- 视觉噪音
- 增加认知负担

✅ 更好的方式：
- 直接使用内容
- 或者使用纯视觉层次
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 排版检查清单

```
开始前：
□ 选择 1-2 种字体家族
□ 定义每种字体的用途
□ 设置字号比例
□ 设置字重系统

设计中：
□ 行高是否适合字体类型？
□ 行长是否在范围内？
□ 段落间距是否合适？
□ 是否避免了不必要的标签？
□ 是否避免了单个词强调？

完成后：
□ 排版是否有个性？
□ 是否符合产品调性？
□ 是否考虑了可读性？
```
