# 设计令牌色彩系统

## 概述

项目使用 Apple HIG 风格的中性色 + 单一强调蓝的色彩体系，所有颜色都通过 CSS 自定义属性（CSS Variables）暴露，便于在不同主题或模式下替换。设计令牌分为 5 大类：**基础色（base）/ 表面（surface）/ 文本（text）/ 边框（border）/ 阴影（shadow）**。

## 设计令牌

### CSS 变量定义

```scss
:root {
  /* ── 基础色 ── */
  --wb-black: #000000;
  --wb-blue: #0071e3;
  --wb-blue-link: #0066cc;
  --wb-blue-dark: #2997ff;

  /* ── 表面（背景层级） ── */
  --wb-surface: #f5f5f7;
  --wb-surface-page: linear-gradient(180deg, #fbfbfd 0%, #f7f7fa 38%, #f5f5f7 100%);
  --wb-surface-elevated: rgba(255, 255, 255, 0.92);
  --wb-surface-glass: rgba(255, 255, 255, 0.74);
  --wb-surface-subtle: rgba(255, 255, 255, 0.78);
  --wb-surface-dark: #1d1d1f;
  --wb-surface-dark-elevated: rgba(39, 39, 41, 0.92);

  /* ── 文本（层级透明度） ── */
  --wb-text: #1d1d1f;                       // 主文本
  --wb-text-secondary: rgba(29, 29, 31, 0.72);
  --wb-text-tertiary: rgba(29, 29, 31, 0.48);
  --wb-text-inverse: #ffffff;               // 深色背景上的文字

  /* ── 边框 ── */
  --wb-border: rgba(29, 29, 31, 0.08);
  --wb-border-strong: rgba(29, 29, 31, 0.12);

  /* ── 阴影 ── */
  --wb-shadow-card: 0 12px 40px rgba(15, 23, 42, 0.08);
  --wb-shadow-float: 0 20px 56px rgba(15, 23, 42, 0.12);
}
```

## 色彩体系详解

### 主色调

| 名称 | 色值 | 用途 |
|------|------|------|
| Blue | `#0071e3` | 主品牌色、链接、按钮 |
| Blue Link | `#0066cc` | 文本链接 |
| Blue Dark | `#2997ff` | 深色背景链接 |
| Black | `#000000` | 黑色调表面 |

### 中性色（surface）

| 名称 | 色值 | 用途 |
|------|------|------|
| Surface | `#f5f5f7` | 页面底色 |
| Surface Page | `linear-gradient` | 整页渐变 |
| Elevated | `rgba(255, 255, 255, 0.92)` | 卡片背景 |
| Glass | `rgba(255, 255, 255, 0.74)` | 毛玻璃面板 |
| Subtle | `rgba(255, 255, 255, 0.78)` | 浅表面 |
| Dark | `#1d1d1f` | 深色面板 |

### 文本层级

| 层级 | 色值 | 用途 |
|------|------|------|
| Primary | `#1d1d1f` | 标题、重要内容 |
| Secondary | `rgba(29, 29, 31, 0.72)` | 正文 |
| Tertiary | `rgba(29, 29, 31, 0.48)` | 辅助、占位 |
| Inverse | `#ffffff` | 深色背景上 |

### 边框与分割线

| 名称 | 色值 | 用途 |
|------|------|------|
| Border | `rgba(29, 29, 31, 0.08)` | 默认 1px 分割线 |
| Border Strong | `rgba(29, 29, 31, 0.12)` | 强调分割 |

### 阴影

| 名称 | 值 | 用途 |
|------|------|------|
| Shadow Card | `0 12px 40px rgba(15, 23, 42, 0.08)` | 卡片抬升 |
| Shadow Float | `0 20px 56px rgba(15, 23, 42, 0.12)` | 浮层、Dialog |

## 应用示例

### 主按钮

```scss
.btn-primary {
  background: var(--wb-blue);
  color: var(--wb-text-inverse);
  border: none;
  box-shadow: none;
}
```

### 毛玻璃卡片

```scss
.panel {
  background: var(--wb-surface-glass);
  backdrop-filter: blur(24px);
  border: 1px solid rgba(255, 255, 255, 0.72);
  box-shadow: var(--wb-shadow-card);
}
```

### 链接文本

```scss
.link {
  color: var(--wb-blue-link);
  &:hover { color: var(--wb-blue-dark); }
}
```

### 文本层级

```scss
.text-primary   { color: var(--wb-text); }
.text-secondary { color: var(--wb-text-secondary); }
.text-tertiary  { color: var(--wb-text-tertiary); }
```

## 响应式策略

色彩令牌不随断点变化，但与暗色模式结合时可整体切换：

```scss
@media (prefers-color-scheme: dark) {
  :root {
    --wb-text: #f5f5f7;
    --wb-text-secondary: rgba(245, 245, 247, 0.78);
    --wb-surface: #1d1d1f;
  }
}
```

## 最佳实践

### ✅ 推荐

- 永远通过 `var(--wb-*)` 引用颜色，禁止硬编码 hex
- 文本层级用三档（primary / secondary / tertiary），不引入第四档
- 边框透明度 8-12%，阴影使用 8-12% 不透明度
- 渐变背景用 linear-gradient，节省图片请求

### ❌ 避免

- 在组件里硬编码 `#1677ff`、`#ff4646` 等品牌色
- 使用纯白 `#fff` 或纯黑 `#000` 作为大面积背景（视觉刺眼）
- 阴影使用纯黑色（应使用带蓝调的 `rgba(15, 23, 42, *)`）

## 无障碍

- 主文本与背景对比度 ≥4.5:1（WCAG AA）
- `--wb-text #1d1d1f` on `#f5f5f7` 对比度 16.5:1（AAA）
- 三档文本均通过 AA 标准
