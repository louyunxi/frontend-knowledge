# 移动端 60/30/10 配色规则

## 概述

60/30/10 配色规则源自室内设计，是移动端 UI 设计中应用最广泛的配色平衡法则。所有移动端界面都应遵循此规则建立视觉层次。

## 核心规则

### 60% — 中性基底色

```text
作用：构建界面"地面"，承载所有内容
选择：
- 浅色系：白色 / 浅灰 / 米白
- 深色系：深灰 / 近黑 / 深蓝黑
常见 token：
- --color-bg-primary: #FFFFFF / #0F1115
- --color-surface-soft: #F7F8FA / #1A1D24
```

### 30% — 互补/对比色

```text
作用：建立层级（文字、标题、分割、容器）
选择：
- 与基底有足够对比度但不冲突
- 通常是中性色的深色变体或文字色
常见 token：
- --color-text-primary: #111827 / #F9FAFB
- --color-text-secondary: rgba(0,0,0,0.8)
- --color-border-subtle: rgba(0,0,0,0.06)
```

### 10% — 品牌强调色

```text
作用：CTA、关键指标、状态、强调
使用场景：
- 主按钮 / 主链接
- 关键数据指标（盈利、收益）
- 状态徽标（成功、警示）
限制：
- 一屏只能有 1-2 个强强调色
- 用 5% 透明度变体承载次级按钮和轻量高亮
常见 token：
- --color-accent: #FF7A45
- --color-accent-soft: rgba(255,122,69,0.05)
- --color-accent-border: rgba(255,122,69,0.5)
```

## 文字透明度变体

不要为每级文字都单独定义颜色，使用中性色的透明度梯度：

```css
:root {
  --color-text: #111827;
}

.text-h1 { color: rgba(0,0,0, 1.00); }   /* 标题 */
.text-body { color: rgba(0,0,0, 0.80); } /* 正文 */
.text-secondary { color: rgba(0,0,0, 0.65); } /* 次要 */
.text-hint { color: rgba(0,0,0, 0.45); } /* 提示 */
```

## 行业应用惯例

| 行业类型 | 基底色（60%） | 文字色（30%） | 强调色（10%） |
|---------|--------------|--------------|--------------|
| AI / 科技 | 白 / 深色 | 黑色 / 浅灰 | 紫蓝渐变 / 青色霓虹 |
| 加密 / Web3 | 深黑 | 高对比白 | 霓虹紫 / 荧光绿 |
| 金融 / 银行 | 浅灰白 | 深蓝文字 | 信任蓝（#1652F0）|
| 健康 / 健身 | 浅米白 | 深灰 | 明亮黄绿 / 珊瑚色 |
| 睡眠 / 冥想 | 深紫色 | 浅紫 | 星河蓝紫渐变 |
| 教育 / 学习 | 浅黄白 | 深棕 | 鲜艳橙 / 亮蓝 |
| 电商 / 食物 | 浅米白 | 深棕灰 | 食欲橙 / 折扣红 |
| 效率 / 工具 | 纯白 | 深灰 | 单一功能蓝 |

## 阴影颜色搭配

```text
关键原则：阴影颜色必须与背景色调一致，不要用纯灰/纯黑

正确做法：
- 浅色背景：阴影偏蓝灰 rgba(15, 23, 42, 0.08)
- 暖色背景：阴影偏暖灰 rgba(120, 80, 50, 0.1)
- 深色背景：阴影偏纯黑 rgba(0, 0, 0, 0.4)

CSS 变量定义：
--shadow-sm: 0 1px 2px rgba(15, 23, 42, 0.06);
--shadow-md: 0 4px 12px rgba(15, 23, 42, 0.08);
--shadow-lg: 0 12px 32px rgba(15, 23, 42, 0.12);
```

## 反模式

- ❌ 使用 3 种以上的强强调色，破坏层级
- ❌ 在浅色背景用纯黑阴影（看起来很脏）
- ❌ 用纯红色做大量装饰（过强的颜色削弱了关键状态的显著性）
- ❌ 强饱和色覆盖大面积区域
- ❌ 文字直接用 #000000 而非中性色变体

## 实施要点

```vue
<!-- Vue + Tailwind 示例 -->
<template>
  <div class="bg-white">                              <!-- 60% -->
    <h1 class="text-gray-900">标题</h1>             <!-- 30% -->
    <button class="bg-orange-500 text-white">       <!-- 10% -->
      主操作
    </button>
  </div>
</template>
```

```tsx
// React + CSS Variables
const theme = {
  bg: 'var(--color-bg)',                   // 60%
  text: 'var(--color-text)',               // 30%
  accent: 'var(--color-accent)',           // 10%
  accentSoft: 'var(--color-accent-soft)'   // 10% × 0.05
}
```
