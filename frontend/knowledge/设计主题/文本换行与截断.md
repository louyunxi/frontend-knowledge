# 文本换行与截断

## 概述

文本换行和截断是排版中的常见需求，需要根据内容类型选择正确的处理方式，避免布局问题。

## 来源

- Skill: `better-typography`
- 来源文件: `better-typography/SKILL.md` 相关章节
- 蒸馏类型: best
- 蒸馏时间: 2026-09-15

## 四大声明

```css
/* 1. 均匀分布（用于标题） */
.heading {
  text-wrap: balance;
}

/* 2. 避免孤行（用于描述） */
.description {
  text-wrap: pretty;
}

/* 3. 长词换行 */
.code {
  overflow-wrap: break-word;
}

/* 4. 禁止换行（用于标签） */
.badge {
  white-space: nowrap;
}
```

## text-wrap 模式

### balance - 均匀分布

```text
适用：标题
原理：将文本均匀分布在各行
效果：两行标题不会一行很长一行很短
```

```css
/* 前 */
╔═══════════════════════════╗
║  This Is A Very Long Title║
║  Here                      ║
╚═══════════════════════════╝

/* 后 */
╔═══════════════════════════╗
║  This Is a Very           ║
║  Long Title Here           ║
╚═══════════════════════════╝
```

```css
.heading {
  text-wrap: balance;
}
```

```tsx
{/* Tailwind */}
<h1 class="text-balance">长标题文本</h1>
```

### pretty - 避免孤行

```text
适用：描述文本、段落
原理：防止最后一行只有一个单词
效果：更自然的段落结尾
```

```css
/* 前 */
╔═══════════════════════════╗
║  This is a description    ║
║  that explains something  ║
║  about the product and    ║
║  features. Here          ║
╚═══════════════════════════╝
                      ↑ 孤行

/* 后 */
╔═══════════════════════════╗
║  This is a description    ║
║  that explains something  ║
║  about the product and    ║
║  features Here           ║
╚═══════════════════════════╝
```

```css
.description {
  text-wrap: pretty;
}
```

```tsx
{/* Tailwind */}
<p class="text-pretty">长描述文本...</p>
```

### 使用注意

```text
⚠️ 不要在长段落中使用 balance 和 pretty
- 影响性能（需要多次布局计算）
- 对用户不可见
- 仅用于标题和短描述
```

## 溢出处理

### overflow-wrap - 长词换行

```text
场景：长URL、长代码、无空格的连续文本
问题：可能溢出容器
```

```css
/* 换行而非溢出 */
.code-block {
  overflow-wrap: break-word;
}

/* Tailwind */
<div className="break-words">长文本...</div>
```

```css
/* 前 */
╔═══════════════════════════════╗
║  https://very-long-domain.co ║
║  m/with/very/long/path/and/q ║
║  uery/parameters/here         ║ ← 溢出
╚═══════════════════════════════╝

/* 后 */
╔═══════════════════════════════╗
║  https://very-long-domain.com ║
║  /with/very/long/path/and/    ║
║  query/parameters/here        ║
╚═══════════════════════════════╝
```

### white-space - 禁止换行

```text
场景：标签、徽章、按钮文字
问题：标签换行显得分散
```

```css
.badge {
  white-space: nowrap;
}
```

```css
/* 前 */
╔═══════════════════════════════╗
║  [重要] [新功能] [限时]      ║
║                               ║
║  [重                            ║ ← 换行了
║   要]                          ║
╚═══════════════════════════════╝

/* 后 */
╔═══════════════════════════════╗
║  [重要] [新功能] [限时]       ║
║  [推荐] [热门] [热卖中]       ║
╚═══════════════════════════════╝
```

## 截断处理

### 单行截断

```css
.single-line {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

```tsx
{/* Tailwind */}
<span className="truncate">超长文本内容...</span>
```

### 多行截断

```css
.multi-line {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;
  overflow: hidden;
}
```

```tsx
{/* Tailwind */}
<p className="line-clamp-3">超长多行文本内容...</p>
```

### 截断提示

```text
⚠️ 截断会隐藏内容
如果被截断的内容重要：
- 添加 tooltip 显示完整内容
- 提供展开查看功能
- 或改用更小的字号
```

## 智能标点

### 弯引号

```html
<!-- HTML实体 -->
<p>他说："你好"</p>
<p>&ldquo;你好&rdquo;</p>
```

```text
区别：
" 直引号（代码用）
" " 弯引号（正文用）
```

### 短破折号（En Dash）

```html
<!-- 范围 -->
<p>2020–2024年</p>
<p>北京–上海</p>
```

### 省略号

```html
<!-- 用单字符而非三个点 -->
<p>加载中…</p>
<p>&hellip;</p>
```

### 不换行空格

```html
<!-- 防止特定词组换行 -->
<p>16 px</p>
<p>16&nbsp;px</p>
```

### 软连字符

```html
<!-- 长单词可在指定位置换行 -->
<p>anti&shy;constitution</p>
```

## 下划线样式

### 基本下划线

```css
a {
  text-decoration: underline;
  text-underline-position: from-font;
  text-decoration-thickness: from-font;
}
```

### 跳过下延字母

```css
/* 下划线在 g, y, p 等字母处断开 */
a {
  text-decoration-skip-ink: auto;
}
```

### 点状下划线

```css
/* 表示缩写或术语 */
abbr {
  text-decoration: underline dotted;
}
```

### 下划线偏移

```css
a {
  text-decoration-thickness: 1px;
  text-underline-offset: 3px;
  text-decoration-color: var(--color-gray-400);
}

a:hover {
  text-decoration-color: var(--color-gray-600);
}
```

### 下划线动画

```text
⚠️ 动画下划线：只有颜色可以可靠动画
其他属性（位置、粗细）动画复杂

如果需要完整动画效果：
用伪元素替代 text-decoration
```

```css
/* 可动画的下划线 */
.link {
  position: relative;
  color: var(--color-primary);
}

.link::after {
  content: '';
  position: absolute;
  left: 0;
  bottom: -2px;
  width: 100%;
  height: 2px;
  background: var(--color-primary);
  transform: scaleX(0);
  transform-origin: right;
  transition: transform 0.3s ease;
}

.link:hover::after {
  transform: scaleX(1);
  transform-origin: left;
}
```

## 文本选择

```css
/* 默认：保持可选 */
p, span, div {
  user-select: auto;
}

/* 禁用（仅限拖拽/手势冲突） */
.drag-handle {
  user-select: none;
}
```

```text
⚠️ user-select: none 使用场景：
- 拖拽把手
- 手势驱动界面
- 绘图/签名区域

❌ 不要全局禁用：
- 按钮标签
- 表单输入
- 应用整体界面
```

## 常见问题

| 问题 | 解决 |
|------|------|
| 标题两行一长一短 | `text-wrap: balance` |
| 描述最后一行孤行 | `text-wrap: pretty` |
| 长URL溢出 | `overflow-wrap: break-word` |
| 标签换行 | `white-space: nowrap` |
| 长文本截断 | `text-overflow: ellipsis` |
| 下划线穿过字母 | `text-decoration-skip-ink: auto` |
| 需要动画下划线 | 用伪元素替代 |

## 反模式

- ❌ 在长段落中用 `text-wrap: balance`
- ❌ 用三个点代替省略号：`...`
- ❌ 全局 `user-select: none`
- ❌ 用 `text-decoration` 做动画下划线
- ❌ 截断重要内容不提供替代方案
