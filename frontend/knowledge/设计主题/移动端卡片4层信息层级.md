# 移动端卡片 4 层信息层级

## 概述

移动端卡片信息分为 4 个层级：**主信息 → 次信息 → 辅助信息 → 元信息**。通过字号、字重、颜色的组合建立清晰的视觉层级，而不是靠加粗和字号堆砌。

## 核心规则

```
层级建立方法 = 字号差 + 字重差 + 透明度差

主信息：最大字号（28-36rpx）+ 正常字重 + 100% 透明度
次信息：中等字号（24-28rpx）+ 正常/中字重 + 100% 透明度
辅助信息：小字号（22-24rpx）+ 正常字重 + 60-80% 透明度
元信息：最小字号（20-22rpx）+ 正常字重 + 40-60% 透明度
```

## 4 层信息定义

### 第 1 层：主信息（Primary）

```
位置：卡片左上或顶部
字号：28-36rpx（最大）
字重：500-600（中等偏重）
颜色：var(--color-text-primary) 100%
用途：数字金额、商品名称、标题、核心指标

示例：
¥1,234.56   ← 数字金额
iPhone 15    ← 商品名称
本月营收      ← 指标名称
```

### 第 2 层：次信息（Secondary）

```
位置：主信息旁边或下方
字号：24-28rpx
字重：400-500
颜色：var(--color-text-primary) 100%
用途：单位、规格、描述、辅助说明

示例：
元    ← 单位（配合 ¥1,234）
128GB  ← 规格
2024年 ← 时间
```

### 第 3 层：辅助信息（Auxiliary）

```
位置：主信息下方或卡片中间
字号：22-24rpx
字重：400
颜色：var(--color-text-secondary) 或 80% 透明度
用途：详情描述、分类标签、简短说明

示例：
苹果官方旗舰店
限时特惠 · 30天最低价
深圳市南山区科技园
```

### 第 4 层：元信息（Meta）

```
位置：卡片底部或角落
字号：20-22rpx（最小）
字重：400
颜色：var(--color-text-tertiary) 或 60% 透明度
用途：时间戳、浏览量、来源、标签

示例：
3分钟前
1.2万浏览
来自京东
#数码 #手机
```

## 层级组合表

| 层级 | 字号 | 字重 | 透明度 | 颜色变量 |
|------|------|------|--------|---------|
| 主信息 | 28-36rpx | 500-600 | 100% | `--color-text-primary` |
| 次信息 | 24-28rpx | 400-500 | 100% | `--color-text-primary` |
| 辅助信息 | 22-24rpx | 400 | 70-80% | `--color-text-secondary` |
| 元信息 | 20-22rpx | 400 | 50-60% | `--color-text-tertiary` |

## 反模式

- ❌ 所有文字使用相同字号 → 没有层级
- ❌ 只靠加粗来区分层级 → 粗体过多显得廉价
- ❌ 标签字号比主信息还大 → 喧宾夺主
- ❌ 使用超过 4 层信息 → 信息过载
- ❌ 不使用 tabular-nums 的大数字 → 数字跳动
