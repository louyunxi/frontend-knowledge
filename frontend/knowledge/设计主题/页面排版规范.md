# 页面排版规范

## 概述

项目将页面级排版抽象为 4 大组件：`Hero`（首屏区）/ `Section`（内容区段）/ `Panel`（面板卡）/ `Form`（表单壳）。每种组件有固定的 padding、字号、圆角规范，跨页面复用形成统一的视觉语言。

## 设计令牌

### Hero（首屏区）

```scss
.wb-hero {
  position: relative;
  overflow: hidden;
  padding: 116px 24px 32px;     // 顶部预留吸顶 Header 高度
  color: var(--wb-text);
  text-align: left;
}

.wb-hero__eyebrow {
  display: inline-block;
  margin-bottom: 12px;
  font-size: 22px;             // S1
  line-height: 1.33;
  letter-spacing: -0.12px;
  color: var(--wb-text-tertiary);
}

.wb-hero__title {
  font-size: 44px;             // L3
  line-height: 1.12;
  letter-spacing: -0.24px;
  font-weight: 600;
}

.wb-hero__desc {
  margin: 12px 0 0;
  max-width: 620px;
  font-size: 22px;             // S1
  line-height: 1.35;
  letter-spacing: -0.22px;
  color: var(--wb-text-secondary);
}
```

### Section（内容区段）

```scss
.wb-section {
  padding: 24px;               // 16 + 8，混合水平与垂直
}
```

## 排版组合公式

### 4 大组件尺寸速查

| 组件 | 圆角 | 内边距 | 标题字号 | 描述字号 |
|------|------|--------|---------|---------|
| Hero | 无 | 116px 24px 32px | 44px | 22px |
| Section | 无 | 24px | - | - |
| Panel | 32px | 28px 32px 0（header） | 42px | 26px |
| Form Panel | 32px | 42px 32px | 44px | 18px |

### 字号映射

```
Hero Title    → 44px (L3)       600 weight   1.12 line-height
Hero Desc     → 22px (S1)       400 weight   1.35 line-height
Panel Title   → 42px (L4)       600 weight   1.1 line-height
Panel Meta    → 24px (M6)       400 weight   1.33 line-height
Panel Copy    → 26px (M5)       400 weight   1.47 line-height
Form Title    → 44px (L3)       600 weight   1.1 line-height
Form Subtitle → 18px (XS)       400 weight   1.47 line-height
```

## 应用示例

### Hero + Section + Panel 组合

```vue
<template>
  <div class="wb-page">
    <!-- Hero 首屏 -->
    <section class="wb-hero">
      <span class="wb-hero__eyebrow">推荐</span>
      <h1 class="wb-hero__title">发现更多好物</h1>
      <p class="wb-hero__desc">编辑精选，每周更新</p>
    </section>

    <!-- 内容区段 -->
    <section class="wb-section">
      <!-- 面板卡 -->
      <div class="wb-panel">
        <header class="wb-panel__header">
          <h2 class="wb-panel__title">新品速递</h2>
          <span class="wb-panel__meta">查看全部</span>
        </header>
        <p class="wb-copy">这里的副标题与说明文字...</p>

```

## 最佳实践

### ✅ 推荐

- 首屏使用 Hero + Section 组合，提供清晰的视觉锚点
- 长内容页使用 Panel 包裹关键信息块
- 表单使用 Form Shell 提供一致的表单体验
- 所有面板共享 `wb-panel` 基类，通过修饰符 `--dark` 等扩展

### ❌ 避免

- 直接修改 Hero/Section 的 padding（应通过修饰类扩展）
- 在 Section 内嵌套 Hero（破坏语义层级）
- 自定义 Form Panel 而不复用 `.wb-form-panel`（导致样式漂移）

## 性能考虑

- Hero 用 `position: relative; overflow: hidden;` 防止内容溢出触发外层重排
- Panel 使用 `backdrop-filter` 时应避免大尺寸应用（GPU 成本高）

## 无障碍

- Hero 标题使用 `<h1>` 语义化标签
- Panel 标题使用 `<h2>` 保持标题层级
- Form Label 关联 input 保证屏幕阅读器可读
