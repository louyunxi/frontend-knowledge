# 移动端排版规范

## 概述

移动端排版的核心是"克制"——用最少的字号和字重构建清晰的视觉层级，而不是用大字号和粗体堆砌。

## 核心规则

### 字体数量限制

```text
1. 字体家族最多 1 个（特殊情况 2 个）
   - 主字体：界面所有文字
   - 辅助字体：仅用于品牌标识或特殊展示

2. 字号最多 4 个
3. 字重最多 2 个
```

### 推荐字号系统（4 级）

```css
/* 移动端基础字号 (基于 16px 基准) */
.text-display { font-size: 28px; line-height: 1.2; }   /* 数字大屏、Hero */
.text-title   { font-size: 20px; line-height: 1.3; }   /* 页面标题 */
.text-body    { font-size: 15px; line-height: 1.5; }   /* 正文 */
.text-caption { font-size: 13px; line-height: 1.4; }   /* 辅助文字 */
```

### 推荐字重（2 级）

```css
.font-regular { font-weight: 400; }  /* 正文 */
.font-medium  { font-weight: 600; }  /* 强调 */
```

## 数字字体：等宽变体

对于价格、统计、指标等大数字，使用等宽字体（tabular-nums）避免数值跳动：

```css
.tabular-nums {
  font-variant-numeric: tabular-nums;
  font-feature-settings: "tnum" 1;
}

/* Tailwind */
.tabular-nums { font-variant-numeric: tabular-nums; }
```

```tsx
<span className="text-3xl font-medium tabular-nums">¥1,234.56</span>
```

## 文字容器宽度

```text
正文行长度控制在 600px 以内
移动端单屏宽度 ≈ 375px (iPhone SE)
建议：移动端单行字符 30-40 个汉字，60-80 个英文字符
```

## 视觉层级建立方法

### ❌ 错误：只靠加粗

```text
"销售" 加粗 + "591" 普通
结果：标签比数值更显眼
```

### ✅ 正确：尺寸 + 字重 + 透明度组合

```text
"销售" 13px / 中性色 65% 透明度
"591"  28px / 中性色 100% + 等宽
```

## 实施模板

### Vue + TypeScript

```vue
<template>
  <article class="stat-card">
    <p class="stat-label">本月营收</p>
    <p class="stat-value tabular-nums">¥128,450</p>
  </article>
</template>

<style scoped>
.stat-card { padding: 16px; }
.stat-label {
  font-size: 13px;
  font-weight: 400;
  color: rgba(0, 0, 0, 0.65);
  margin-bottom: 8px;
}
.stat-value {
  font-size: 28px;
  font-weight: 600;
  font-variant-numeric: tabular-nums;
  color: rgba(0, 0, 0, 1);
}
</style>
```

### React + Tailwind

```tsx
<div className="p-4">
  <p className="text-caption text-gray-500 mb-2">本月营收</p>
  <p className="text-display font-medium text-gray-900 tabular-nums">
    ¥128,450
  </p>
</div>
```

## 反模式

- ❌ 使用 5+ 种字号
- ❌ 用 3 种以上字重（Light / Regular / Medium / Bold / Black）
- ❌ 标签字号比数值还大
- ❌ 在小屏上硬塞长段落不限制宽度
- ❌ 多字体家族（衬线 + 无衬线 + 手写体）
