# AI 设计反模式识别

## 概述

AI 生成的 Web 设计容易聚集在某些特定模式中，这些模式本身没有问题，但当它们成为默认选择时，设计会显得模板化和缺乏个性。

本知识帮助你识别这些反模式，在设计时有意识地做出更独特的选择。

---

## 常见反模式

### 1. 暖色调 + 衬线体组合

```
❌ 常见模式：
- 暖奶油色背景 (#F4F1EA)
- 高对比度衬线体标题
- 陶土色或暖色强调色 (#D97757)

⚠️ 问题：
- 这个组合过于常见
- 容易显得模板化
- 需要特殊理由才使用

✅ 建议：
- 如果不适用，替换为其他配色
- 考虑产品/行业特性选择配色
```

### 2. 深色背景 + 亮色强调

```
❌ 常见模式：
- 近黑色背景
- 单个明亮的酸绿色或朱红色强调色

⚠️ 问题：
- 过于极端
- 视觉疲劳
- 不适合所有产品

✅ 建议：
- 考虑使用场景
- 深色模式需要有明确理由
```

### 3. 报纸风格布局

```
❌ 常见模式：
- 细线分隔
- 零圆角
- 密集的报纸式多列布局

⚠️ 问题：
- 不适合现代 Web
- 阅读体验差
- 过于传统

✅ 建议：
- 根据内容特性选择布局
- 考虑响应式需求
```

### 4. SaaS 卡片套件

```
❌ 常见模式：
- 内容切分为相同的圆角卡片
- 所有元素使用相同的圆角
- 相同的柔和灰色阴影 (rgba(0,0,0,.1))
- 渐变洗色作为装饰

⚠️ 问题：
- 视觉层次不清
- 缺乏焦点
- 过度使用卡片

✅ 建议：
- 使用卡片时保持层次
- 阴影和圆角应该有变化
- 避免不必要的装饰
```

### 5. 模板化 UI 元素

```
❌ 常见模式：

1. 眉毛标签
   ALL CAPS eyebrow label above every heading

2. 元数据分隔
   A · B · C (用点号连接)

3. 标签格式
   WORD — fragment (用长破折号)

4. 深色替代黑色
   #0B0B0B, #111 代替纯黑

5. 等宽字体数据标签
   monospace face for small data labels

6. 链接箭头
   '→' appended to link and button text

⚠️ 问题：
- 这些元素出现不考虑主题
- 成为默认装饰
- 缺乏设计意图

✅ 建议：
- 每个元素都应该有理由
- 检查是否符合当前主题
- 避免无意义的装饰
```

## 避免策略

### 1. 两阶段设计流程

```
Phase 1: 构思设计计划
━━━━━━━━━━━━━━━━━━━━━━
在写代码之前，先制定设计计划：

1. 色彩系统
   描述 4-6 个命名颜色值

2. 字体系统
   选择字体家族及其角色

3. 布局概念
   用简洁的句子描述
   用 ASCII 线框图 ideation

4. 设计原则
   高层次的独特性指导

━━━━━━━━━━━━━━━━━━━━━━

Phase 2: 评审后再实现
━━━━━━━━━━━━━━━━━━━━━━
实现前检查设计计划：

❓ 关键问题：
- 这个设计是否对这个主题独特？
- 如果用类似提示词，是否会得到类似设计？
- 设计选择是否有理由？

如果答案是"会得到类似设计"：
→ 修订这部分设计

只有确认设计独特性后，才开始写代码

━━━━━━━━━━━━━━━━━━━━━━
```

### 2. 主题驱动设计

```
设计应该基于：

✅ 产品的行业
   金融仪表盘 vs 儿童玩具网站

✅ 产品的主题
   游戏 vs 企业软件

✅ 目标受众
   设计师 vs 工程师 vs 儿童

✅ 实际内容
   使用真实内容设计
   不是占位符填充

❌ 不要：
- 使用任何项目都会用的默认设计
- 不考虑产品特性
- 不考虑用户群体
```

### 3. 克制的原则

```
一个页面应该：
━━━━━━━━━━━━━━━━━━━━━━
✅ 一个焦点
   让一个元素成为记忆点

✅ 其他保持安静
   围绕焦点的元素保持克制

✅ 移除不必要的装饰
   每个装饰都应该服务目的

❌ 不要：
- 每个元素都想突出
- 过度装饰
- 缺乏层次

示例：
焦点可能是：
- 一个大标题
- 一个核心图片
- 一个关键数据
- 一个独特的视觉元素
━━━━━━━━━━━━━━━━━━━━━━
```

## 设计检查清单

### 开始前

```
□ 产品/主题是什么？
□ 目标受众是谁？
□ 设计的主要任务是什么？
□ 产品/行业的视觉词汇是什么？
□ 有哪些约束条件？
```

### 设计中

```
□ 设计是否对这个主题独特？
□ 是否避免了常见反模式？
□ 每个设计选择是否有理由？
□ 是否有清晰的视觉焦点？
□ 是否保持了克制？
```

### 完成后

```
□ 是否有模板化的痕迹？
□ 设计是否与竞品区分？
□ 是否符合品牌调性？
□ 是否考虑了一致性？
```
