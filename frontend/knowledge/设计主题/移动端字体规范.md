# 移动端字体规范

## 概述

项目采用 Apple HIG 风格的「**精简阶差 + 字重变化**」排版体系：18px 到 88px 共 14 个核心字号档位，SF Pro Text / Display + PingFang SC 字体栈，行高普遍 1.0-1.47，配合字重 500/600/700 三档控制层次。

## 设计令牌

### SCSS 变量（基础）

```scss
$large: 38px;     // 主价格
$normal: 32px;    // 标题
$small: 28px;     // 副标题
$mini: 20px;      // 标签
```

## 字体栈

```scss

  font-family:
    'SF Pro Text',
    'SF Pro Display',
    'PingFang SC',
    'Helvetica Neue',
    Helvetica,
    Arial,
    sans-serif;
  -webkit-font-smoothing: antialiased;
  text-rendering: optimizeLegibility;

  line-height: 1.47;
}
```

  font-weight: 600;       // Semibold
  letter-spacing: -0.12px; // 紧凑字距
  -webkit-line-clamp: 2;  // 限两行

  line-height: 1;         // 数字行高紧贴

## 字重（Font Weight）

| 字重 | 用途 |
|------|------|
| 400 / Regular | 辅助说明 |
| 500 / Medium | 类目名称、辅标题 |
| 600 / Semibold | 主标题、价格、按钮 |
| 700 / Bold | Hero 数字、价格强调 |

## 字距（Letter Spacing）

| 场景 | 推荐值 |
|------|-------|
| 大字号（>=38px） | -0.22 ~ -0.28px（紧排） |
| 中字号（26-36px） | -0.12 ~ -0.22px |
| 小字号（<=24px） | 0（默认） |
| 大写英文 | 0.5-1px（加宽） |

## 行高（Line Height）

| 场景 | 推荐值 |
|------|-------|
| 大数字（>=48px） | 1 |
| 标题（32-44px） | 1.08-1.26 |
| 正文（24-28px） | 1.28-1.47 |
| 多行文本 | 1.47 |

## 响应式策略

```css
@media (max-width: 480px) {
  .wb-hero__title { font-size: 38px; }     /* 44 → 38 */
  .wb-form-title { font-size: 36px; }      /* 44 → 36 */
}
```

## 最佳实践

### ✅ 推荐

- 标题使用 600/700 字重，正文使用 400/500
- 价格字号 ≥ 价格货币字号（如 38 / 30）
- 数字加 `font-variant-numeric: tabular-nums` 保证等宽对齐
- 标题负字距（-0.12 ~ -0.28px）提升精致感
- 正文行高 1.4-1.5，大标题 1.0-1.2

### ❌ 避免

- 同时使用 5+ 种字号（视觉杂乱）
- 字距为正数（中文不适用）
- 字号过大超出容器（导致文字溢出）
- 在 18px 以下（移动端最小可读尺寸）

## 无障碍

- 主文本最小 22px，移动端可读性保证
- 用户可通过系统设置放大（rem 适配）
- 颜色对比度 ≥4.5:1（详见色彩系统）

## 性能考虑

- 字体子集化（中文可大幅压缩）
- 字体声明加 `display: swap` 避免 FOIT
- 使用 `text-rendering: optimizeLegibility`

```css
@font-face {
  font-family: 'PingFang SC';
  src: url('...woff2') format('woff2');
  font-display: swap;
}
```
