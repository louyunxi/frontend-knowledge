# 移动端行业设计语言

## 概述

不同行业的移动应用已形成用户期待的设计惯例。理解这些惯例能帮助决定何时"遵循惯例以建立熟悉感"，何时"打破惯例以脱颖而出"。

## 行业设计惯例速查表

| 行业 | 视觉惯例 | 关键案例 | 核心策略 |
|------|---------|---------|---------|
| AI / 科技 | 渐变、动态、深度感、光晕 | ChatGPT / Perplexity | 用平滑动画传递"智能" |
| 加密 / Web3 | 深色、霓虹、几何、未来感 | Phantom | 抛光建立信任 |
| 金融 / 银行 | 信任蓝、留白、保守字体 | Revolut | 触觉交互溢价 |
| 健康 / 健身 | 明亮、温暖、低焦虑 | Ahead / Headspace | 温和引导 + 个性化洞察 |
| 睡眠 / 冥想 | 紫色深蓝、低对比、氛围感 | Calm | 降低刺激 = 放松 |
| 教育 / 学习 | 明亮活泼、角色化 | Duolingo | 情感反馈循环 |
| 效率 / 工具 | 极简、信息密度、键盘快捷 | Notion / Linear | 信息架构清晰 |

## AI / 科技产品

```text
视觉惯例：
- 柔和渐变和动态元素
- 通过发光元素建立深度和维度
- 平滑动画传达"智能"
- 深色或浅色主题搭配空灵 accent色
```

```css
/* AI 主题配色示例 */
:root {
  --color-bg: #0F1115;
  --color-surface: #1A1D24;
  --color-accent: linear-gradient(135deg, #8B5CF6, #06B6D4);
  --color-glow: rgba(139, 92, 246, 0.4);
}

.glow-card {
  background: var(--color-surface);
  border: 1px solid rgba(139, 92, 246, 0.3);
  box-shadow: 0 0 24px var(--color-glow);
}
```

## 加密 / Web3

```text
视觉惯例：
- 未来感美学：霓虹色 + 粗体字
- 深色背景搭配几何形状
- 高对比、尖端视觉语言

Phantom 经验：
- 抛光建立信任
- 把视觉细节、运动、转场视为核心产品功能，不是装饰
- 关键启示：高风险领域（金融、健康、加密），视觉精度 = 用户信任
```

```css
:root {
  --color-bg: #0A0B0F;
  --color-text: #FFFFFF;
  --color-accent: #8B5CF6;       /* 紫色霓虹 */
  --color-success: #00FF88;       /* 荧光绿 */
  --color-border: rgba(255, 255, 255, 0.08);
}
```

## 金融 / 银行

```text
视觉惯例：
- 蓝色主导调色板（信任、稳定、可靠）
- 慷慨留白、清晰布局、保守字体
- 必须感觉安全、专业

Revolut 经验：
- 触觉交互（可拖动图表、3D 卡片翻转）
- 把基础功能通过精细交互变为高级体验
- 关键启示：基础功能也能"溢价"
```

```css
:root {
  --color-bg: #F5F7FA;
  --color-surface: #FFFFFF;
  --color-primary: #1652F0;       /* 信任蓝 */
  --color-success: #00C853;
  --color-danger: #D32F2F;
  --color-text-primary: #0A2540;
  --color-text-secondary: #425466;
}
```

## 健康 / 健身

```text
视觉惯例：
- 明亮、易接近的颜色降低焦虑
- 友好插画和温暖微交互
- 非威胁性 onboarding 流程

Ahead 经验（Apple Design Award）：
- 温和引导用户
- 把"峰值"建成个性化洞察时刻
- 关键启示：心理健康类产品要主动降低压力峰值
```

```css
:root {
  --color-bg: #FFFBF5;
  --color-accent: #FF6B6B;       /* 珊瑚色，温暖 */
  --color-secondary: #4ECDC4;    /* 薄荷绿 */
  --color-text: #2D3142;
}
```

## 睡眠 / 冥想

```text
视觉惯例：
- 紫色和深蓝色调（平静关联）
- 极简 UI、柔和过渡
- 环境感、低对比界面

设计原则：
- 降低视觉刺激
- 缓慢动画（500ms+）
- 大面积负空间
- 暗色为主，避免明亮色
```

```css
:root {
  --color-bg: #1A1B3A;           /* 深紫色 */
  --color-surface: #252852;
  --color-accent: #6B5B95;       /* 雾紫 */
  --color-text: #E8E8F0;
  --color-text-soft: rgba(232, 232, 240, 0.7);
}
```

## 教育 / 学习

```text
视觉惯例：
- 明亮、活泼调色板
- 角色驱动体验，带有个性

Duolingo 经验：
- 角色动画 + 情感反馈循环
- 答对：吉祥物欢呼动画
- 答错：温和失望 + 鼓励重试
- 连续打卡：角色逐步成长动画
- 错过打卡：角色"想念你"复访提醒
- 结果：DAU 从 14.2M → 34M+（2 年内翻倍）
```

```css
:root {
  --color-bg: #FFFFFF;
  --color-primary: #58CC02;       /* 鲜绿 */
  --color-secondary: #1CB0F6;     /* 亮蓝 */
  --color-accent: #FF9600;        /* 橙色 */
  --color-danger: #FF4B4B;
  --color-text: #4B4B4B;
}
```

## 效率 / 工具

```text
视觉惯例：
- 清晰、极简、信息密集但有组织
- 强网格系统和一致间距
- 快速操作模式和键盘快捷键

参考案例：
- Notion：单色 + 极简，强调内容
- Linear：深色 + 等宽字体，强调工程师文化
- Things 3：浅色 + 柔和阴影，强调优雅

设计要点：
- 高级用户密度更大（更多快捷键、更少 hover）
- 新手用户密度更小（更多引导、更少快捷键）
```

```css
:root {
  --color-bg: #FAFAFA;
  --color-surface: #FFFFFF;
  --color-primary: #5E6AD2;       /* 工具蓝紫 */
  --color-text: #1A1A1A;
  --color-border: rgba(0, 0, 0, 0.08);
}
```

## 电商 / 食物

```text
视觉惯例：
- 高质量产品摄影
- 显眼 CTA 和无缝结账流程
- 信任信号：评论、评分、配送预估
```

## 行业选择决策树

```text
开始
  │
  ├── 用户是新用户？
  │   └── YES → 遵循惯例（建立熟悉感）
  │
  ├── 用户是老用户？
  │   └── YES → 微创新（强化品牌识别）
  │
  ├── 是否是高风险领域？
  │   │   （金融、健康、加密）
  │   └── YES → 严格遵循惯例 + 抛光细节
  │
  └── 追求差异化？
      └── NO → 遵循惯例
      └── YES → 打破 1-2 个惯例，但保留核心体验逻辑
```

## 行业混搭策略

```text
允许的混搭：
- 金融的"信任蓝" + AI 的"发光效果"
- 教育的"明亮色" + 健康的"温暖插画"
- 睡眠的"深紫" + 加密的"霓虹强调"

禁止的混搭：
- 金融的"严肃感" + 教育的"卡通角色"
- 健康的"温暖" + 睡眠的"深色"（错位）
- 效率的"信息密度" + 冥想的"极简"（互相抵消）
```
