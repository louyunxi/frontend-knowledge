# 调试与首屏优化（eruda + 首屏动画 + gzip）

> 适用场景：基于 Vue3 + Vite 的**纯 H5** 项目，提升调试效率与首屏体验。
> 本文档提炼 vue3-h5-template 的调试方案与首屏优化策略。

## 一、eruda 移动端调试面板

### 1.1 简介

[eruda](https://github.com/nicknisi/eruda) 是为移动端网页设计的调试面板，类似 Chrome DevTools，提供：

- Console 日志
- Elements DOM 查看
- Network 网络请求
- Resources 资源
- Sources 源码
- Application Storage

### 1.2 配置

```ts
// src/main.ts
if (import.meta.env.VITE_ENABLE_ERUDA === 'true') {
  const script = document.createElement('script')
  script.src = '//cdn.jsdelivr.net/npm/eruda'
  script.onload = () => (window as any).eruda?.init()
  document.head.appendChild(script)
}
```

仅当 `.env.development` 中 `VITE_ENABLE_ERUDA=true` 时加载。

### 1.3 环境变量

```bash
# .env.development
VITE_ENABLE_ERUDA = "true"

# .env.production
VITE_ENABLE_ERUDA = "false"   # 或省略
```

### 1.4 优点与限制

| 优点 | 限制 |
|---|---|
| 移动端真机调试 | 体积约 200KB（CDN 加载不打包） |
| 内嵌页面 | 生产环境必须关闭 |
| 类似 DevTools | 性能开销较大 |
| 即开即用 | 必须公网访问 jsdelivr |

### 1.5 替代方案

| 工具 | 特点 |
|---|---|
| **vConsole** | 腾讯出品，轻量 |
| **Chrome Remote Debug** | 通过 USB 调试真机 |
| **Weinre** | 远程调试（已较少用） |

## 二、首屏加载动画

### 2.1 index.html 内嵌动画

```html
<!-- index.html -->
<div id="app">
  <style>
    html, body, #app {
      height: 100%;
      margin: 0px;
      padding: 0px;
      width: 100%;
    }
    .__spinner-container {
      height: 100%;
      display: flex;
      flex-direction: column;
      align-items: center;
      justify-content: center;
    }
    .__spinner {
      position: relative;
      width: 68px;
      height: 68px;
      background-color: #41b883;  /* Vue 绿色 */
      animation: cube-shadow-spinner 1.8s cubic-bezier(0.75, 0, 0.5, 1)
        infinite;
    }
    @keyframes cube-shadow-spinner {
      50% {
        border-radius: 50%;
        transform: scale(0.5) rotate(360deg);
      }
      100% {
        transform: scale(1) rotate(720deg);
      }
    }
  </style>
  <div class="__spinner-container">
    <div class="__spinner"></div>
  </div>
</div>
```

### 2.2 工作原理

1. 浏览器解析 HTML，**立即渲染** `#app` 中的 spinner（无需等待 JS）。
2. Vue 应用挂载完成后，**替换** spinner 为实际页面。
4. **避免白屏**，提供视觉反馈。

### 2.3 关键设计点

| 设计点 | 原因 |
|---|---|
| **内嵌 CSS** | 不依赖外部资源，最快渲染 |
| **使用 Vue 绿色**（#41b883） | 体现项目品牌 |
| **立方体旋转 + 圆角 + 缩放** | 视觉简洁，无图片依赖 |
| **`cubic-bezier(0.75, 0, 0.5, 1)`** | 缓动曲线显得优雅 |

### 2.4 进阶优化

如需更精细的过渡：

```js
// main.ts
app.mount('#app').$nextTick(() => {
  // 移除 spinner
  document.querySelector('.__spinner-container')?.remove()
})
```

## 三、gzip 压缩

### 3.1 插件配置

```ts
// vite.config.ts
import { compression } from 'vite-plugin-compression2'
plugins: [compression()],
```

### 3.2 产出

```
dist/
├── static/
│   ├── js/
│   │   ├── index-abc123.js
│   │   └── index-abc123.js.gz   ← 新增
│   ├── css/
│   │   ├── index-xyz.css
│   │   └── index-xyz.css.gz     ← 新增
```

### 3.3 Nginx 配置

```nginx
server {
  listen 80;
  server_name example.com;
  root /var/www/dist;

  # 启用 gzip_static（发送预压缩文件）
  gzip_static on;
  gzip_proxied any;
  gzip_types text/plain text/css application/json application/javascript;

  # SPA fallback
  location / {
    try_files $uri $uri/ /index.html;
  }
}
```

要点：
- **`gzip_static on`** 启用预压缩文件（关键）。
- `gzip_types` 列出要压缩的类型（可选）。
- `try_files` 处理 SPA 路由 fallback。

### 3.4 效果

| 文件 | 原始 | gzip 后 | 压缩率 |
|---|---|---|---|
| vendor.js（Vue + Vant + Router） | ~600KB | ~180KB | 70% |
| index.js | ~50KB | ~15KB | 70% |
| index.css | ~30KB | ~8KB | 73% |

总产物减小约 60%-70%。

### 3.5 替代：brotli

如果想更高压缩率：

```ts
import { compression } from 'vite-plugin-compression2'
compression({
  algorithm: 'gzip',     // 或 'brotliCompress'
  ext: '.br',            // .br 扩展
})
```

但 brotli 需要服务端 `ngx_brotli` 模块支持。

## 四、CDN 加载依赖（生产环境）

### 4.1 配置

```ts
// build/cdn.ts
import { cdn } from 'vite-plugin-cdn2'
import { unpkg } from 'vite-plugin-cdn2/resolver/unpkg'

export function enableCDN(isEnabled: string) {
  if (isEnabled === 'true') {
    return cdn({
      resolve: unpkg(),
      modules: ['vue', 'vue-demi', 'pinia', 'axios', 'vant', 'vue-router'],
    })
  }
}
```

### 4.2 启用

```bash
# .env.production
VITE_CDN_DEPS = "true"
```

### 4.3 效果

构建后 HTML 自动注入：

```html
<script src="https://unpkg.com/vue@3.5.24/dist/vue.global.prod.js"></script>
<script src="https://unpkg.com/vue-router@4.6.3/dist/vue-router.global.prod.js"></script>
<!-- ... -->
```

产物 JS 不再包含这些依赖，体积减小 ~600KB。

### 4.4 适用场景

| 场景 | 是否启用 CDN |
|---|---|
| 公网部署 | ✅ 推荐 |
| 内网部署 | ❌ 必须关闭 |
| 高并发公网 | ✅ 推荐 + 增加缓存 |
| 移动弱网 | ❌ 不推荐（CDN 请求耗时） |

## 五、Vite 预加载指令

Vite 自动为入口 chunk 生成 `<link rel="modulepreload">`：

```html
<link rel="modulepreload" href="/static/js/vendor-abc123.js">
```

浏览器预加载关键资源，缩短 TTI（可交互时间）。

## 六、关键决策对比

| 维度 | 选择 | 替代 | 理由 |
|---|---|---|---|
| 调试工具 | eruda | vConsole / Remote Debug | 移动端真机调试友好 |
| 首屏动画 | CSS 动画内嵌 HTML | JS 动态创建 | 不依赖 JS 加载 |
| 压缩算法 | gzip | brotli | 服务端兼容性最好 |
| CDN 策略 | unpkg | jsdelivr / cdnjs | unpkg 默认按需加载 |
| 字体加载 | system font | Google Fonts | 避免 DNS 解析延迟 |

## 七、性能指标参考

针对移动端首屏：

| 指标 | 目标 | 本模板优化手段 |
|---|---|---|
| FCP（首次内容渲染） | < 1.8s | 首屏动画内嵌 HTML |
| LCP（最大内容渲染） | < 2.5s | 首屏内容体积小 |
| TTI（可交互时间） | < 3.8s | gzip + CDN |
| CLS（累积布局偏移） | < 0.1 | 首屏动画尺寸固定 |
| TBT（总阻塞时间） | < 200ms | 按需加载 + 代码分割 |

## 八、常见踩坑

1. **eruda 加载失败**：jsdelivr 在某些地区被墙，改为 `cdnjs.cloudflare.com`。
2. **首屏动画残影**：`<App>` 内容溢出导致动画残留，加 `overflow: hidden`。
3. **gzip 文件不生效**：Nginx 没启用 `gzip_static on`，或缺少 `gzip_types`。
4. **CDN 引入 404**：`VITE_CDN_DEPS=true` 后还需确保 unpkg 可访问。
5. **字体加载延迟**：避免使用 Google Fonts，会增加 DNS 查询。
