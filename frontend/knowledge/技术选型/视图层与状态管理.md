# 视图层与状态管理（Vue 3 + Pinia + Vue Router）

> 适用场景：基于 Vue 3.5 + Vant 4 + Pinia 2 + Vue Router 4 的**纯 H5** 移动端项目。
> 本文档提炼 vue3-h5-template 的视图、路由、状态层核心模式。

## 二、Pinia 状态管理（Setup Store 写法）

### 2.1 入口极简

```ts
// src/store/index.ts
import { createPinia } from 'pinia'
const store = createPinia()
export { store }
```

无任何插件配置，纯净版。Pinia 默认支持 TS 推断和 SSR 安全。

### 2.2 模块化：每个功能一个文件

```
src/store/modules/
├── cached-view.ts   # 路由缓存策略
└── dark-mode.ts     # 暗色模式 + View Transition
```

### 2.3 路由缓存 store（核心模式）

```ts
// src/store/modules/cached-view.ts
import type { RouteLocationNormalized } from 'vue-router'

export const useCachedViewStore = defineStore('cached-view', () => {
  const cachedViewSet = ref(new Set<string>())
  const cachedViewList = ref<string[]>([])

  function addCachedView(view: RouteLocationNormalized) {
    const name = view.name as string
    if (cachedViewSet.value.has(name)) return
    if (!view?.meta?.noCache) {
      cachedViewSet.value.add(name)
      cachedViewList.value.push(name)
    }
  }

  function delCachedView(view: RouteLocationNormalized) {
    const name = view.name as string
    cachedViewSet.value.delete(name)
    const index = cachedViewList.value.indexOf(name)
    if (index > -1) cachedViewList.value.splice(index, 1)
  }

  function delAllCachedViews() {
    cachedViewSet.value.clear()
    cachedViewList.value = []
  }

  return { cachedViewSet, cachedViewList, addCachedView, delCachedView, delAllCachedViews }
})
```

**亮点**：
- `Set + Array` 双结构：`Set` 提供 O(1) 去重判断，`Array` 提供 `<keep-alive :include>` 所需的顺序列表。
- 通过 `meta.noCache` 标记不缓存的路由。
- 在路由前置守卫中调用 `addCachedView(to)`。

### 2.4 暗色模式 store（View Transition API）

```ts
// src/store/modules/dark-mode.ts
export const useDarkModeStore = defineStore('dark-mode', () => {
  const darkMode = ref(isDarkMode())

  const isDark = computed(() => darkMode.value)
  const theme = computed(() => darkMode.value ? 'dark' : 'light')

  function toggleDarkMode(event?: TouchEvent | MouseEvent) {
    // 1. 检测浏览器是否支持 View Transition
    const isAppearanceTransition
      = 'startViewTransition' in document
        && !window.matchMedia('(prefers-reduced-motion: reduce)').matches

    const toggle = () => {
      darkMode.value = !darkMode.value
      updateDarkMode(darkMode.value)
    }

    if (!isAppearanceTransition) {
      toggle()
      return
    }

    // 2. 计算过渡圆心（用户点击位置 / 屏幕右上角）
    let x: number, y: number
    if (event instanceof TouchEvent) {
      x = event.touches[0].clientX
      y = event.touches[0].clientY
    }
    else if (event instanceof MouseEvent) {
      x = event.clientX
      y = event.clientY
    }
    else {
      x = window.innerWidth
      y = 0
    }
    const endRadius = Math.hypot(
      Math.max(x, window.innerWidth - x),
      Math.max(y, window.innerHeight - y),
    )

    // 3. 调用 startViewTransition 包裹状态切换
    const transition = (document as any).startViewTransition(async () => {
      toggle()
      await nextTick()
    })

    transition.ready.then(() => {
      const clipPath = [
        `circle(0px at ${x}px ${y}px)`,
        `circle(${endRadius}px at ${x}px ${y}px)`,
      ]
      document.documentElement.animate(
        { clipPath: darkMode.value ? [...clipPath].reverse() : clipPath },
        {
          duration: 400,
          easing: 'ease-out',
          pseudoElement: darkMode.value
            ? '::view-transition-old(root)'
            : '::view-transition-new(root)',
        },
      )
    })
  }

  return { darkMode, isDark, theme, toggleDarkMode }
})
```

**亮点**：
- **使用浏览器原生 View Transition API**（无需 GSAP/Motion 库）。
- **支持点击位置扩散的圆形剪裁动画**（类 QQ/Twitter 主题切换效果）。
- 自动降级：浏览器不支持或开启了 `prefers-reduced-motion` 时直接切换。
- 支持触摸/鼠标事件自适应坐标。

## 三、Vue Router 4（Hash 模式）

### 3.1 入口

```ts
// src/router/index.ts
import { createRouter, createWebHashHistory } from 'vue-router'
import { useCachedViewStore } from '@/store/modules/cached-view'
import setPageTitle from '@/utils/set-page-title'
import routes from './routes'

const router = createRouter({
  history: createWebHashHistory(),  // 哈希模式
  routes,
})

router.beforeEach((to, _from, next) => {
  useCachedViewStore().addCachedView(to)
  setPageTitle(to.meta.title)
  next()
})

export default router
```

### 3.2 路由表

```ts
// src/router/routes.ts
const routes: Array<RouteRecordRaw> = [
  {
    path: '/',
    name: 'root',
    component: Layout,
    redirect: { name: 'Demo' },
    children: [
      { path: 'demo', name: 'Demo', component: () => import('@/views/demo/index.vue'), meta: { title: '主页' } },
      { path: 'tools', name: 'Tools', component: () => import('@/views/tools/index.vue'), meta: { title: '工具' } },
      { path: 'about', name: 'About', component: () => import('@/views/about/index.vue'), meta: { title: '关于', noCache: true } },
    ],
  },
  // 404
  { path: '/:pathMatch(.*)*', name: 'NotFound', component: () => import('@/views/404.vue'), meta: { title: '页面未找到', noCache: true } },
]
```

要点：
- 业务页面全部走 **Layout 子路由**，方便后续加权限守卫。
- 404 路由**必须放在最后**，作为兜底。
- `meta.title` 用于动态页面标题。
- `meta.noCache: true` 关闭缓存。

### 3.3 路由 Meta 扩展类型

```ts
// src/typings/router.d.ts
import 'vue-router'

declare module 'vue-router' {
  interface RouteMeta {
    title?: string
    noCache?: boolean
  }
}
```

让 `route.meta.title` 有 TS 类型提示。

## 四、keep-alive 路由级缓存

```vue
<!-- src/layout/index.vue -->
<script setup lang="ts">
const cachedViewStore = useCachedViewStore()
const { cachedViewList } = storeToRefs(cachedViewStore)
</script>

<template>
  <van-config-provider :theme="theme">
    <NavBar />
    <router-view v-slot="{ Component }">
      <keep-alive :include="cachedViewList">
        <component :is="Component" />
      </keep-alive>
    </router-view>
    <tabbar />
  </van-config-provider>
</template>
```

**关键约束**：

> ⚠️ **组件的 `name` 必须与路由的 `name` 完全一致**，否则 keep-alive 无法识别组件身份导致缓存失败。

Vue 3.3+ 推荐的写法：

```vue
<script setup lang="ts">
defineOptions({
  name: 'About',  // 与路由的 name 对应
})
</script>
```

## 五、Vant 4 集成

### 5.1 全局配置（按需）

不需要 `app.use(Vant)`，组件自动按需导入。但**主题切换**通过 `<van-config-provider>`：

```vue
<van-config-provider :theme="theme">
  <NavBar />
  ...
</van-config-provider>
```

`theme` 是 Pinia 中 `dark-mode` store 计算出的 `'light' | 'dark'`，与 CSS 变量联动。

### 5.2 全局样式与 Toast

```ts
import { showFailToast } from 'vant'
import 'vant/es/toast/style'  // 重要：Toast 是函数式调用，必须手动引入样式
```

> ⚠️ 函数式 API（`showToast` / `showDialog`）**不会随组件自动引入 CSS**，必须显式 `import 'vant/es/<组件>/style'`。

### 5.3 Vant CSS 变量驱动设计

```less
// styles/variables.less
:root {
  --color-text: var(--van-text-color, #323233);
  --color-background-2: #fafafa;
  --color-block-background: #ffffff;
  --color-border: var(--van-border-color, #ebedf0);
}

html.dark {
  --color-text: var(--van-text-color, #f5f5f5);
  --color-background-2: var(--van-background-2, #1c1c1e);
  --color-block-background: var(--van-border-color, #3a3a3c);
  --color-border: var(--van-border-color, #3a3a3c);
}
```

要点：
- **业务 CSS 变量**复用 **Vant CSS 变量**，确保主题一致。
- 使用 `var(--van-text-color, #323233)` 形式，**Vant 主题切换时业务样式自动跟随**。

## 七、关键技术决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 状态管理 | Pinia 2 | 官方推荐，TS 友好，setup 写法 |
| 路由模式 | Hash | 静态部署友好，无需服务端 fallback |
| 路由缓存 | `<keep-alive :include>` + Pinia | 动态控制缓存列表 |
| UI 库 | Vant 4 | 移动端组件最全 |
| 主题切换 | Vant 内置 + View Transition | 浏览器原生 API，无第三方库 |
| 视图层规范 | `<script setup>` + `defineOptions` | Vue 3.3+ 标准写法 |

## 八、常见踩坑

1. **keep-alive 不生效**：`defineOptions` 中的 name 与路由 name 不一致，或写错大小写。
2. **Pinia 自动解构丢失响应性**：必须用 `storeToRefs(store)` 解构。
3. **Vant 函数式组件样式丢失**：手动 `import 'vant/es/<name>/style'`。
4. **Vue Router 4 守卫 `next` 不调用**：本项目使用同步 `next()`，不返回 `void`。
5. **Hash 模式下子路径刷新 404**：必须保证 dist 服务返回 `index.html`（Nginx 配置 `try_files`）。
