## 🔥 核心模式

### ⭐ 状态管理方案对比

| 特性 | Redux Toolkit | Zustand | Jotai | Valtio |
|-----|--------------|---------|-------|--------|
| 学习曲线 | 中等 | 低 | 低 | 低 |
| 包大小 | ~11KB | ~1KB | ~3KB | ~3KB |
| 类型安全 | 优秀 | 优秀 | 优秀 | 良好 |
| DevTools | 内置 | 支持 | 支持 | 支持 |
| 适用场景 | 大型复杂应用 | 中小型应用 | 原子化状态 | 响应式状态 |
| 样板代码 | 较多 | 极少 | 少 | 少 |

**Zustand 适用场景**
```tsx
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

interface AuthStore {
  user: User | null;
  login: (user: User) => void;
  logout: () => void;
}

const useAuthStore = create<AuthStore>()(
  persist(
    (set) => ({
      user: null,
      login: (user) => set({ user }),
      logout: () => set({ user: null }),
    }),
    { name: 'auth-storage' }
  )
);
```

**Jotai 适用场景**
```tsx
import { atom, useAtom } from 'jotai';

const userAtom = atom<User | null>(null);
const isLoggedInAtom = atom((get) => get(userAtom) !== null);

const UserProfile = () => {
  const [user] = useAtom(userAtom);
  const [isLoggedIn] = useAtom(isLoggedInAtom);
  // ...
};
```

### ⭐ 请求库对比

| 特性 | Axios | Fetch | Ky |
|-----|-------|-------|-----|
| 语法 | Promise | 原生 | Promise |
| 拦截器 | 支持 | 不支持 | 支持(插件) |
| 自动JSON | 是 | 需手动 | 是 |
| 取消请求 | 支持 | AbortController | AbortController |
| 浏览器兼容 | IE11+ | 现代浏览器 | 现代浏览器 |
| 包大小 | ~14KB | 0 | ~2KB |

**Axios 拦截器**
```tsx
// 全局请求拦截
axios.interceptors.request.use(
  (config) => {
    const token = getToken();
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => Promise.reject(error)
);

// 全局响应拦截
axios.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (error.response?.status === 401) {
      // 处理未授权
    }
    return Promise.reject(error);
  }
);
```

**React Query (SWR替代)**
```tsx
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';

const { data, isLoading, error } = useQuery({
  queryKey: ['user', userId],
  queryFn: () => fetchUser(userId),
  staleTime: 5 * 60 * 1000, // 5分钟内不重新请求
});

const mutation = useMutation({
  mutationFn: updateUser,
  onSuccess: () => {
    queryClient.invalidateQueries(['user']);
  },
});
```

### ⭐ 动画库对比

| 特性 | GSAP | Framer Motion | CSS Animation | Anime.js |
|-----|------|--------------|---------------|----------|
| 学习曲线 | 中等 | 低 | 低 | 低 |
| 能力 | 强大 | 强大 | 基础 | 中等 |
| 性能 | 优秀 | 优秀 | 良好 | 良好 |
| React集成 | 一般 | 优秀 | 原生 | 一般 |
| 价格 | 免费+付费 | 免费 | 免费 | 免费 |
| 适用场景 | 复杂动画 | React应用 | 简单动画 | 通用 |

**Framer Motion (React)**
```tsx
import { motion } from 'framer-motion';

const AnimatedCard = ({ children }) => (
  <motion.div
    initial={{ opacity: 0, y: 20 }}
    animate={{ opacity: 1, y: 0 }}
    transition={{ duration: 0.5 }}
    whileHover={{ scale: 1.05 }}
  >
    {children}
  </motion.div>
);
```

**GSAP (通用)**
```tsx
import { gsap } from 'gsap';

const animate = () => {
  gsap.to('.element', {
    x: 100,
    rotation: 360,
    duration: 1,
    ease: 'power2.out',
  });
};
```
