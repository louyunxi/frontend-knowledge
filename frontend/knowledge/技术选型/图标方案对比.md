# 图标方案对比（Iconify + 本地 SVG + Sprite）

> 适用场景：基于 Vue3 + Vite 的**纯 H5** 项目，需要大量图标但不想维护 iconfont 库。
> vue3-h5-template 项目同时集成 **3 套图标方案**（Iconify 在线、Iconify 离线、本地 SVG 雪碧图），按需选择。

## 一、3 套方案对比

| 方案 | 包 | 使用场景 | 内网支持 | 体积 |
|---|---|---|---|---|
| Iconify 在线 | `@iconify/vue` | 公网项目快速开发 | ❌ 需要 API | 0（按需请求） |
| Iconify 离线 | `@iconify-icons/fa6-solid` | 内网/严格离线 | ✅ | 每个图标集 ~10KB |
| 本地 SVG 雪碧图 | 自定义 + `vite-plugin-svg-icons-ng` | 项目专属图标 | ✅ | 自定义 |

## 二、Iconify 在线（推荐 — 公网环境）

### 2.1 封装组件

```vue
<!-- src/components/i-icon/index.vue -->
<script setup lang="ts">
import type { IconifyIcon } from '@iconify/vue'
import { Icon as IconifyIconComp } from '@iconify/vue'

defineOptions({ name: 'IIcon' })

const props = defineProps<{ icon: string | IconifyIcon }>()
</script>

<template>
  <IconifyIconComp :icon="props.icon" class="i-icon" />
</template>

<style scoped>
.i-icon {
  width: 1em;
  height: 1em;
  vertical-align: -0.15em;
  fill: currentColor;
  overflow: hidden;
}
</style>
```

### 2.2 使用

```vue
<template>
  <!-- 用法 1：字符串（按需请求） -->
  <i-icon icon="fa6-solid:heart" />
  <i-icon icon="material-symbols:admin-panel-settings-outline" />

  <!-- 自动按当前字号显示，Tailwind 控制大小 -->
  <i-icon icon="jam:android" class="text-[24px]" />
</template>
```

### 2.3 自动按需注册

`unplugin-vue-components` 会自动注册 `IIcon` 组件，**无需 main.ts 手动注册**。

### 2.4 在线 API 行为

- 浏览器访问 `https://api.iconify.design/{prefix}.json?icons={name}` 拉图标数据。
- 首次使用某图标会发一次请求，后续使用浏览器缓存。
- **需要公网访问权限**。

## 三、Iconify 离线（内网推荐）

### 3.1 安装图标集依赖

```bash
# 依赖包名规则：@iconify-icons/[图标集]
pnpm i -D @iconify-icons/fa6-solid
pnpm i -D @iconify-icons/mdi
pnpm i -D @iconify-icons/lucide
```

每个图标集是一个 npm 包，包含所有图标数据。

### 3.2 引入并使用

```vue
<script setup lang="ts">
import Fa6SolidHeart from '@iconify-icons/fa6-solid/heart'
import Fa6SolidAppleWhole from '@iconify-icons/fa6-solid/apple-whole'
</script>

<template>
  <!-- 传入 IconifyIcon 对象 -->
  <i-icon :icon="Fa6SolidHeart" class="text-[24px]" />
  <i-icon :icon="Fa6SolidAppleWhole" class="text-[24px]" />
</template>
```

### 3.3 找图标

1. 访问 [https://icon-sets.iconify.design/](https://icon-sets.iconify.design/)
2. 搜索图标（如 "heart"）
3. 查看前缀（`fa6-solid`、`mdi`、`lucide`）
4. 安装对应包，按上述方式使用

### 3.4 体积优化

如果只用一个图标却安装了整个图标集，会产生冗余。
进阶优化：

```ts
// vite.config.ts
Components import { IconifyResolver } from 'unplugin-vue-components/resolvers'
// 配置 IconifyResolver 自动按需分析 import
```

但本项目用静态 import，简单可控。

## 四、本地 SVG 雪碧图

### 4.1 准备 SVG 文件

```
src/icons/svg/
├── check-in.svg
├── dark.svg
├── github.svg
├── light.svg
├── link.svg
└── svgo.yml  # SVG 优化配置
```

### 4.2 Vite 配置

```ts
// vite.config.ts
import { createSvgIconsPlugin } from 'vite-plugin-svg-icons-ng'

createSvgIconsPlugin({
  iconDirs: [path.resolve(process.cwd(), 'src/icons/svg')],
  symbolId: 'icon-[dir]-[name]',
})
```

生成的 symbol ID 格式：

```html
<svg>
  <symbol id="icon-svg-github">...</symbol>
  <symbol id="icon-svg-check-in">...</symbol>
</svg>
```

### 4.3 main.ts 引入虚拟模块

```ts
// src/main.ts
import 'virtual:svg-icons/register'  // 关键：把 symbol 注入到 document
```

### 4.4 封装组件

```vue
<!-- src/components/svg-icon/index.vue -->
<script setup lang="ts">
import { computed } from 'vue'
import { isExternal } from '@/utils/validate'

interface Props {
  name: string
  className?: string
}
const props = withDefaults(defineProps<Props>(), { className: '' })

const isExternalIcon = computed(() => isExternal(props.name))
const iconName = computed(() => `#icon-${props.name}`)

const styleExternalIcon = computed(() => ({
  mask: `url(${props.name}) no-repeat 50% 50%`,
  '-webkit-mask': `url(${props.name}) no-repeat 50% 50%`,
}))
</script>

<template>
  <div
    v-if="isExternalIcon"
    :style="styleExternalIcon"
    class="svg-external-icon svg-icon"
    v-bind="$attrs"
  />
  <svg v-else :class="svgClass" aria-hidden="true" v-bind="$attrs">
    <use :xlink:href="iconName" />
  </svg>
</template>

<style scoped>
.svg-icon {
  width: 1em;
  height: 1em;
  vertical-align: -0.15em;
  fill: currentColor;
  overflow: hidden;
}
.svg-external-icon {
  background-color: currentColor;
  mask-size: cover !important;
  display: inline-block;
}
</style>
```

要点：
- **支持外链 SVG**：检测 `https?://` 或 `data:` 前缀，自动用 `mask` 方式渲染。
- **支持本地 SVG**：通过 `<use xlink:href="#icon-xxx">` 引用 symbol。
- **所有图标 1em × 1em**，通过父级 `font-size` 或 Tailwind `text-[24px]` 控制大小。

### 4.5 使用

```vue
<template>
  <svg-icon name="github" class="text-[20px] mr-[8px]" />
  <svg-icon name="check-in" class="text-[24px]" />
  <svg-icon name="dark" class="text-[18px]" />
</template>
```

### 4.6 工具函数

```ts
// src/utils/validate.ts
export function isExternal(path: string) {
  return /^(?:https?:|mailto:|tel:)/.test(path)
}
```

## 五、3 套方案的选型建议

| 业务场景 | 推荐方案 |
|---|---|
| 通用图标（如首页、列表、用户） | Iconify 在线 + 离线双备 |
| 项目专属 Logo、品牌图标 | 本地 SVG 雪碧图 |
| 内网/严格部署 | Iconify 离线 + 本地 SVG |
| 公网/快速原型 | Iconify 在线 |
| 大量图标（> 100 个） | Iconify 离线 + 本地 SVG |

## 六、暗色模式切换图标（实战）

本项目的 navbar 暗色模式切换：

```vue
<!-- src/components/nav-bar/index.vue -->
<script setup lang="ts">
import { useDarkModeStore } from '@/store/modules/dark-mode'

const darkModeStore = useDarkModeStore()
const { isDark } = storeToRefs(darkModeStore)

const iconName = computed(() => isDark.value ? 'light' : 'dark')

function onClickRight(event: TouchEvent | MouseEvent) {
  darkModeStore.toggleDarkMode(event)
}
</script>

<template>
  <van-nav-bar fixed placeholder @click-right="onClickRight">
    <template #right>
      <svg-icon class="text-[18px]" :name="iconName" />
    </template>
  </van-nav-bar>
</template>
```

要点：
- `light.svg` / `dark.svg` 是本地 SVG。
- 暗色模式展示太阳（点击切到亮色），亮色模式展示月亮（点击切到暗色）。

## 七、SVG 优化（svgo）

```yaml
# src/icons/svg/svgo.yml
# 用于 svgo 优化 SVG
```

```bash
pnpm i -g svgo
svgo --config src/icons/svg/svgo.yml src/icons/svg/*.svg
```

可减小 SVG 体积 30%-70%。

## 八、关键决策对比

| 维度 | Iconify 在线 | Iconify 离线 | 本地 SVG |
|---|---|---|---|
| 接入成本 | 低（无需安装包） | 中（要装包） | 中（要准备文件） |
| 离线运行 | ❌ | ✅ | ✅ |
| 图标数量 | 200,000+ | 每个图标集 ~1,500 | 无限制 |
| 按需加载 | ✅（按图标） | ❌（整包加载） | ❌（整包） |
| 体积 | 极小 | 10-100KB/包 | 视图标而定 |
| 动态图标 | ✅（运行时拉取） | ❌ | ❌ |
| 自定义 | ❌ | ❌ | ✅ |

## 九、常见踩坑

1. **Iconify 在线 404**：项目部署在**内网**会失败，必须用离线包。
2. **本地 SVG `<use>` 不显示**：忘记 `import 'virtual:svg-icons/register'`。
3. **SVG fill 颜色不对**：本地 SVG 用 `fill: currentColor` 跟随父元素文字颜色。
4. **自动按需导入未生效**：检查 `vite.config.ts` 的 `Components({ resolvers: ... })` 配置。
5. **图标大小不统一**：所有组件都用 `1em × 1em`，父级 `font-size` 控制实际尺寸。
