## 页面模式索引规则

页面级布局知识保存到 `布局/页面模式/`，与 Grid、Flex、Sticky 等底层布局技术分开管理。

```text
布局/
├── 页面模式/             页面任务、区域结构、模块关系、状态协作、跨端转换
├── 响应式/               断点、媒体查询、容器查询
├── 栅格布局/             Grid、Flexbox
├── 定位布局/             Sticky、Fixed、Absolute
├── 特殊布局/             瀑布流、经典结构
└── 对齐布局/             居中、等高、均分
```

页面模式条目只在对应知识文件真实存在并通过结构校验后登记。条目名称应以任务和模块组合为主，例如"筛选表格 + 详情抽屉"，不得只用 CSS 技术命名。

每个页面模式索引项必须标明：

- `knowledge_id`：跨索引稳定且唯一；
- `display_name`：供人阅读的模式名称；
- `relative_path`：从 `knowledge/` 开始的真实相对路径；
- `knowledge_type`：固定为 `page-layout-pattern`；
- `target_platform`：`web`、`mobile` 或 `responsive`；
- 页面类型与核心任务；
- 关键模块组合；
- 适用和不适用条件；
- 来源范围与置信度。

当前没有已登记的页面模式知识文件时，保持本节为空，不创建占位条目。

## 🔥 核心模式

### ⭐ 响应式栅格系统

适用：构建可复用的响应式布局

```css
.grid {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 24px;
}

.col-span-12 { grid-column: span 12; }
.col-span-6  { grid-column: span 6; }
.col-span-4  { grid-column: span 4; }
.col-span-3  { grid-column: span 3; }

@media (max-width: 768px) {
  .col-span-6, .col-span-4, .col-span-3 {
    grid-column: span 12;
  }
}
```

### ⭐ Flex 垂直居中

适用：元素居中场景

```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
```

### ⭐ Sticky 侧边栏

适用：侧边栏滚动时固定

```css
.layout {
  display: grid;
  grid-template-columns: 250px 1fr;
}

.sidebar {
  position: sticky;
  top: 80px;
  height: fit-content;
}
```

### ⭐ 瀑布流布局

适用：图片画廊、商品列表

```css
.masonry {
  columns: 3;
  column-gap: 16px;
}

.masonry-item {
  break-inside: avoid;
  margin-bottom: 16px;
}
```

### ⭐ 水平垂直居中

```css
/* 方法1: Flexbox */
.center-flex {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* 方法2: Grid */
.center-grid {
  display: grid;
  place-items: center;
}

/* 方法3: Absolute + Transform */
.center-absolute {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

## 📐 Grid vs Flex 对比

| 场景   | 推荐   | 原因      |
| ---- | ---- | ------- |
| 二维布局 | Grid | 行和列同时控制 |
| 一维布局 | Flex | 沿主轴排列   |
| 整体页面 | Grid | 页面级布局   |
| 组件内部 | Flex | 组件内元素排列 |
| 卡片网格 | Grid | 统一间距和大小 |
| 导航菜单 | Flex | 单行排列    |
