# 首页分区栅格布局

## 概述

首页产品区使用 CSS Grid 实现 2 列卡片栅格（新品上架、热卖推荐）、5 列金刚位栅格（类目入口）、3 列复合栅格（优惠券入口）。三套栅格统一使用 `repeat(n, minmax(0, 1fr))` 写法，配合模块专属 gap 形成节奏清晰的首页布局。

## 布局类型

- [x] 栅格系统
- [x] 响应式布局（基于 CSS Grid auto-fit/fractional）

## 适用场景

### ✅ 适合

- 商品列表 / 卡片陈列
- 类目入口（icon grid）
- 优惠券 / 福利入口

### ❌ 不适合

- 长列表无限滚动（应使用 list/virtual-list）
- 异形卡片（建议 flex + 显式宽度）

## 实现详解

### 三种栅格对比

| 变体 | 列数 | 间距 | 适用模块 |
|------|------|------|---------|
| 产品 2 列 | `repeat(2, minmax(0, 1fr))` | gap: 16px | 新品、热卖、推荐 |
| 金刚位 5 列 | `repeat(5, minmax(0, 1fr))` | gap: 18px 10px | 类目入口 |
| 优惠券 3 列 | `118px minmax(0, 1fr) auto` | gap: 16px | 领券区 |

### 关键 CSS 细节

```scss
/* minmax(0, 1fr) 防止子项内容溢出破坏栅格 */
grid-template-columns: repeat(2, minmax(0, 1fr));

/* gap 多值语法：行间距 列间距 */
gap: 18px 10px;

/* 复合栅格：固定列 + 自适应列 + 内容列 */
grid-template-columns: 118px minmax(0, 1fr) auto;
```

### 卡片圆角映射

| 元素 | 圆角 |
|------|------|
| 产品卡主体 | 28px / 30px |
| 缩略图 | 22px |
| 行动按钮（圆形） | 50% / 21px |
| 圆角徽章 | 999px（pill） |

## 响应式策略

```css
/* 项目使用 rem + flexible.js 自动适配 DPR */
/* 栅格按 fr 自动重排，无需额外断点 */
@media (max-width: 480px) {
  .new-arrivals__card { padding: 12px 12px 14px; }
  .diamond__grid { grid-template-columns: repeat(5, minmax(0, 1fr)); gap: 14px 8px; }
}
```

## 最佳实践

### ✅ 推荐

- 使用 `minmax(0, 1fr)` 而非 `1fr`，避免子项 `white-space: nowrap` 撑爆列宽
- 长文本使用 `-webkit-line-clamp: 2` 限制两行，固定 `min-height` 防抖动
- 缩略图 `aspect-ratio: 1/1` + `object-fit: cover` 保证方形统一
- 按钮放在卡片右下角用 `align-self: flex-end`

### ❌ 避免

- 使用 flex-wrap 实现列布局（无法精确控制列宽）
- 在 grid 中嵌套额外一层容器（增加渲染负担）
- 使用百分比而非 fr（无法处理 gap 与 padding 减扣）

## 性能考虑

- CSS Grid 在现代浏览器已高度优化，无需 will-change
- 使用 `aspect-ratio` 替代 padding-bottom hack，减少重排

## 无障碍

- 栅格容器使用 `<ul>/<li>` 或 `role="list"`，保证列表语义
- 缩略图必须有 alt 描述
