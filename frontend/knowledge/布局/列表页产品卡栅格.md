# 列表页产品卡栅格

## 概述

列表页（搜索结果、钻石商品、分类列表）统一采用「**1 个摘要卡 + 2 列产品卡栅格**」结构。每张产品卡保持圆角 30-32px、缩略图 188x188 方形、标题固定两行、价格字号 30-34px 的统一规格，形成跨页面一致的浏览体验。

## 布局类型

- [x] 栅格系统
- [x] 对齐方式
- [ ] 响应式
- [ ] 定位
- [ ] 特殊

## 适用场景

### ✅ 适合

- 搜索结果列表
- 类目下的商品列表
- 聚合活动商品列表

### ❌ 不适合

- 内容信息密度高的列表（应使用紧凑型 3-4 列）
- 大图沉浸式列表（应改为 1 列大图卡）

### 搜索列表页结构


## 实现详解

### 三种列表页对比

| 页面 | 栅格 | 间距 | 卡片圆角 | 标题字号 | 价格字号 |
|------|------|------|---------|---------|---------|
| 搜索结果 | 2 列 | 16px | 30px | 34px | 34px |
| 钻石商品 | 2 列 | 16px | 32px | 28px | 34px |
| 分类列表 | 2 列 | 14px | 28px | 28px | 32px |

### 列表页统一公式

```
列表页 = 摘要卡（24-32px 内边距 + 30-36px 圆角）
       + 2 列产品栅格（repeat(2, minmax(0,1fr)) + gap 14-16px）
       + 无限滚动加载（van-list）
       + 空态/骨架
```

### 摘要卡（Summary Card）规格

| 元素 | 规格 |
|------|------|
| 圆角 | 30-36px |
| 内边距 | 24-32px |
| 背景 | linear-gradient 或 surface-glass |
| 标题字号 | 48-68px（凸显搜索关键词） |

## 最佳实践

### ✅ 推荐

- ProductCard 作为公共组件，所有列表页复用同一份视觉规格
- 摘要卡放在列表顶部，帮助用户确认搜索意图
- 使用 `<ProductCard>` + `v-for` 渲染，命中 `:key` 提升 diff 效率
- 加载状态使用 van-list `finished-text` 与 `loading` 插槽

### ❌ 避免

- 在每个列表页都手写一份产品卡样式（违反 DRY）
- 使用 3 列产品栅格（缩略图过小，用户辨识度低）
- 价格字体使用 px 数值混用（应统一 30-34px 区间）

## 性能考虑

- 无限滚动使用 `van-list` 配合后端分页，首屏只渲染可视区
- 缩略图使用懒加载（`loading="lazy"`）
- 摘要卡放首屏外可延迟渲染（content-visibility: auto）

## 无障碍

- 列表使用 `<ul>/<li>` 语义化标签
- 每张卡片支持键盘聚焦（`tabindex="0"`）和回车跳转
- 缩略图 alt 必须填写商品名
