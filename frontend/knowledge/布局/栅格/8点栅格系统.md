# 8 点栅格系统

## 概述

8 点栅格（8-Point Grid）是移动端界面布局的基础系统。所有 spacing、padding、margin、width、height 都应基于 8 或 4 的倍数。

## 核心规则

### 基础间距值（8 倍数优先）

```text
可用值：4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128
推荐使用：8, 16, 24, 32, 48, 64
```

### 推荐间距 token

```css
:root {
  --space-1: 4px;   /* 极小间距、图标与文字 */
  --space-2: 8px;   /* 元素内紧密间距 */
  --space-3: 12px;  /* 表单字段间距 */
  --space-4: 16px;  /* 卡片内 padding 最小值 */
  --space-5: 20px;  /* 中等间距 */
  --space-6: 24px;  /* 卡片内 padding 推荐 */
  --space-8: 32px;  /* 卡片间距离、组件大间距 */
  --space-12: 48px; /* 节段间距 */
  --space-16: 64px; /* 大段落间距 */
  --space-20: 80px; /* Section 垂直内边距（移动端） */
  --space-24: 96px; /* Major section 垂直内边距 */
  --space-32: 128px; /* Hero section 顶部 */
}
```

## 关系型间距

```text
核心原则：相关元素靠近，不相关元素远离

实施：
1. 同组元素：16px 间距
2. 异组元素：2× = 32px 间距
3. 段落之间：3× = 48px 间距
4. Section 之间：4× = 64px 间距

比例：1 : 2 : 3 : 4 = 16 : 32 : 48 : 64
```

## Section 与卡片 Padding

```text
Section 垂直 padding：≥ 80-96px（移动端）
Major Section padding：160px（更大屏幕）
卡片内部 padding：24-32px baseline
小卡片 / 紧凑列表：16px baseline
```

## 字号与间距的对应

```text
字号越大，需要的间距越大

示例：
- 13px caption → 上下间距 8px
- 15px body    → 上下间距 12px
- 20px title   → 上下间距 16px
- 28px display → 上下间距 24px
```

## 移动端布局尺度

### 拇指区（Thumb Zone）

```text
iPhone 屏幕：约 375 × 812 px (iPhone X)

区域划分：
┌──────────────┐
│  难以触及区   │  ← 顶部 1/3：单手操作困难
│              │
├──────────────┤
│  自然区      │  ← 中部 1/3：容易看到
│              │
├──────────────┤
│  拇指区 ★    │  ← 底部 1/3：单手操作最佳
│  放主CTA!    │
└──────────────┘

★ 主操作按钮、Tab Bar、放这里
```

### F 型阅读模式

```text
用户扫描顺序：
1. 顶部水平扫描
2. 沿左侧向下
3. 再次水平扫描（较短）
4. 沿左侧继续向下

布局启示：
- 关键信息：左上
- 次要信息：中右
- 弱信息：右下
```

## 实施示例

### Vue + Tailwind

```vue
<template>
  <section class="px-6 py-20">
    <h2 class="text-title mb-6">标题</h2>
    <p class="text-body mb-4">段落内容</p>
    <button class="mt-8 px-6 py-3">主操作</button>
  </section>
</template>
```

### React + CSS Modules

```css
/* styles.module.css */
.section {
  padding: 80px 24px;        /* py-20 px-6 */
}
.title {
  font-size: 20px;
  margin-bottom: 24px;       /* mb-6 */
}
.body {
  font-size: 15px;
  margin-bottom: 16px;       /* mb-4 */
}
.button {
  margin-top: 32px;          /* mt-8 */
  padding: 12px 24px;
}
```

## 反模式

- ❌ 使用 7px、13px、15px 等非 4 倍数值
- ❌ 同组元素 32px、异组元素 16px（比例倒置）
- ❌ 主 CTA 放在屏幕顶部
- ❌ 所有 section padding 一致（缺少节奏感）
- ❌ 字号大但间距小（视觉拥挤）
