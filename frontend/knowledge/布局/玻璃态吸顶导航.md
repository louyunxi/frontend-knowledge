# 玻璃态吸顶导航

## 概述

首页 Header、分类页 TopBar、详情页 NavBar 等需要固定在顶部的导航栏统一采用「Glassmorphism 毛玻璃」视觉：背景 `rgba(245, 245, 247, 0.86)` + `backdrop-filter: saturate(180%) blur(18px)` 形成半透明模糊效果，配合 72px 高度的药丸搜索框，营造 iOS 原生 App 般的浮层质感。

## 布局类型

- [x] 定位布局（position: sticky / fixed）
- [x] 对齐方式

## 适用场景

### ✅ 适合

- 顶部固定搜索 / 导航
- 长列表滚动时需要保留入口
- 内容切换 Tab 锚点

### ❌ 不适合

- 内容过少的页面（无意义固定）
- 全屏沉浸式场景（视频播放、活动落地页）

## 实现详解

### 玻璃态核心三件套

```scss
.header {
  background: rgba(245, 245, 247, 0.86);              /* 半透明底色 */
  backdrop-filter: saturate(180%) blur(18px);         /* 模糊+饱和度提升 */
  -webkit-backdrop-filter: saturate(180%) blur(18px); /* Safari 兼容 */
}
```

| 属性 | 作用 | 推荐值 |
|------|------|-------|
| background | 半透明底色 | rgba(245, 245, 247, 0.86) |
| backdrop-filter | 模糊 | blur(18-24px) |
| backdrop-filter | 饱和度 | saturate(180%) |
| border-bottom | 区分边界 | rgba(29, 29, 31, 0.06) 1px |

### position 选型

| 场景 | position | 原因 |
|------|----------|------|
| 全屏固定头部 | `fixed` | 不随父容器滚动 |
| 跟随滚动到顶后吸顶 | `sticky` | 滚动区域上方时跟随 |
| 局部固定（如分类页 TopBar） | `sticky` | 与滚动容器结合 |

### 高度规范

| 元素 | 高度 |
|------|------|
| 顶部 Header（容器） | 88px |
| 搜索框（内嵌） | 72px |
| TabBar 容器 | 96-156px（详见容器布局） |

### z-index 层级

```
100  Header（最高）
 80  弹窗/Toast
 50  吸顶 TopBar
 20  浮动按钮
 10  内容
  0  默认
```

## 最佳实践

### ✅ 推荐

- 同时声明 `-webkit-backdrop-filter` 保证 Safari 兼容
- 使用 `rgba(245, 245, 247, 0.86)` 而非 `transparent`，避免背景完全透明导致文字对比度不足
- 底部加 1px `rgba` 边框代替 box-shadow，性能更好
- 搜索框使用 999px pill 圆角 + 半透明白底，与背景形成层次

### ❌ 避免

- 使用 `filter: blur()`（会模糊整个元素内部）
- 完全不写 `-webkit-` 前缀（iOS Safari 无 backdrop-filter）
- `position: fixed` 时不设置 `left/right` 导致宽度异常

## 性能考虑

### 渲染性能

```css
/* 高斯模糊是 GPU 密集型操作，避免在大容器上使用 */
.header {
  /* 限制模糊区域 */
  isolation: isolate;
  will-change: backdrop-filter;
}
```

### 加载性能

- 头部不使用图片资源（全部用 CSS 渐变）
- 搜索图标用 iconfont / SVG sprite，减少请求

## 无障碍

### 视觉

- 半透明背景仍保证文字对比度 ≥4.5:1
- iOS 的「增强对比度」开启后 backdrop-filter 会自动降级为不透明

### 键盘导航

- 搜索框使用 `<button>` 而非 `<div>`，支持键盘聚焦
