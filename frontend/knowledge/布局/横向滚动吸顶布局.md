# 横向滚动吸顶布局

## 概述

首页「热卖 Top」模块使用 CSS Scroll Snap 实现横向滚动展示效果：容器宽度 100%，子项以 `flex: 0 0 calc((100% - 20px) / 2.8)` 计算宽度（一次显示 ~2.8 项），结合 `scroll-snap-type: x mandatory` 让滑动对齐到卡片边缘，模拟原生 App 的轮播体验。

## 布局类型

- [x] 特殊布局（scroll-snap）
- [x] 对齐方式

## 适用场景

### ✅ 适合

- 首页热点 / 推荐位横向展示
- 同一类目下的多卡片预览（让人快速 swipe 浏览）
- 榜单类横向排名展示

### ❌ 不适合

- 长列表（应使用纵向虚拟列表）
- 需要分页指示器（应改用 swiper）
- 子项宽高不一致（snap 对齐失效）

## 实现详解

### 核心 CSS 三件套

```scss
.hot-shelf__rail {
  display: flex;
  gap: 12px;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  scroll-padding: 16px;
}

.hot-shelf__item {
  flex: 0 0 calc((100% - 20px) / 2.8);
  scroll-snap-align: start;
}
```

| 属性 | 作用 |
|------|------|
| `display: flex` | 横向排布子项 |
| `overflow-x: auto` | 启用横向滚动 |
| `scroll-snap-type: x mandatory` | 强制 snap 对齐 |
| `scroll-padding` | snap 边界预留内边距 |
| `flex: 0 0 calc((100% - 20px) / 2.8)` | 子项宽度公式 |
| `scroll-snap-align: start` | 子项对齐方式 |

### 子项宽度公式解析

```
calc((100% - 20px) / 2.8)
         │      │      │
         │      │      └─ 一屏显示 2.8 项（露出下一项的 1/2.8）
         │      └─ 总间距（20px = 12px gap + 8px 视觉缓冲）
         └─ 容器宽度
```

效果：每次滚动停下时屏幕显示 2 项 + 第 3 项的边缘，暗示可继续滑动。

### 排名徽章渐变

| 排名 | 配色 |
|------|------|
| No.1 | linear-gradient(135deg, #ff6b6b, #ff9f43) 橙红 |
| No.2 | linear-gradient(135deg, #ffb86b, #ffd23f) 橙黄 |
| No.3 | linear-gradient(135deg, #5fa8ff, #7d97ff) 蓝紫 |

## 响应式策略

```css
/* 子项宽度公式对宽度敏感，需在小屏下增加可视项 */
@media (max-width: 480px) {
  .hot-shelf__item {
    flex: 0 0 calc((100% - 16px) / 2.4);  // 屏幕更小时露出更多
  }
}
```

## 最佳实践

### ✅ 推荐

- 隐藏滚动条（视觉清爽，但保留可访问性焦点）
- 子项宽度公式中分母 2.4-2.8 之间取值最佳
- 标题用 `-webkit-line-clamp: 2` 固定高度，避免滚动抖动
- 标题前加排名徽章，强化榜单感

### ❌ 避免

- 使用第三方 swiper（性能与体积成本高）
- 在横向滚动容器上监听横向手势（与原生滚动冲突）
- 子项高度不一致（破坏 snap 节奏）

## 性能考虑

### 渲染性能

```css
/* 横向列表使用 transform 而非 left/top 滚动 */
.hot-shelf__rail { will-change: transform; }
```

### 加载性能

- 缩略图懒加载 `loading="lazy"`
- 超出可视区的子项使用 `content-visibility: auto`

## 无障碍

- 横向滚动容器添加 `role="region"` + `aria-label="本周热卖"`
- 子项使用键盘左右键导航（`tabindex="0"`）
- 隐藏滚动条但保留原生滚动行为（辅助技术可识别）
