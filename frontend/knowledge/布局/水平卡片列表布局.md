# 水平卡片列表布局

## 概述

首页「猜你喜欢 / 推荐流」（RecommendFeed）使用经典的「水平缩略图 + 内容」结构：固定 132x132 方形缩略图在左，内容区在右，通过 `grid-template-columns: 132px minmax(0, 1fr)` 控制 18px gap，文字标题固定两行、价格字号 38px 突出，配合右下角行动按钮形成可点击的整体卡。

## 布局类型

- [x] 对齐方式
- [ ] 栅格系统
- [ ] 响应式
- [ ] 定位
- [ ] 特殊

## 适用场景

### ✅ 适合

- 首页个性化推荐流
- 订单商品列表
- 评论 / 帖子列表
- 内容聚合类卡片

### ❌ 不适合

- 商品陈列（应使用 2-3 列栅格）
- 强调图片的列表（应改为 1 列大图卡）

## 实现详解

### 核心布局

```scss
.recommend-card__grid {
  display: grid;
  grid-template-columns: 132px minmax(0, 1fr);  // 固定缩略图 + 自适应内容
  gap: 18px;
  padding: 18px;
}
```

| 元素 | 规格 |
|------|------|
| 卡片圆角 | 30px |
| 卡片内 padding | 18px |
| 缩略图 | 132 x 132 方形，圆角 22px |
| 标题字号 | 32px / 1.22 / 600 |
| 价格主字号 | 38px / 1 / 600 |
| 行动按钮 | 50px 高 × 150px min-width，圆角 999px |

### 列表外层

```scss
.recommend-feed__list {
  display: flex;
  flex-direction: column;
  gap: 16px;  /* 卡片之间间距 */
}
```

## 响应式策略

```css
@media (max-width: 480px) {
  .recommend-card__grid {
    grid-template-columns: 112px minmax(0, 1fr);
    gap: 14px;
    padding: 14px;
  }
  .recommend-card__media { width: 112px; height: 112px; }
  .recommend-card__title { font-size: 28px; }
}
```

## 最佳实践

### ✅ 推荐

- 缩略图固定宽高，避免被标题撑高导致视觉错位
- 内容区使用 `min-width: 0` 防止 grid 子项内容溢出
- 价格区使用 `margin-top: auto` 推到底部，保持视觉对齐
- `display: grid` 而非 `display: flex`，避免内容高度参差不齐

### ❌ 避免

- 缩略图使用 `width: 30%`（不同机型下尺寸不稳定）
- 标题不固定高度（导致多张卡片高度不一致）
- 价格与按钮放在同一行顶部（与缩略图重叠）

## 性能考虑

- 列表使用 `van-list` 懒加载（首屏只渲染可见项）
- 缩略图懒加载 `loading="lazy"`
- `transform: scale(0.99)` 触发 GPU 加速

## 无障碍

- 整卡可点击时使用 `<article>` + 点击事件，而非嵌套 `<a>`
- 缩略图 alt 必须填写商品名
- 价格使用语义化结构（数字 + 单位）
