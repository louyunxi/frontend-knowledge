# 页面布局模式蒸馏模板

本模板仅用于：

```text
/frontend:distill <源路径> --type page-layout --domain 布局 --platform web | mobile | responsive [--name 名称]
```

知识文件保存到 `knowledge/布局/页面模式/`。所有事实必须能够追溯到源代码、项目规范、测试、设计说明或运行证据；无法验证的内容必须标为推断或未知。

## 完成前检查

1. 删除所有未填写的占位符，或将未知项明确写为 `unknown`；
2. 确认 `target_platform` 与命令 `--platform` 一致，`observed_platforms` 只列出有证据的平台；
3. 确认响应式条目没有把独立移动任务流错误合并；
4. 检查目标路径和索引中的同名或同任务模式，存在时默认停止并输出差异；
5. 确认知识正文、frontmatter、索引和测试词均已脱敏且不含凭据；
6. 确认索引引用的知识文件真实存在且含稳定 ID、规范化相对路径和目标平台；
7. 使用页面类型、核心任务、模块组合、同义词和口语表达执行匹配测试；
8. 使用 `/frontend` 的页面路径分支（带布局域相关页面任务表达）验证可召回性；
9. 只有全部必填项通过后才保存并同步索引，任一同步失败不得报告成功。
