# 索引一致性 CI 校验清单 (index-sync-checklist)

> **用途**：CI 期 / 提交前 / 发布前必须运行的本索引一致性校验。任何一项未通过 → 阻断提交或报告 P0 缺陷。
> **执行时机**：本地 `git commit` 钩子、PR 检查、定时巡检。

---

## 0. 运行方式

```bash
# 推荐方式：以脚本驱动（未实现前可手动核对）
node scripts/sync-check.mjs

# 临时手动核对：对照本清单逐项检查 knowledge/ 真实目录与索引文件
```

---

## 1. 文件 ↔ 索引 1:1

- [ ] 对每个 `knowledge/<域>/` 目录，统计 `.md` 文件清单（排除该域索引本身）
- [ ] 对每个域索引 `目录结构` 段，提取声明的文件清单
- [ ] 两份清单差异必须为空；存在差异 → 报告 P0：`目录结构漂移`
- [ ] 索引中出现的文件名必须实际存在；不存在的 → 报告 P0：`索引断链`
- [ ] 磁盘上存在但索引未声明的文件 → 报告 P1：`索引遗漏`

## 2. 四层检索索引对齐

- [ ] L1-精确索引：每个条目对应的 `relative_path` 文件实际存在；不存在 → 报告 P0：`L1 断链`
- [ ] L2-关键词索引：每个条目"对应知识"列所引用的文件名实际存在；否则报告 P0：`L2 断链`
- [ ] L3-标签索引：每个标签条目指向的知识文件名实际存在
- [ ] L4-场景索引：每个场景条目指向的知识文件名实际存在
- [ ] 四层索引中不允许出现 `page-layout-pattern` 类型条目，除非该条目在 `knowledge/布局/页面模式/` 下有真实文件

## 3. 域与目录一致

- [ ] 知识文件 frontmatter 中的 `domain` 字段必须等于其所在父目录名
- [ ] `--domain` 取值仅允许：`动效`、`布局`、`功能`、`项目规范`、`设计主题`、`技术选型`
- [ ] `page-layout` 类型文件的 `--domain` 必须为 `布局`
- [ ] 知识文件不在任何"待补充模式"或"未来规划"目录名（如 `状态管理/`、`构建工具/` 等尚未落盘的占位目录）下

## 4. 命名规范

- [ ] 非 page-layout 文件名遵循 `{域}-{主题}-{修饰}.md`（中文/小写英文均可，但必须三段或以上，使用 `-` 连接）
- [ ] page-layout 文件名遵循 `[页面任务]-[平台].md`，平台后缀 ∈ `web` / `mobile` / `responsive`
- [ ] 不允许单段名（如 `Modal.md`、`规则.md`）进入知识库
- [ ] 不允许含空格或特殊字符（除 `-` 和中文）

## 5. 关键词真相源

- [ ] SKILL.md 的"关键词表"必须显式声明派生自 L2，不得手编关键词
- [ ] SKILL.md 与 L2-关键词索引的关键词条目数差异必须 ≤ 1（仅允许 L2 多一条"待补"占位）
- [ ] L2-关键词索引中任何条目都必须能在 L1 中找到对应行

## 6. 最后更新日期

- [ ] 每个索引文件底部必须有 `*最后更新: YYYY-MM*`
- [ ] 日期必须等于或晚于该文件最近一次 git commit 日期
- [ ] 日期不允许为未来日期
- [ ] 任何 distill 操作后必须刷新该索引文件的 `最后更新` 字段

## 7. 跨域一致性

- [ ] 同一 `knowledge_id` 仅出现在一个域下
- [ ] 同一文件名仅出现在一个域下
- [ ] 域索引的"常见场景速查"表的"推荐模式"列必须指向该域实际存在的文件
- [ ] 域索引的"核心模式"段不允许含未在 `目录结构` 中声明的文件
- [ ] 域索引的"待补充模式"段不允许含本索引未声明计划但用户已开始引用的功能

## 8. 阻断条件

以下任一情况 → 阻断提交 / 报告 P0：

- 索引中出现 `相对路径` 找不到对应文件
- 索引中出现重名条目且未走合并
- SKILL.md 关键词表与 L2 不一致
- 任意索引文件 `最后更新` 早于磁盘 mtime / git log
- 任意 domain 与目录不一致
- 任意索引文件不包含 `最后更新` 字段
