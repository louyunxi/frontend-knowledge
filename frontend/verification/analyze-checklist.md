# /frontend 页面路径分支验证清单

输出方案前逐项检查。无法满足的项目写入“风险与证据缺口”，不得静默跳过。

## 输入与证据

- [ ] 已确认唯一页面入口
- [ ] 已读取页面直接引用的本地组件、样式、类型、Hooks 和工具
- [ ] 已检查依赖清单与现有技术栈
- [ ] 已查找设计文档、Token、主题和全局样式
- [ ] 已查找公共页面容器、UI 组件及同类页面
- [ ] 事实、推断和知识建议已明确区分
- [ ] 所有关键项目结论都有文件依据或标记为推断

## 页面理解

- [ ] 已识别核心目标和主要用户任务
- [ ] 已列出页面已有模块及来源
- [ ] 已识别已有功能而非仅根据组件名猜测
- [ ] 已梳理同时、顺序、主从、筛选目标和触发反馈关系
- [ ] 已明确筛选、排序、分页、选择和详情之间的状态协作不变量
- [ ] 已识别 URL 查询参数在页面状态中的角色，未默认新增 URL 同步
- [ ] 已标记受保护的业务逻辑、数据流、路由和事件
- [ ] 页面类型由任务、内容和模块关系共同得出

## 多域召回

- [ ] 布局、功能、动效、设计主题和项目规范分别生成了查询
- [ ] 布局召回同时覆盖页面模式、页面骨架、内容编排和响应式技术
- [ ] 功能召回覆盖已有 capability、关键链路和必要状态
- [ ] 动效候选包含触发器、对象和目的
- [ ] 设计知识没有覆盖项目现有 Design Token
- [ ] 技术建议未假设项目不存在的依赖
- [ ] 索引线索与真实知识文件已区分

## 裁剪与冲突

- [ ] 候选已分为采用、可选、排除和缺失
- [ ] 每项采用知识都绑定具体模块或交互链路
- [ ] 已排除与核心任务无关的功能
- [ ] 已排除已有组件的重复实现
- [ ] 已排除与项目设计冲突的通用样式
- [ ] 已排除无业务目的的装饰动效
- [ ] 未解决冲突已显式记录

## 方案完整性

- [ ] 页面骨架能表达模块层级和关系
- [ ] 每个核心模块都有布局、功能、状态、动效、视觉和复用说明
- [ ] 已区分首次空数据、筛选无结果和请求错误
- [ ] 已检查加载、提交、成功、失败、权限和破坏性操作
- [ ] 已检查键盘、焦点、语义、对比度和减少动态效果
- [ ] 覆盖层已定义焦点进入、约束、关闭、返回及触发器卸载时的回退
- [ ] 已区分首次加载、保留旧数据的局部刷新及各请求通道的局部错误
- [ ] 已给出桌面、平板和移动端结构策略
- [ ] 已处理长文本、横向内容、固定区域和溢出风险
- [ ] 背景分区服务于信息层级而非装饰

## Agent 提示词

- [ ] 提示词脱离分析报告后仍可单独执行
- [ ] 包含准确页面路径和必须阅读文件
- [ ] 包含项目约束、可复用组件和保护逻辑
- [ ] 包含最终页面骨架和模块级实施方案
- [ ] 包含功能状态、动效绑定、视觉和响应式要求
- [ ] 包含实施顺序和可验证验收标准
- [ ] 未要求 Agent 修改与目标无关的代码
- [ ] 未声称方案中不存在证据缺口

## 阻断条件

出现以下情况时，默认不得生成 Agent 实施提示词，也不得输出“高置信度完整方案”：

- 页面入口无法确认
- 关键直接依赖无法读取
- 页面主要任务无法从代码和用户要求中判断
- 项目设计规范存在冲突但无法消解
- 关键业务逻辑只能猜测
- 推荐知识只有索引线索而无可靠内容
