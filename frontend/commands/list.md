# /frontend:list 命令

动态生成知识库索引与统计信息，所有数字与示例均**由当前知识库实际内容自动计算**，
禁止硬编码。执行本命令前必须先扫盘 `knowledge/` 目录，以扫盘结果为唯一真相源。

## 命令格式

```
/frontend:list [选项]
```

## 功能

1. **列出所有知识域**：扫描 `knowledge/` 下 6 个一级目录，统计模式数与标签分布
2. **列出指定域的知识**：查看某个域下的所有模式
3. **显示知识概览**：提供快速索引和搜索建议
4. **统计信息**：自动汇总总模式数、复杂度分布、标签分布

> 所有数字必须由执行时扫盘 `knowledge/` 实时生成，禁止引用本文档或 SKILL.md 中的任何
> 数字。生成后必须用 [verification/index-sync-checklist.md](../verification/index-sync-checklist.md)
> 自检：文件↔索引 1:1、命名规范、关键词真相源、最后更新日期。

## 使用场景

```
✅ 适用场景：
├── 不知道有哪些可用的技术经验
├── 想了解某个域的具体内容
├── 需要快速找到相关的模式
├── 作为开发的参考索引
└── 探索知识库的深度和广度

❌ 不适用场景：
├── 搜索具体的技术实现（用 `/frontend <需求>`）
└── 需要详细的实现代码（用 `/frontend <需求>`）
```

## 命令选项

### 1. 列出所有知识域（默认）

```
/frontend:list
```

**生成规则**：

1. 扫盘 `knowledge/动效/`、`knowledge/布局/`、`knowledge/功能/`、`knowledge/项目规范/`、
   `knowledge/设计主题/`、`knowledge/技术选型/` 六个域目录
2. 每个域的"模式数" = 该域下 `*.md` 文件数（排除 `*域索引.md` 索引文件本身）
3. 每个域的"内容" = 从该域索引文件 `## 核心模式` 或同等章节提取关键词
4. 每个域的"示例" = 从该域下挑 1-2 个文件名（不含 `.md`）作为代表
5. 快速索引表 = 从 [knowledge/索引/L4-场景索引.md](../knowledge/索引/L4-场景索引.md)
   中提取 3-5 条最高优先级场景

**输出模板**：

```markdown
## 📚 Frontend Knowledge 知识库概览
（最后更新：YYYY-MM，扫盘时间 HH:MM）

### 六大知识域

| 域 | 模式数 | 内容 | 示例 |
|---|-------|------|------|
| {域1} | {N1} | {内容} | {示例1}、{示例2} |
| {域2} | {N2} | {内容} | {示例} |
| ... | ... | ... | ... |

### 快速索引

| 需求 | 推荐域 | 推荐模式 |
|-----|-------|---------|
| {场景1} | {域} | {模式} |
| ... | ... | ... |
```

### 2. 列出指定域的知识

```
/frontend:list --domain {域}
```

**生成规则**：

1. 仅扫盘 `knowledge/{域}/` 下 `*.md` 文件（排除 `{域}域索引.md` 索引文件本身）
2. "可用模式 (N)" 的 N = 该域下实际文件数
3. 表格的"模式"列 = 文件名（去掉 `.md`，将 `-` 替换为空格展示）
4. "复杂度"列 = 从每个文件的元数据/Front-matter 或正文首段提取（无则留空或标注 `?`）
5. "描述"列 = 每个文件第一行非空标题行

**输出模板**：

```markdown
## {emoji} {域}域 - 模式列表
（最后更新：YYYY-MM，扫盘时间 HH:MM）

### 可用模式 ({N})

| 模式 | 复杂度 | 描述 |
|-----|-------|------|
| {模式1} | {⭐...} | {描述} |
| {模式2} | {⭐...} | {描述} |
| ... | ... | ... |

### 快速使用

```bash
# 查看具体模式
/frontend <需求关键词>
```
```

### 3. 列出所有域的详细知识

```
/frontend:list --all
```

**生成规则**：

1. 依次扫盘全部 6 个域，每个域输出一段 `## {emoji} {域}域 ({N})`，N 为该域实际文件数
2. 每条目下显示该文件的：文件名（去掉 `.md`）、复杂度（来自元数据）、首行标题、适用场景（来自正文首段或元数据）
3. 域之间用 `---` 分隔
4. 若某域文件数为 0，则该域下显示：
   ```
   ⚠️ 该域暂无落盘知识，可通过 /frontend:distill 蒸馏补充。
   ```

**输出模板**：

```markdown
## 📖 完整知识目录
（最后更新：YYYY-MM，扫盘时间 HH:MM）

---

### {emoji1} {域1}域 ({N1})

1. **{模式1}** {⭐...}
   - {描述}
   - 适用：{适用场景}

2. **{模式2}** {⭐...}
   ...

---

### {emoji2} {域2}域 ({N2})
...
```

### 4. 统计信息

```
/frontend:list --stats
```

**生成规则**：

1. "总体统计"：知识域数 = 固定 6（六个一级目录）；总模式数 = 所有 `*.md` 减去各域索引文件；
   总代码模板 = 扫盘所有 `*.md` 中 ` ``` ` 代码块计数（自动统计）
2. "各域分布"：条形图以 `█` 表示，宽度按比例 = `round(文件数 / 最大文件数 * 20)`，
   文件数填在右侧
3. "复杂度分布"：扫盘所有 `*.md` 的元数据或正文 `⭐` 标记，统计 `⭐` 到 `⭐⭐⭐⭐⭐` 数量，
   条形图宽度同上规则

**输出模板**：

```markdown
## 📊 知识库统计
（最后更新：YYYY-MM，扫盘时间 HH:MM）

### 总体统计
- 知识域: 6 个
- 总模式数: {N} 个
- 总代码模板: {M} 个

### 各域分布
{域1}    {bar1}  {N1}
{域2}    {bar2}  {N2}
...

### 复杂度分布
⭐      {bar_1}  {N_1}
⭐⭐     {bar_2}  {N_2}
⭐⭐⭐    {bar_3}  {N_3}
⭐⭐⭐⭐   {bar_4}  {N_4}
⭐⭐⭐⭐⭐  {bar_5}  {N_5}
```

## 配合使用

```bash
# 1. 先查看可用模式
/frontend:list --domain {域}

# 2. 再召唤知识驱动大模型
/frontend <需求关键词>

# 3. 需要添加新知识
/frontend:distill {源文件路径} --type pattern --domain {域}
```

## 搜索建议

> 本节内容应**由 [knowledge/索引/L4-场景索引.md](../knowledge/索引/L4-场景索引.md)
> 实时派生**，按场景出现频率倒序展示前 10 条，禁止硬编码场景名。

生成规则：

1. 读取 `L4-场景索引.md` 中所有场景行
2. 按场景计数 / 引用次数倒序
3. 每条展示：场景名、推荐域、对应模式名（不含 `.md`）

## 自检清单

执行完 `/frontend:list` 后必须逐项核对：

- [ ] 所有数字均来自实际扫盘 `knowledge/` 结果，未引用 SKILL.md 或本文档中任何示例数字
- [ ] 输出文件 ↔ `L1-精确索引.md` 1:1 对齐（无遗漏、无虚构）
- [ ] 文件名均符合 `{域}-{主题}-{修饰}.md` 三段式命名规范（page-layout 例外）
- [ ] 关键词引用均来自 `L2-关键词索引.md`，未引入新关键词
- [ ] 顶部"最后更新"日期与 `L1-精确索引.md` 一致
- [ ] 统计信息与各域索引文件中的"常见场景速查"行数一致
